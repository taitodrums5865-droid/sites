No single NAICS code covers government contracts as a category. The NAICS codes you use for government contracts are the ones that describe what you actually sell. The FAR requires the contracting officer to determine the NAICS code and size standard for each solicitation, and SBA says that code sets the size standard for the contract. This guide shows you how to test candidate codes against real award data and size standards so you register 3-5 that you can actually win under.

Key points

  • No single NAICS code covers all government contracting
  • FPDS ezSearch retired Feb 24, 2026; award search moved to SAM.gov
  • Size standards vary by code: 484122 is $43.0M, 492110 is 1,500

What is the NAICS code for government contracting?

There isn't one. NAICS describes the product or service you sell, and federal agencies assign one NAICS code to each solicitation based on what they are buying.

NAICS stands for the North American Industry Classification System, and the Census Bureau maintains it. The current U.S. version is still the 2022 NAICS. The Census Bureau's NAICS update fact sheet lays out the revision process, and a July 13, 2026 Federal Register notice asked for comments on proposed 2027 updates. The 2027 structure is targeted for January 2027, so some codes may change in 2027. Check census.gov/naics before you rely on a code you haven't looked at recently.

Here's what that means for you:

  • A janitorial company bids under 561720 (Janitorial Services). It doesn't use a "government contractor" code.
  • A management consultant typically bids under 541611 (Administrative Management and General Management Consulting Services). Our NAICS code for consulting guide compares the nearby consulting codes.
  • The solicitation decides which code applies to a bid. Under FAR 19.303, the contracting officer determines the appropriate NAICS code and related size standard and includes them in the solicitation. SBA explains that this designated code determines the size standard you have to meet.

Some codes look like they fit "government work" but describe government agencies themselves. Sector 92 (Public Administration) in the Census NAICS structure covers government establishments that administer and manage public programs, not private firms selling to them. Because those definitions describe what agencies do rather than what a contractor sells, they won't match the work in a solicitation you'd bid on. Search for the code that describes your service instead.

What is the best NAICS code for government contracts?

The best code matches your core service and shows recent awards in a size range you can staff and finance, ideally with some of them awarded under small business set-asides. You can check that directly in USAspending's Type of Set Aside filter. Choose by award data, not by "most popular code" lists.

A broad code like 541512 (Computer Systems Design Services) can show large total spending, but a big total can hide a small number of very large awards or contract vehicles. Before treating a broad code as your best target, check how many distinct recipients won awards and what the median award size is. For a two-person firm, a narrower code with steady awards in a range you can perform may be the better first target. Score each candidate code on these criteria:

If a code fails on fit, drop it no matter how much money flows through it. A code you can't perform only attracts notices you'll have to pass on. There is also a legal side: when you bid, you represent your size status under the solicitation's code, and 13 CFR 121.108 sets out penalties for misrepresenting size status, including debarment and civil or criminal penalties. Register only codes that genuinely describe your work, and certify only where you're actually small.

How to choose 3-5 NAICS codes for government contracts in 5 steps

Each step below ends with one pass/fail check, so you know when a code should move forward or drop out.

  1. List what you sell in plain words. Write 3-6 services or products you could deliver to a federal buyer this year, with the share of revenue each brings in. Check: each line is something you have done before, not something you hope to do.
  2. Shortlist codes in the NAICS search. Go to census.gov/naics, type a keyword (for example, "janitorial") into the NAICS Search box, and open each 6-digit result to read its definition and "cross-references." Cross-references tell you which similar activities belong in a different code. Keep 5-8 candidates. Check: each candidate's definition describes your work without stretching.
  3. Test each code against what agencies bought. Run the USAspending and SAM.gov checks described in the next two sections. Check: the code shows awards in recent fiscal years and live notices in a range you can win.
  4. Confirm the SBA size standard for each code. Look up every surviving code in the SBA table and compare it with your average annual receipts or employee count. Check: you're small under the code you plan to make primary.
  5. Register the final 3-5 codes in SAM.gov. Add them under Assertions → Goods and Services and mark one as primary (steps below). Check: your primary code is the one tied to most of your revenue and passed step 4.

Example (illustrative only): a small facilities firm in Kansas City might start with 561720 (Janitorial Services), 561730 (Landscaping Services), 238220 (Plumbing, Heating, and Air-Conditioning Contractors), 561210 (Facilities Support Services) and 236220 (Commercial and Institutional Building Construction). After step 3 it might drop 236220 because typical awards are too large to bond, and drop 561210 because those awards tend to be large bundled base-operations contracts. That would leave three codes to register. For the construction side, our NAICS code for construction guide breaks down the trade codes.

How to check what agencies actually bought on USAspending and FPDS

Filter awards by NAICS code, recent fiscal years, set-aside type and place of performance, then compare total dollars, number of awards, typical award size, buying agencies and winners. Many mid-sized awards from several agencies suggest the code is worth registering.

FPDS.gov is no longer where you do this. GSA decommissioned the ezSearch function in FPDS.gov on February 24, 2026. Contract award searches now run in SAM.gov, which requires a SAM.gov account (created through Login.gov). The same bulletin notes that the data stays publicly available on USAspending.gov without an account. Older tutorials that send you to FPDS ezSearch are out of date.

USAspending.gov (no login)

  1. Open USAspending.gov → Search → Advanced Search.
  2. Under Time Period, pick the last two or three fiscal years. Check each year separately so you can see whether spending is rising or falling.
  3. Under Award Type, keep only contracts. Leave out grants and loans.
  4. Under the North American Industry Classification System (NAICS) filter, type your 6-digit code and tick it.
  5. Under Type of Set Aside, select the small business set-aside types that apply to you. Then run the search again without this filter to see the full market.
  6. Under Location, use Place of Performance, not recipient location, if you only work regionally. The Congressional Research Service recommends place of performance because it shows where the work happens, not where the winner's headquarters is.
  7. Submit, then open the results table and category views to see awarding agencies and top recipients. Download the results if you want to sort them in a spreadsheet.

Record five numbers per code: total obligated dollars, number of awards, median award size (sort the table and take the middle row), number of distinct awarding agencies, and how many winners show up more than once. If one company won most awards with one office, the code may be closed to newcomers for now.

Do you need a paid tool for this? Subscription databases can compute these numbers and add pipeline alerts, and our GovWin vs HigherGov vs GovSpend comparison is our own editorial comparison of them, not an independent test. They're not for everyone. If you're testing 3-5 codes once a year, the steps above cover it using award data that GSA says remains publicly available on USAspending.gov. A subscription makes more sense if you track many codes and agencies weekly. Before buying, ask each vendor what it adds beyond public award and opportunity data, and how it handles the DoD reporting delay described below.

SAM.gov contract awards (login required)

Use SAM.gov's award search when you need contract-level detail, such as the contracting office, the specific award ID or links between an award and its original notice. GSA says the new search adds partial-match filters and links between opportunities, awards and subawards.

The DoD data lag: Defense award data is delayed. FPDS documentation states DoD data is subject to a 90-day delay before public release. If you check a code mostly bought by the Army or Navy in October, the last quarter will look empty. Compare full fiscal years instead of counting the most recent months as a drop in demand.

How to find opportunities by NAICS code on SAM.gov

Search Contract Opportunities by NAICS code and notice type. Then count how often solicitations appear, how many are set aside for small business, and what the scope usually is.

Award data tells you what was bought. Live notices show which code contracting officers use for work like yours right now, and they sometimes surprise you. For example, a landscaping job bundled with snow removal might be posted under a facilities code.

  1. Go to SAM.gov and select Contract Opportunities as the search domain.
  2. Open the filters panel and enter the 6-digit code in the NAICS field. Enter one code at a time so the results stay clean.
  3. Under Notice Type, include Solicitation, Combined Synopsis/Solicitation, Presolicitation and Sources Sought. Leave out Award Notice for this demand check.
  4. Under Set Aside, select Total Small Business and any program you hold (8(a), HUBZone, WOSB, SDVOSB).
  5. Add Place of Performance if you only travel within a region.
  6. Toggle between active and inactive notices so you can count the last 6-12 months, not just today's list.

What to look for: a code with notices posted every few weeks, including sources sought notices, gives you chances to show up early. Our sources sought response template shows how to answer those notices. Open five notices per code and read the statement of work. If the scope keeps including things you don't do, the code may be right but the buyers may not be.

Watch for this: the NAICS code on a notice is the contracting officer's choice. If it looks wrong for the work, SBA allows an appeal of the NAICS designation to its Office of Hearings and Appeals within 10 days of the solicitation's publication. Waiting until after award is too late.

What is the SBA size standard for my NAICS code?

Each NAICS code has its own SBA size standard, measured in either average annual receipts or number of employees. You may count as small under one code and large under another.

The official values are in 13 CFR 121.201, which you can read in the government's eCFR (updated daily) or via Cornell LII. SBA's downloadable summary table is labeled effective March 17, 2023. The values below are transcribed from 13 CFR 121.201 and match the size standards in that March 2023 table. The proposed August 2026 changes described below were not final at the time of the Holland & Knight summary. Confirm each value in the eCFR on the day you certify, because a final rule would update the regulation before older summary tables.

Source: 13 CFR 121.201 (eCFR); SBA table effective March 17, 2023.

How to measure yourself, per SBA:

  • Receipts-based codes: average your annual receipts over the latest five completed fiscal years. If you've been in business less than five years, multiply average weekly revenue by 52.
  • Employee-based codes: average the number of people employed per pay period over the latest 24 calendar months. That includes full-time, part-time and temporary staff.
  • Affiliates count. Add the receipts or employees of any affiliated businesses.

These limits may change. On August 20, 2026, SBA published proposed rules that would consolidate roughly 1,000 size standards into 338 and raise some limits sharply. According to Holland & Knight's summary, the proposal would raise 541512 from $34 million to $531 million. Comments closed September 21, 2026, and the rules weren't final at the time of that summary. Don't certify under the proposed numbers. For appeals, affiliation and a fuller table, see our SBA size standards by NAICS guide.

How to register NAICS codes in SAM.gov

Add your NAICS codes in the Assertions section of your SAM.gov entity registration and mark one as primary. Only list codes for work you can actually perform.

The SAM.gov entity registration checklist puts NAICS codes (and optional Product and Service Codes) under Goods and Services. Annual receipts and employee counts go under Size Metrics, both inside Assertions. SAM.gov uses those size metrics to show your small business status for each NAICS code in your representations and certifications. That's why accurate receipts matter as much as the codes themselves.

  1. Sign in at SAM.gov and open your entity registration from your Workspace to start an update. SAM.gov's entity registration page covers registering, updating and renewing. Menu labels can change, so follow the update option shown on screen rather than a saved click path. New registrants follow the full flow in our SAM.gov registration guide.
  2. Open Assertions → Goods and Services and search for each 6-digit code. Add your 3-5 final codes.
  3. In the NAICS table, select your primary NAICS code. Pick the code tied to most of your revenue and the one you're small under.
  4. Optionally add PSC codes for the items or services you sell. (PSCs describe what the government buys, while NAICS describes the industry.)
  5. Continue to Size Metrics and enter average annual receipts and number of employees, using SBA's averaging rules.
  6. In Reps and Certs, review the small business size table that SAM.gov generates for each code before you submit.

Check that table carefully. SAM.gov reported a system error that may have shown incorrect NAICS size standards in the FAR 52.219-1 and 52.212-3 tables. It affected registration renewals submitted between March 24 and July 22, 2026. If you renewed in that window and got the "Action Required: SAM.gov NAICS Code Size Table Discrepancy" email, follow its instructions before you bid.

Registration also has to be renewed every 365 days. Your annual renewal is a good time to drop codes that produced no notices and add any that came up in your searches.

Example (illustrative): say an owner-operator with three box trucks does local deliveries. They would compare 484110 and 492210 on USAspending with Place of Performance set to their metro area. If they only see a few awards under one code and steady awards under the other, the steady code becomes their primary.

Watch out for brokers. If you arrange freight but don't haul it, 488510 measures revenue differently from the trucking codes (see the footnote in the regulation). Its $20.0M limit is also lower than the trucking codes' $34.0M. Also, patient-transport and disability-shuttle work fits the 485991 definition rather than a trucking code, so search both before you decide.

How to find Missouri government contracts by NAICS code

Filter USAspending and SAM.gov by place of performance in Missouri to see federal awards for your codes. Separately, register on the state's MissouriBUYS portal, which uses different commodity codes. Keep federal NAICS research separate from state procurement.

Federal work performed in Missouri:

  1. In USAspending Advanced Search, set Place of Performance to Missouri and add your NAICS code and fiscal years.
  2. Check the category view by awarding agency to see which federal buyers spend in the state under your code.
  3. In SAM.gov Contract Opportunities, set Place of Performance to Missouri with the same NAICS code to see live notices.

State of Missouri contracts:

MissouriBUYS doesn't use NAICS for bid matching. The state uses the UNSPSC commodity/service code set. Vendors select UNSPSC codes at registration and get email notifications for bids tagged with those codes. Vendors who select no codes get no notifications. Bids issued on or after September 18, 2024 are posted on the MOVERS Bid Board. You can view it without registering, but you have to upload a signed W-9 before you can be approved as a vendor (MissouriBUYS FAQ).

Because MissouriBUYS matches bids on UNSPSC codes, your SAM.gov NAICS codes won't drive state notifications. Map each NAICS code to the matching UNSPSC codes yourself when you register on MissouriBUYS. Missouri businesses can also get counseling from the Missouri APEX Accelerator program through University of Missouri Extension.

Next steps

Once your codes are registered, the work shifts from choosing codes to keeping them current and getting in front of buyers.

This month:

  1. Answer at least one sources sought notice under your primary code. Responses are how contracting officers learn which small businesses can do the work, and our sources sought response template gives you a starting structure.
  2. If you renewed in SAM.gov between March 24 and July 22, 2026, recheck your reps and certs size table against the SAM.gov discrepancy alert.

Before 2027: two rule changes could affect your list. The 2027 NAICS revision may renumber or split codes, and SBA's August 2026 size standards proposal could change whether you count as small. Recheck both at your next SAM.gov renewal.

If you'd rather not do it alone: APEX Accelerators (formerly PTACs) are a program of the Department of Defense Office of Small Business Programs. Local centers such as Maryland's and Missouri's offer government contracting counseling. Services and any fees vary by center, so confirm with yours. Find a center at apexaccelerators.us. This suits first-time bidders who want someone to review their code choices and SAM.gov entries. Ask what's included before you count on a center for ongoing market research or daily pipeline tracking.

FAQ

Can I change my NAICS codes in SAM.gov after registering?

Yes. Start an update to your entity registration in SAM.gov (the entity registration page covers updates and renewals) and edit the list under Assertions → Goods and Services, the section the SAM.gov checklist assigns to NAICS codes. Review the size table in your reps and certs before you submit. If you hold a contract, ask your contracting officer whether a primary-code change affects it.

How many NAICS codes should a small business register in SAM.gov?

There's no required number. We suggest 3-5 that pass the award-data and size checks above. A short list keeps your profile believable to contracting officers searching for vendors. It also keeps your size representations to codes you've actually checked, since SAM.gov generates a size status for each code you list. You can add codes at your annual renewal as your work expands.

Do I need a NAICS code to bid on federal contracts?

FAR 4.1102 generally requires offerors to be registered in SAM.gov when they submit an offer, with listed exceptions. NAICS codes are part of that registration's Goods and Services assertions. Small business status for each bid depends on the NAICS code on that solicitation, so you need to know where you stand under it.

Is the NAICS code the same as a PSC code?

No. NAICS classifies the industry, while a Product and Service Code (PSC) describes the specific item or service being bought. Solicitations usually show both. SAM.gov registration asks for NAICS codes and lets you add PSCs optionally.

Does my primary NAICS code have to match the contract's NAICS code?

No. Your eligibility depends on the NAICS code the contracting officer assigns to that solicitation, and SBA ties the size standard to that designation. You must be small under that code, whatever your primary code is. Make sure the code is also in your SAM.gov list so your reps and certs cover it.

Where do I find the NAICS code on a solicitation?

FAR 19.303 requires the contracting officer to include the NAICS code and its size standard in solicitations above the micro-purchase threshold. On SAM.gov notices, the code appears in the notice's classification details alongside the PSC. If you can't find it in the notice, check the solicitation document's small business size representation clause.
