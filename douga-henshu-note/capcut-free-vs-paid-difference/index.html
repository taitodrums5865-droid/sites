CapCutは無料版のままでも、カット・テキスト・トランジションなどの基本の編集と書き出しができます。有料のCapCut Proにすると、4K/60fpsの書き出し、透かしなしの書き出し、Pro専用のテンプレートや素材、毎月のAIクレジット、1TBのクラウドストレージが使えるようになります（CapCut公式ヘルプ、CapCut料金ページ）。日本向け料金ページに出ているProの料金は月額2,700円・年額21,800円です（2026年10月時点・最新は公式で確認）。初めての人は無料版から始めて、「書き出すときにProの案内が何度も出る」ようになってから有料を考えれば間に合います。

この記事の要点

  • 無料版でもPro機能を試せるが、使った動画の書き出しには加入が必要
  • 料金ページのProは月額2,700円・年額21,800円
  • 解約は購入した場所で行い、更新日の24時間前までに済ませる

向いている人: CapCutを無料で使うか有料にするか迷っている初心者

あなたに合うのはどれ?

ほとんどの初心者は、まず無料版で十分です。Pro機能は無料版でも試せて、お金が必要になるのは「Pro機能を使った動画を書き出すとき」だからです（CapCut公式ヘルプ）。

決めるときの目安は次のとおりです。

  • 無料版で十分な人: 1080pで書き出せればよい人、Proマークのついた素材を使わなくても作れる人
  • Proを考えてよい人: 4K/60fpsで書き出したい人、Pro専用のテンプレートやエフェクトを毎回使う人、AI機能を月に何度も使う人
  • Proが向いていない人: 月に1〜2本しか作らない人、自動更新の管理が苦手な人（解約し忘れると課金が続きます）

無料版とCapCut Proの機能の違い

いちばん大きな違いは、Pro専用の機能や素材を使った動画を書き出せるかどうかです。無料版でもPro機能を画面上で試すことはできますが、使ったまま書き出そうとすると加入の案内が出ます（CapCut公式ヘルプ）。

書き出すときにProの案内が出る条件

公式ヘルプでは、使っている端末ごとに次の場合に加入の案内が出ると説明されています（CapCut公式ヘルプ）。

  • CapCut Online（ブラウザ版）: バッジのついたテンプレート・エフェクト・フォント・音楽・ステッカーを使ったとき、AI生成機能を使ったとき、プレミアムのトランジションやLUT（色を変える設定）を使ったとき
  • CapCut Desktop（パソコン版）: 「4K」「60fps」などを選んだとき、Pro専用のタグがついた素材を使ったとき
  • CapCut Mobile（スマホ版）: Pro素材を使ったとき、15分以上の動画を書き出すとき（地域によって違います）、透かしを消す設定を選んだとき

公式ページ同士で書いてある内容が違う点

CapCutの公式ページは、ページによって数字が違います。たとえば、PC版Proの紹介ページには「月額2,180円・年額19,800円」と書かれています（CapCut公式・PC向けPro紹介）。一方で、日本向け料金ページには「月額2,700円・年額21,800円」と出ています（CapCut料金ページ）。AIクレジットの数も、料金ページは「毎月800」ですが、新しい料金についてのヘルプには「550から1,200に増加」と書かれています（CapCut公式ヘルプ）。

公式ヘルプには「料金は地域、デバイス、プロモーションによって変わる」とも書かれています（CapCut公式ヘルプ）。最後は、支払う直前の購入画面に出る金額を正しいものとして見てください。

月払いと年払い、どちらがいい?

1年続けるつもりなら、年払いのほうが安くなります。料金ページの金額で計算すると、月払いを12か月続けると2,700円×12＝32,400円です。年払いの21,800円と比べると、差は10,600円になります。

ただし、年払いには注意点があります。CapCutの購入は基本的に返金できないと公式ヘルプに書かれています（CapCut公式ヘルプ）。途中で使わなくなっても戻ってこないと考えて、迷うならまず月払いか無料トライアルで確かめるほうが安全です。

支払いの方法

ブラウザ版で加入するときは、クレジットカード・デビットカード、PayPal、Apple Pay、Google Payが使えると公式ヘルプに書かれています（CapCut公式ヘルプ）。スマホアプリから加入した場合は、iPhoneならApp Store、AndroidならGoogle Playでの支払いになります。

無料版で透かしやProの案内が出るときの直し方

無料版のまま書き出したいなら、Pro素材を外して、最後に自動で入るロゴのクリップを消すのが基本です（CapCut公式ヘルプ）。

手順

  1. 書き出しの画面でProの案内が出たら、いったん閉じて編集画面に戻ります。デスクトップ版の案内は「CapCut Pro is required to export this video.」、ブラウザ版の案内は「This video uses CapCut Pro content.」という文言だと公式ヘルプに書かれています（CapCut公式ヘルプ）。
  2. タイムラインを見て、Proのマークやバッジがついたエフェクト・フォント・音楽・ステッカー・トランジションを探します。
  3. 見つけたものを削除するか、無料の素材に入れかえます。
  4. デスクトップ版では、書き出し設定の解像度とフレームレートを確認します。「4K」「60fps」を選んでいたら、1080pや30fpsに戻します。
  5. タイムラインのいちばん後ろを確認します。CapCutのロゴが入った短いエンディングのクリップが自動で入っていたら、削除します（CapCut公式ヘルプ）。
  6. もう一度書き出します。

つまずきやすい所

  • Pro素材がどこにあるか分からない: テンプレートから作った動画は、テンプレートの中にPro素材が入っていることがあります。公式ヘルプでも、テンプレートや素材によって透かしが自動で付くことがあり、自分で一から編集すれば透かしなしで書き出せると説明されています（CapCut公式ヘルプ）。見つからないときは、テンプレートを使わずに新しいプロジェクトで作り直すのが確実です。
  • Pro素材を外したら透かしが付いた: 公式ヘルプには、Pro素材を外して無料で書き出すと透かしが付く場合があると書かれています（CapCut公式ヘルプ）。エンディングのクリップが残っていないか、もう一度確認してください。

ほかのソフトも含めた「透かしが消える条件」の比べ方は、動画編集ソフトの無料版、透かしが消える条件とはにまとめています。

CapCut Proの始め方と7日間無料トライアル

Proは、どの端末から加入しても、加入後はすべての端末でPro機能が使えます（CapCut公式ヘルプ）。

7日間無料トライアルの条件

公式ヘルプによると、次の条件に当てはまる人は7日間無料でProを試せます（CapCut公式ヘルプ）。

  • 新しく使い始める人で、トライアルの対象地域に住んでいる
  • これまでにProを契約したことがない（過去のトライアルも含む）
  • アカウントに問題がない

トライアルを始めるときは、クレジットカードなどの支払い方法の登録が必要です。トライアル中はお金がかかりませんが、7日たつと自動で課金されます（CapCut公式ヘルプ）。

加入の手順（公式ヘルプの英語表記どおり）

公式ヘルプは英語で説明されているので、ボタン名はそのまま書きます。日本語で表示している場合は、言い方が少し違うことがあります（CapCut公式ヘルプ）。

パソコン版（Windows・Mac）

  1. CapCutのデスクトップアプリを開いて、ログインします。
  2. 右上の「Account」から「Upgrade to Pro」をクリックします。
  3. 「Join CapCut Pro」をクリックします。
  4. 自動でブラウザが開いて、CapCutのWebのPro申し込みページに移ります。
  5. プランを選んで、支払いを済ませます。

スマホ版（iPhone・Android）

  1. CapCutアプリを開きます。
  2. 右下の「Me」タブをタップします。
  3. ニックネームの横の「Join CapCut Pro」をタップします。
  4. 「Purchase」または「Subscribe」をタップすると、App StoreかGoogle Playの画面に移ります。

つまずきやすい所: スマホで加入すると、支払いはApple・Googleの管理になります。パソコンでは加入した場所がCapCutのWebになります。解約するときは、加入したのと同じ場所で手続きするので、どこで加入したかをメモしておいてください。

CapCut Proの解約方法

解約は「加入した場所」で行い、更新日の24時間前までに済ませます。24時間前を過ぎると次の期間の料金がかかると公式ヘルプに書かれています（CapCut公式ヘルプ）。

iPhone・iPadの場合

Appleの公式サポートに書かれている手順です（Apple公式サポート）。

  1. 「設定」を開いて、いちばん上のユーザ名をタップします。
  2. 「サブスクリプション」をタップします。
  3. CapCutをタップします。
  4. 「サブスクリプションをキャンセル」をタップします。

つまずきやすい所: 下までスクロールしないと「サブスクリプションをキャンセル」が見えないことがあります。ボタンがなく、期限切れのメッセージが赤字で出ていれば、もう解約は済んでいます（Apple公式サポート）。

Androidの場合

Googleの公式ヘルプに書かれている手順です（Google Playヘルプ）。

  1. AndroidでGoogle Playの定期購入の画面を開きます。
  2. CapCutを選びます。
  3. 「定期購入を解約」をタップします。
  4. 画面の案内に沿って進めます。

つまずきやすい所: アプリを削除（アンインストール）しても、定期購入は解約されません（Google Playヘルプ）。

パソコン・ブラウザで加入した場合

CapCutにログインして、アカウントのサブスクリプション管理画面で自動更新を止めます。CapCutの日本語の解約ヘルプには、端末ごとの細かい画面の手順までは書かれていません。画面が見つからないときは、ヘルプにあるとおりサポートに問い合わせてください（CapCut公式ヘルプ）。

返金について

CapCutのサブスクリプションはバーチャルグッズとして扱われるので、基本的に返金はできないと公式ヘルプに書かれています。特別な事情があるときは、異議を申し立てることはできます（CapCut公式ヘルプ）。

仕事で使う前に確認したい「商用利用」

Proに入れば、どの素材でも仕事に使えるわけではありません。CapCutの素材ライセンス契約では、素材ごとに使える範囲が決まっています（CapCut素材ライセンス契約）。

  • 「commercial use」などのマークがついた素材は、宣伝・マーケティング・広告に限って商用に使えます
  • 非商用の素材は、個人的で商用ではない目的にしか使えません
  • サブスクに入ると、一部の有料素材を期間内に追加料金なしで使えます

たとえば、お店の宣伝動画や仕事の案件にCapCutの音楽やテンプレートを使うときは、素材ごとにマークを確認してください。迷う素材は、自分で撮った映像や、権利がはっきりした素材に入れかえるほうが安全です。

よくある質問

CapCutは無料版だけで使い続けられますか?

使い続けられます。料金ページで無料版は0円で、基本の機能が使えると案内されています。Proのマークがついた素材や、4K・60fpsの書き出しを使わなければ、加入しなくても書き出せます。

無料版で書き出すと必ず透かしが付きますか?

必ずではありません。公式ヘルプによると、透かしが付くのはテンプレートや一部の素材を使ったときで、自分で一から編集すれば透かしなしで書き出せます。最後に自動で入るロゴのクリップは削除してください。

7日間無料トライアルのあと、勝手にお金はかかりますか?

かかります。トライアルを解約しないと、7日後に登録した支払い方法で自動で課金されます。課金されたくないときは、更新の24時間前までに、加入した場所（App Store・Google Play・CapCut Web）で解約してください。

スマホで加入したProはパソコンでも使えますか?

使えます。公式ヘルプには、加入後はすべての端末でPro機能が使えると書かれています。ただし解約するのはスマホ側（App StoreかGoogle Play）なので、加入した場所を忘れないようにしてください。

CapCutのアプリを消せば解約になりますか?

なりません。Google Playのヘルプにも、アプリをアンインストールしても定期購入は解約されないと書かれています。必ず解約の手続きをしてください。
