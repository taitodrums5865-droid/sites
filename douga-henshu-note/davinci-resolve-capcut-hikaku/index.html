DaVinci ResolveとCapCutを比べると、スマホで撮った縦の短い動画をテンプレートや自動字幕で速く仕上げたい人にはCapCut、YouTubeの長い動画や作品で画質・色・音までこだわりたい人にはDaVinci Resolveが合います。どちらも無料で始められます。違いが出るのは「何に時間をかけたいか」と「手持ちのパソコン」の2点です。

この記事の要点

  • 縦の短い動画を速く作るならCapCut、画質と色ならDaVinci
  • Resolve無料版はStudio専用機能を使うと透かしが入る
  • CapCutの公式料金ページのプランは4つ(2026-10-26)

DaVinci ResolveとCapCutどっちを選ぶべき?

SNS向けの短い動画をスマホ感覚で作るならCapCut、作品としての画質や色にこだわるならDaVinci Resolveです。

違いは、ソフトがどこに力を入れているかにあります。CapCutのデスクトップ版の公式ページが前に出しているのは、トレンドのエフェクト、字幕の自動生成、縦横比の変更です(CapCut デスクトップ版)。一方のDaVinci Resolveは、エディット・カラー・Fusion(合成)・Fairlight(音声)・デリバー(書き出し)などが1本のアプリにまとまっていて、色と音の仕上げまで同じ画面の流れで進められます(DaVinci Resolve エディット)。

たとえば、次のような場面で考えてみてください。

  • 部活の練習風景を30秒のリールにする → CapCut。テンプレートに素材を入れて、自動字幕を付ければ形になります
  • 旅行の映像を15分のVlogにまとめ、夕焼けの色味を整えたい → DaVinci Resolve。カラーページで色を細かく調整できます
  • 会社の商品紹介を、横長の本編と縦長の切り抜きの両方で出す → 本編をDaVinci Resolve、切り抜きをCapCutと分けるやり方もあります

迷ったときの判断の基準

次の2つの問いに順に答えてください。

  1. 出来上がる動画の大半は60秒以下で縦長か?
  2. はい → CapCut
  3. いいえ → 問い2へ
  4. 手持ちのパソコンは、Windowsならメモリ16GB以上、Macならアップルシリコン(M1以降)か?
  5. はい → DaVinci Resolve
  6. いいえ → CapCut

つまり、問い1が「いいえ」(縦の短い動画が中心ではない)で、問い2が「はい」(パソコンが最低ラインを満たす)のときだけ、DaVinci Resolveを入れてみる価値があります。それ以外はCapCutから始めてください。どちらも無料なので、両方入れて比べても費用はかかりません。

つまずきやすい所

DaVinci Resolveを選んだ初心者がよく止まるのは、最初に開いた画面のボタンの多さです。全部を覚える必要はありません。最初は「カット」か「エディット」のページだけ使い、カラーやFusionのページは開かない、と決めてしまうと進めやすくなります。CapCutのほうでは、テンプレートやエフェクトに有料のものが混ざっていて、書き出す段階で初めて気づくことがあります。対策は料金の章に書きました。

AI機能の違い

どちらにもAI機能はありますが、向いている方向が違います。CapCutのAIは字幕の自動生成や、人物・会話で素材を探す機能など、編集を速く終わらせるためのものです(デスクトップ版)。CapCutでAI機能をしっかり使うには、ProかUltraのプランが前提になります(料金)。

DaVinci ResolveのAI(DaVinci AI Neural Engine)は、Magic Maskやノイズ除去など仕上げの品質を上げる道具が中心です。こちらは多くがStudio版の機能です(製品ページ)。「AIで楽をしたい」ならCapCut、「AIで画をきれいにしたい」ならDaVinci Resolve Studio、と覚えておくと選びやすくなります。

お金のかかり方の違い

CapCutは月額か年額の支払い、DaVinci Resolve Studioは一度払えば終わりの買い切りです。たとえばCapCut Proを年額で2年使うと21,800円×2=43,600円になり、Studioの40,980円(2026年10月時点の割引適用後の表示価格)を少し上回ります。ただし無料版で足りるなら、どちらも0円のままです。買い切りと月額の損益の考え方は動画編集ソフト買い切り比較で表にしています。

DaVinci Resolve無料版の使い方の手順は?

公式サイトからダウンロードし、新規プロジェクトを作って、読み込み→カット→書き出しの順に進めれば最初の1本が作れます。

ここでは最初の1本を書き出すまでの最短の流れだけ書きます。画面の名前は日本語表示のときのものです(日本語にする方法はよくある質問にあります)。

ダウンロードとインストール

  1. DaVinci Resolve 製品ページを開き、「無料ダウンロード」を押します
  2. 「DaVinci Resolve」(無料版)の欄で、使っているOS(Windows・Mac・Linux)を選びます。「DaVinci Resolve Studio」のほうは有料版なので押しません
  3. 登録フォームが出たら名前やメールアドレスを入れてダウンロードします
  4. ダウンロードしたファイルを開き、画面の案内どおりにインストールします
  5. インストール後、DaVinci Resolveを起動します

つまずきやすいのは手順2です。Studioのほうを入れると、起動時にライセンスキー(アクティベーションコード)を求められます。キーを持っていないなら、無料版を入れ直してください。

最初の1本を作る

  1. 起動すると「プロジェクトマネージャー」が開きます。「新規プロジェクト」を押し、名前(たとえば「test01」)を入れて「作成」を押します
  2. 画面下のページ切り替えから「カット」か「エディット」を選びます
  3. 撮った動画ファイルを、画面左上の「メディアプール」にドラッグして読み込みます
  4. メディアプールのクリップをタイムラインにドラッグします
  5. いらない部分の始まりと終わりで切り、削除します。エディットページでは「ブレード編集モード」(キーボードのB)で切れます
  6. 画面下の「デリバー」ページを開き、レンダー設定でプリセット(たとえば「YouTube」)を選びます
  7. 保存先とファイル名を決め、「レンダーキューに追加」を押します
  8. 右側のレンダーキューで「すべてレンダー」を押すと書き出しが始まります

つまずきやすい所と直し方

  • 読み込んだときに「フレームレートが違う」と聞かれる → 撮った素材に合わせて変更してかまいません。スマホの動画なら、変更を選ぶのが一般的です
  • 再生がカクカクする → 再生メニューの「タイムラインプロキシ解像度」を下げると軽くなります
  • 手順8で書き出したのにファイルが見つからない → 手順7で決めた保存先を、デリバーページの「場所」の欄で確かめます

この流れをもっとていねいに追いたい人は、このサイトのDaVinci Resolve無料版の使い方、最初の一歩を続けて読んでください。公式の日本語ガイド「DaVinci Resolve 20 ビギナーガイド」も無料で手に入ります(公式トレーニング)。ガイドはバージョン20向けですが、基本操作はほぼ同じです。

DaVinci Resolve無料版に透かし(ウォーターマーク)は入るのか

ふつうの書き出しでは入りません。Studio版専用の機能を使ったときだけ、その部分に透かしが出ます。

無料版でできることについて、公式は次のように書いています。

「60fpsまでのほぼすべての8-bitフォーマットおよびUltra HD 3840x2160までの解像度に対応」(DaVinci Resolve 製品ページ)

つまり4K相当(UHD)・60fpsまでなら、無料版のまま透かしなしで書き出せます。透かしが出るのは、Studio専用のResolveFXやAI機能を、無料版のタイムラインに入れた場合です。無料版でもそうしたエフェクトは試せますが、プレビューと書き出しに「DaVinci Resolve Studio」の透かしが表示されます(Blackmagic フォーラムの関連スレッド)。なお、この透かしの仕組みは公式の製品ページには書かれていません。

透かしが出たときの直し方

  1. エフェクトのライブラリで、名前の横に「Studio」などの印が付いた効果を探します
  2. タイムラインのクリップを選び、インスペクタでその効果を削除します
  3. カラーページのノードに入れた効果も見て、Studio専用のものがあれば消します
  4. もう一度デリバーページで書き出します

よくある原因は、ノイズ除去や一部のResolveFXを「試しに」入れたまま忘れることです。透かしの条件はソフトごとに違い、CapCutなどほかのソフトの条件は動画編集ソフトの無料版、透かしが消える条件とはで並べて比べています。

CapCut側の透かしは?

CapCutの公式ヘルプには、無料アカウントの4K書き出しについて次の一文があります。

「無料アカウントは、4 Kのエクスポートにウォーターマークやビットレートの制限がある場合があります。」(CapCut ヘルプ)

「場合があります」という書き方で、どの条件で出るかまでは書かれていません。SNSに出すなら1080pで足りることが多いので、無料版では1080pで書き出すのが確実です。

初心者がStudioを買う理由になりやすいのは、次の2つでしょう。

  • iPhoneなどで撮った10-bitのHDR動画を、そのまま扱いたい
  • 暗い場所で撮った映像のノイズを、AIのノイズ除去で消したい

この2つに当てはまらないなら、無料版のままで困ることはあまりありません。Studioを買うかどうかの細かい判断は、このサイトのDaVinci Resolve無料版と有料版の違いにまとめました。

Studioを買う前の注意点

40,980円という価格は、公式ページで割引適用後の価格として表示されているものです(2026年10月26日時点)。割引の期間はページにありません。買う時期によって値段が変わる可能性があるので、購入の直前に公式ページで通常価格と割引の有無を確かめてください。また、Studioの力を引き出すにはGPUの性能も要ります。高度なAIツールの目安はGPUメモリ(VRAM)16GBとまとめられていて(ClipVerdict の要件まとめ)、ソフトだけ買っても手持ちの機械では重い、ということが起こり得ます。

CapCutは無料で使えるのか、料金はどうなっているか

基本編集と無料テンプレートは0円で使えます。AI機能・プレミアムテンプレート・1TBの保存領域は有料プランからです。

公式の料金ページに載っているプランは4つです(CapCut 料金・2026-10-26に数えた)。

向いている人・向いていない人

CapCut Proが向いているのは、週に何本もSNS動画を出す人や、自動字幕などのAI機能で作業時間を削りたい人です。逆に、月に1〜2本しか作らない人や、AI機能をほとんど使わない人には、毎月の支払いのほうが重くなります。その場合は無料版で十分か、買い切りのソフトを考えたほうが得です。無料と有料の差は、CapCut無料と有料の違いでくわしく比べています。

つまずきやすい所: 有料素材と商用利用

編集中に選んだテンプレートやエフェクトがPro向けで、書き出しのときに有料プランを求められることがあります。防ぐには、素材を選ぶときにプレミアムの印がないかを先に見ます。

仕事や収益化を考える動画なら、素材の使える範囲にも注意が要ります。CapCutの公式ヘルプによると、PC版ではフォントライブラリの右上付近に「商用利用」のフィルターやトグルがあり、オンにすると商用で使える素材に絞り込めます(CapCut ヘルプ)。音楽も同じで、使う前に用途の許可を確かめるよう公式は案内しています(CapCut 著作権フリーの音楽)。

動画編集を始めるのに必要なパソコンのスペックは?

DaVinci Resolve 21は、Windowsならメモリ16GB・GPUメモリ4GB、Macならアップルシリコンが最低ラインとされています。CapCutはそれより軽い機械でも動きます。

DaVinci Resolveの要件は、バージョンごとにBlackmagic Designがダウンロードに添える「Readme」(説明書)に載ります。製品ページには要件の数字が書かれていないので、上の表は第三者がReadmeをまとめたものから取りました。入れる前に、ダウンロードしたファイルのReadmeで最新の数字を確かめてください。CapCutの公式ページにはCPUやメモリの細かい要件がありません。

自分のパソコンで判断する

  1. Windowsなら「設定」→「システム」→「バージョン情報」で「実装RAM」を見ます。Macならアップルメニューの「このMacについて」で「チップ」と「メモリ」を見ます
  2. Windowsでメモリが16GB未満、またはMacがIntelのチップなら、DaVinci Resolve 21は最低ラインに届きません。CapCutから始めます
  3. 最低ラインは超えていても、4Kの素材で色まで整えるなら、メモリ32GBあると安心です

注意したいのは、Intel Macです。DaVinci Resolve 21はアップルシリコンだけの対応とまとめられていて、古いMacでは入れても動かない可能性があります。これから買う人は動画編集パソコンのスペック、最低限の目安はで予算別の目安を見てから選ぶと、買い直しを防げます。

初心者は何から編集を学び始めればいいか

カットと書き出しだけを最初に覚え、次にテロップとBGM、最後に色やトランジションへ進む順番が無理のない進め方です。

どちらのソフトでも、最初に覚えることは同じです。順番の目安を表にしました。

  1. スマホで1分の動画を3本撮ります(散歩、料理、ペットなど何でもかまいません)
  2. 3本をつなぎ、いらない部分を切って60秒以内にします
  3. 書き出して、スマホで再生して確かめます
  4. 次の日、同じ動画に冒頭のタイトルと字幕を付けて書き出し直します

ポイントは段階1を「何も見ずにできる」まで繰り返すことです。色の調整は、カットに慣れてから触れば十分間に合います。DaVinci Resolveなら、公式トレーニングのページに19〜93分の動画講座と練習用の素材があります(公式トレーニング)。

よくある質問

DaVinci Resolve 無料版の透かしはいつ付くのか

Studio版専用のエフェクトやAI機能をタイムラインに入れたときだけ付きます。ふつうのカットや色の調整、Ultra HD・60fpsまでの書き出しでは付きません。透かしが出たら、Studio専用の効果を消して書き出し直してください。

DaVinci Resolve freeは商用利用できるか

公式の製品ページには、無料版での仕事の利用を禁じる記述は見当たりません(2026年10月26日時点)。ただ、条件はインストールのときに出る使用許諾契約が正式なものです。仕事で使う前に一度読んでおくと安心です。BGMやフォントなど、ソフト以外の素材の権利は別に確かめる必要があります。

DaVinci Resolve 無料版で日本語化はできるか

できます。環境設定の「ユーザー」タブにある「UI設定」で、言語を日本語に切り替えます。切り替えたあと、ソフトを起動し直すと反映されます。公式の「ビギナーガイド」にも日本語版があります(公式トレーニング)。

CapCutはパソコン版とスマホ版で機能は同じか

同じではありません。書き出しの画面を例にとると、PC版は右上の「エクスポート」から解像度・フレームレート・ビットレートを決めます。スマホ版は編集画面右上の解像度の表示をタップして720P〜4Kから選びます(CapCut ヘルプ)。有料プランの中身は機器の間で共通ですが、使える機能はアプリのバージョンでも変わるので、気になる機能はそれぞれのアプリで確かめてください。
