DaVinci Resolveの無料版と有料版(DaVinci Resolve Studio)の違いは、書き出しの上限と、AIなど上位機能が使えるかどうかです。無料版はUHD 3840×2160・60fpsまで書き出せて基本の編集は一通りでき、Studioは32K・120fpsやAIノイズ除去などが使える買い切り版で、通常51,980円(税込)、2026年11月20日までは40,980円です(公式・PRONEWS、2026年10月時点・最新は公式で確認)。YouTubeやSNS用の動画を作り始める段階なら、無料版で足ります。

この記事の要点

  • 無料版の書き出し上限はUHD 3840×2160・60fpsまで
  • Studioは買い切り。2026年11月20日まで40,980円
  • Studio専用エフェクトを無料版で使うと透かしが出る

向いている人: DaVinci Resolveを無料で始めるか有料版を買うか迷っている初心者

あなたに合うのはどれ?

初心者なら、まず無料版から始めてください。無料版で作ったプロジェクトは、Studioを入れた後もそのまま開いて続きを作業できます。迷いやすい状況ごとに、最初の選択と開くページを並べました。

決め方は1つだけ覚えておけば大丈夫です。「無料版のこの上限、またはこの機能のせいで作業が止まった」と言えるならStudioを買う。言えないうちは無料版のままでかまいません。

DaVinci Resolve 無料版と有料版(Studio)は何が違うのか

一言でいえば、無料版はほぼ全部の作業ができる無料ソフト、Studioはそこに書き出しの上限解除とAI機能を足した買い切り版です。公式は無料版を「編集、カラー、VFX、モーショングラフィックス、オーディオをすべて融合した」オールインワンのソフトと説明しています。Studioは無料版の全機能に加えて「DaVinci AI Neural Engine、さらに多くのResolveFX、時間的/AI空間的ノイズ除去、テキストベースの編集」などを使えると書かれています(DaVinci Resolve 公式、2026年10月時点)。

「You can use it to edit and finish up to 60 fps in resolutions as high as Ultra HD 3840 x 2160」(DaVinci Resolve Studio 英語版公式)

訳すと「(無料版では)Ultra HD 3840×2160までの解像度、60fpsまでで編集して仕上げられる」という意味です。

公式ページの記載をもとに、違いを表にまとめました(DaVinci Resolve 21、2026年10月時点)。

出典はStudioの機能比較ページと製品トップページです。

Studioの比較ページでAI(DaVinci AI Neural Engine)の機能として名前が挙がっているものを数えると、8つありました。顔認識、Super Scale、スピードワープリタイム、デインターレース処理、Magic Mask、スマートリフレーム、オブジェクト除去、シーンカット検出です(Studioの機能比較・2026-10-25に数えた)。英語版のページは、Studioで増える機能を「over 100 advanced features」(100以上の上位機能)とまとめています(英語版公式)。

裏を返すと、カット・テロップ・BGM・色補正・書き出しという動画作りの基本は、全部無料版で済みます。上位の検索結果でも「初心者には無料版で十分」という結論がほとんどでした。表の右側の機能は、どれも「困ってから欲しくなる」ものです。

書き出し解像度・フレームレートはどこまで無料版で対応しているのか

無料版はUHD 3840×2160・60fpsまで書き出せます。YouTubeの4K動画やSNSの縦動画なら、この範囲に収まります。Studioは32K・120fpsまで対応しています(Studioの機能比較、2026年10月時点)。

よく使うサイズに当てはめると、こうなります。

つまずきやすい所:60fpsと8-bitの意味

フレームレートの上限は、書き出しだけの話ではありません。公式の表現は「60fpsまでで編集して仕上げられる」です。たとえばスマホで120fpsのスロー映像を撮っても、無料版では120fpsのタイムラインで仕上げることはできません。60fps以下のタイムラインでスローモーション素材として使う形になります。

色の深さにも差があります。無料版は「60fpsまでの8-bit形式」、Studioは「120fpsまでの10-bit映像」に対応すると公式は書いています(DaVinci Resolve 公式)。空のグラデーションのような色の変化を強く補正すると、8-bitでは縞(バンディング)が出やすくなります。SNS投稿で問題になる場面は多くありません。一方、10-bitで撮れるカメラの映像を仕事で納品するなら、ここが乗り換えの理由になります。

書き出し設定を変えても上限は外れない

デリバーページの解像度の欄に大きな数字を入れても、無料版の上限は外れません。DCI 4Kや8Kで納品するよう頼まれたら、その時点でStudioが必要だと考えてください。

無料版で使えない編集・エフェクト機能は何か

無料版に無いのは、AIで処理する機能と、プロの納品で使う機能です。ノイズ除去、Magic Mask、ボイスアイソレーション、テキストベースの編集、HDR(Dolby Vision・HDR10+)、ステレオスコピック3DがStudio限定です(Studioの機能比較、2026年10月時点)。

「時間的ノイズ除去およびAIベースの空間的ノイズ除去ツール」(DaVinci Resolve Studio 公式)

公式ページの言葉をもとに、初心者が使いそうな場面と並べて分類しました。

ResolveFX(エフェクト)の数も違います。Studioの比較ページは、Studioで使えるResolveFXを「45種類以上」としています。例として挙がっているのは、レンズフレア、ダート除去、フリッカー除去、シャープニング、パッチリプレーサー、オブジェクト除去などです(Studioの機能比較)。

初心者が気づくのは「音」と「暗い映像」

上の表で、初心者が最初に「欲しい」と思いやすいのは2つです。1つは声の聞き取りやすさ(ボイスアイソレーション)。もう1つは暗い映像のノイズ(ノイズ除去)。外で話す動画や夜の撮影が多い人ほど、早めにこの差に気づきます。

逆に、HDR・立体・スクリプト・リモートは、仕事の環境が決まってから考えれば十分な機能です。

DaVinci Resolve 無料版 透かし(ウォーターマーク)は入るのか

無料版で普通に書き出した動画には、透かしは入りません。ただし、Studio専用のエフェクトやAI機能を無料版のタイムラインで使うと、映像に「DaVinci Resolve Studio」の透かしが表示されます(DaVinci Resolve Club・Miracamp)。

無料版では、Studio専用のResolveFXも試しに当てられます。その代わり、プレビューに透かしが重なる仕組みです。初心者がエフェクト一覧を上から順に試すと、知らないうちにStudio専用のものを当ててしまい、「無料版なのに透かしが入った」と驚くことがあります。

透かしが出たときの直し方

  1. 透かしが出ているクリップを、タイムラインで選びます。
  2. 画面右上の「インスペクタ」を開き、当てたエフェクト(ResolveFX)を確かめます。カラーページで当てた場合は、そのノードを確かめます。
  3. Studio専用のエフェクトを削除するか、無効にします。
  4. もう一度プレビューして、透かしが消えたことを確かめてから書き出します。

Studioのライセンスでそのまま書き出す方法もあります(Miracamp)。

もう1つの透かし:他社のプラグインやテンプレート

他社が売っている有料プラグインやテンプレートにも、体験版の間は自社のロゴや透かしが入るものがあります。この透かしはDaVinci Resolveとは関係がありません。その製品の購入やライセンス登録で消えるので、配布元の説明を確かめてください。

ほかのソフトの無料版で、どんな条件で透かしが消えるのかは、動画編集ソフトの無料版、透かしが消える条件にまとめています。

どんな人がStudio(有料版)に乗り換える必要があるのか

乗り換えが必要なのは、無料版の上限か、Studio限定の機能のせいで作業が止まる人です。具体的には次のどれかに当てはまる人が当てはまります。

8K・DCI 4Kなど、UHDを超える解像度で納品する無料版はUltra HD 3840×2160まで依頼主にUHDでよいか確かめる

条件の出典はStudioの機能比較と製品トップです。

たとえばこんな場面

  • たとえば週1本のYouTube動画を1080pで投稿している人。上限には当たりません。声の雑音に困っていなければ、無料版のままで十分です。
  • たとえば夜のイベントを撮って、知り合いに映像を渡す人。ノイズ除去が使えないと、暗い所のザラつきが目立ちます。編集の時間がこの作業でふくらむなら、Studioを考える場面です。
  • たとえば企業から「納品はDCI 4K、10-bit」と頼まれた人。無料版では条件を満たせないので、Studioが必要です。

Studioのデメリットも知っておく

Studioを買えば、全部が速くなるわけではありません。AI機能は、パソコンの性能を多く使います。上級のAI機能には16GB以上のVRAMが必要と紹介されています(ClipVerdict、Resolve 21のReadmeをもとにした説明)。古いノートパソコンにStudioを入れても、AI機能が重くて実用にならないことがあります。買う前に、まず無料版で自分のパソコンの動きを確かめてください。

DaVinci Resolve 無料版の使い方の基本手順

無料版と有料版の基本の流れは同じです。インストールして、プロジェクトを作り、素材を入れ、カットし、色と音を整えて、書き出します。画面の下に並ぶページ(メディア、カット、エディット、Fusion、カラー、Fairlight、デリバー)を、左から順に使うのが基本です。

1. ダウンロードとインストール

  1. DaVinci Resolve 公式ページを開き、ダウンロードのボタンを押します。
  2. 一覧から無料の「DaVinci Resolve 21」を選びます。名前に「Studio」と付いたほうは有料版です。
  3. 登録フォームに名前などを入れてダウンロードし、インストーラーを開いて案内どおりに進めます。

ここで一番つまずくのが、2の選択です。「DaVinci Resolve Studio 21」を入れてしまうと、起動したときにアクティベーションキー(ライセンスキー)を求められます。キーを持っていなければ、無料の「DaVinci Resolve 21」を入れ直してください。

2. プロジェクトを作る

  1. 起動すると「プロジェクトマネージャー」が開きます。
  2. 「新規プロジェクト」を押して名前を付け、「作成」を押します。
  3. 解像度とフレームレートは、画面右下の歯車(プロジェクト設定)で決めます。たとえばYouTube用なら1920×1080・30fps、縦動画なら1080×1920です。

フレームレートは、素材を入れる前に決めるのが安全です。タイムラインに素材を入れた後では変えにくくなります。

3. 素材を入れてカットする

  1. 下の「メディア」または「カット」ページで、動画ファイルをドラッグして読み込みます。
  2. 「エディット」ページで、素材をタイムラインに並べます。
  3. いらない部分は、ブレード(カミソリのアイコン)で切って削除します。

4. 色と音を整える

  1. 「カラー」ページで、明るさや色味を調整します。
  2. 「Fairlight」ページか「エディット」ページで、BGMと声の音量を合わせます。

このとき、エフェクトの一覧からStudio専用のものを当てると、透かしが出ます。直し方は、透かしの見出しに書いた手順のとおりです。

5. 書き出す

  1. 一番右の「デリバー」ページを開きます。
  2. 左上のレンダー設定で「YouTube」などのプリセットを選ぶか、形式と解像度を指定します。
  3. ファイル名と保存先を決めて「レンダーキューに追加」を押します。
  4. 右側のレンダーキューで「すべてレンダー」を押すと、書き出しが始まります。

「レンダーキューに追加」を押しただけでは、まだ書き出されません。4の「すべてレンダー」を押し忘れて、ファイルが無いと戸惑う人がよくいます。

各ページの画面の見方は、DaVinci Resolve無料版の使い方、最初の一歩で順に説明しています。

DaVinci Resolve 無料版と有料版、初心者はどちらを選ぶべきか

初心者には無料版をおすすめします。理由は2つあります。基本の作業が全部無料版でできること。それに、自分のパソコンで快適に動くかを、お金をかけずに確かめられることです。

ここで見落としやすいのが、パソコンの要件です。DaVinci Resolveは、ほかの無料編集ソフトより重いソフトです。Resolve 21の最小要件として、次の数字が紹介されています(ClipVerdict、Resolve 21.0.4のReadmeをもとにした説明、2026年8月時点)。

DaVinci Resolve 無料版と有料版、初心者はどちらを選ぶべきか
OS最小要件の目安
WindowsWindows 10 Creators Update以降、メモリ16GB(Fusionを使うなら32GB)、VRAM 4GB以上のGPU
MacAppleシリコン、macOS 15 Sequoia以降、メモリ8GB(Fusionを使うなら16GB)
LinuxRocky Linux 8.6、メモリ32GB、VRAM 4GB以上の単体GPU

この要件は無料版とStudioで共通です。違いは、Studioだと複数GPUやH.264/H.265のハードウェア処理といった性能を引き出す機能が使えることです(Studioの機能比較)。正確な要件は、ダウンロードしたインストーラーに付いてくるReadmeで確かめてください。

無料版を選ぶと困りやすい人

無料版にも向いていない人がいます。たとえば、メモリ8GBのWindowsノートしか持っていない人。最小要件の16GBに届かないので、動いても重く感じやすいはずです。その場合は、軽いソフトを使うのも手です。CapCut無料と有料の違いや、動画編集ソフト無料ロゴなし比較で、ほかの選択肢を比べられます。パソコン選びから迷っている人は、動画編集パソコンのスペック目安を先に読んでください。

判断の目安

  • 無料版のままでよい:上限(UHD・60fps)に当たらない。Studio限定の機能に困っていない
  • Studioを考える:乗り換えの表のどれかに当たり、その作業を週に何度もしている

よくある質問

DaVinci Resolve 無料版でYouTube投稿用の動画は作れますか?

作れます。無料版はUHD 3840×2160・60fpsまで書き出せるので、YouTubeの1080pや4Kの動画は上限に収まります(Studioの機能比較)。デリバーページには「YouTube」のプリセットもあります。Studio専用のエフェクトを使わなければ、透かしも入りません。

DaVinci Resolve 無料版が自分のパソコンで動くか、どう確かめればいいですか?

まず、パソコンのメモリとGPUのVRAMを調べてください。Windowsなら、メモリ16GB・VRAM 4GBが最小要件の目安です(ClipVerdict)。そのうえで無料版を入れ、短い動画を再生して書き出せるかを見るのが確実です。お金はかかりません。

無料版と有料版で、パソコンのスペック要件は違いますか?

最小要件は同じです。違うのは、Studioだと複数GPUやH.264/H.265のハードウェア処理が使えて、性能の高いパソコンの力を引き出せる点です(Studioの機能比較)。上級のAI機能には16GB以上のVRAMが必要とされているので(ClipVerdict)、AI目当てでStudioを買うなら、GPUも確かめてください。

DaVinci Resolve Studioは後からアップグレードできますか?

できます。無料版を使っていても、後からキーを買って「DaVinci Resolve Studio 21」をインストールし、キーを入れればStudioとして使えます。無料版で作ったプロジェクトも、Studioでそのまま続けられます。急いで買う必要はありません。
