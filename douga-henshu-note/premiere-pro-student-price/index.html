Premiere Pro 学生版の料金はいくら?1年目と2年目以降の価格

学生版は1年目の合計22,560円、2年目以降は年50,160円です。公式の料金ページでは製品名が「Premiere」と書かれていますが、探しているのはこのプランで合っています。

公式の利用条件には、次のように書かれています。

「最初の3ヵ月980 円/月(税込)、 4か月目以降2,180 円/月(税込)、2年目以降4,180 円/月(税込)でご利用いただけます。」(Adobe 利用条件)

確認して気づく3つの注意点

一括払いのほうが高い点に気をつけてください。利用条件の初年度一括価格は26,162円で、月々払いの合計より3,602円高くなります。「一括なら割安」という思い込みは、ここでは当てはまりません。

次に、公式ページ内の表記ゆれです。学生向けページのFAQには「980円/月は初年度のみ有効」とあり、4か月目以降の2,180円には触れていません。料金欄と利用条件は2,180円で一致しているので、この記事はそちらを採用しました。申し込み画面の金額も確かめてください。

3つ目は、Premiereの料金ページにある「89%以上OFF」の範囲です。通常価格の月9,080円と比べて計算すると、89%に届くのは月980円の3か月だけ。4か月目以降は約76%、2年目以降は約54%の割引になります。

Premiere Pro 学生版の対象条件は?教職員も使える?

対象は13歳以上の学生と、対象校の教職員です。在籍する課程や学校の種類にも条件があります。

「Adobe Creative Cloudの学生割引を利用するには、13歳以上で、大学、専門学校、小・中・高等学校、ホームスクールのいずれかに在籍している必要があります。」(Adobe 学生・教職員向けページ)

日本向けの購入資格ページでは、さらに細かく決められています。

たとえば大学や専門学校の学生は、表の学校に当てはまります。一方で、3か月未満の短期講座だけを受けている人は、課程の条件に合いません。

迷いやすいのは、一覧に名前のない学校です。購入資格ページに載っていない民間スクールなどは、自分で判断せず、買う前に Adobe へ問い合わせてください。

教職員の雇用形態については、購入資格ページに細かい記載がありません。非常勤の方は「在職を示す書類を出せるか」を先に確かめると安心でしょう。更新時に認められる書類の例は、次の見出しで挙げます。

申し込めないケース

利用条件には、購入条件が次のように定められています。

  • 購入先はアドビストアかアドビコールセンターに限られます。
  • 特別価格の利用は1人につき1契約、1回までです。
  • 既存の契約を解約して買い直す場合は対象外です。

すでに一般向けプランを契約中の方は、解約から始める前に問い合わせましょう。

Premiere Pro 学生版の申し込み手順と必要な証明

学校発行のメールアドレスがあれば、購入時の入力で資格確認が終わります。ここでの手順は公式ページの記載をもとに整理したもので、当サイトが実際の決済まで進めたものではありません。ボタン名が違うときは、画面の表示に従ってください。

  1. プラン一覧を開き、学生・教職員向けの欄を選びます。
  2. Creative Cloud Pro を選び、支払い方法を「年間プラン(月々払い)」か「一括払い」から選びます。
  3. 申し込み画面で、1年目の金額と2年目以降の金額を確認します。
  4. 学校発行のメールアドレス(例: xxx@xxx.ac.jp)を入力します。
  5. 支払い情報を入力して購入を完了します。
  6. 追加の証明を求められたら、書類を提出します。
  7. 契約の開始日をカレンダーに入れ、1年後の更新日の30日前にも予定を立てます。

卒業したら Premiere Pro の料金はどうなる?通常プランへの切り替え時期

卒業後も今の契約が終わるまでは学生価格で、次の更新から一般向けに移ります。Adobe のコミュニティマネージャーは、2026年3月の案内で次のように説明しました。

「卒業後は在籍証明ができないため、更新時に自動的に一般向けプランへ切り替わります。」(Adobe コミュニティのお知らせ)

日本語の公式ヘルプにも、在籍を確認できなければ更新時に通常価格へ戻るとあります。放っておくと月4,180円が月9,080円になり、年58,800円の負担増です。

一方、英語版のFAQには卒業後1年の猶予という記述があり、日本語の案内とは書き方が違います。日本の契約者は、日本語の案内とアカウントに表示された更新日を基準にしてください。

更新前にやることの順番

更新日の30日前が動き始める目安です。

  1. Adobeアカウントでプランの更新日を確認します。
  2. 更新の30日前に届く通知メールを確認します。
  3. 在学中なら、メールのリンクから在籍確認を進めます。
  4. 卒業するなら、この先使うアプリの数を書き出します。
  5. 1本だけなら単体へ、3本以上なら通常版の継続へ、使わないなら解約へ進みます。
  6. 手続きの後で、次回の請求額と更新日を確かめます。

プラン変更の操作はアカウントページから行うと案内されています。ただし、学生版から通常版への変更はサポートへの連絡が必要という情報もあり、画面で進めない場合は問い合わせが確実です。

途中で切り替えると費用がかかることも

年間プランの月々払いは、途中でやめると残りの料金の半分を請求される場合があります。公式の解約条件の個人向けの欄には、14日経過後の解約について「契約残存期間の料金の50%」と書かれています。

たとえば1年目の6か月分を払った時点でやめると、残りは2,180円×6か月で13,080円。その50%で6,540円が目安です。学生版の実際の金額は、解約画面の表示で確かめてください。更新日に合わせて動く理由は、ここにあります。

学校のメールで登録した人の落とし穴

卒業で学校のメールが使えなくなると、更新の通知を読めません。更新の案内によると、メールが見つからなくてもアカウントから確認でき、カスタマーケアにも相談できます。卒業前に、更新日をカレンダーへ移しておきましょう。

無料体験の解約で失敗しないために

Premiereの体験は、期間が終わると自動で単体プランへ移ります。解約は開始日から7日以内に行うのが基本で、公式には追加で14日間の返金猶予も書かれています。初日に終了日をカレンダーへ入れておくと確実です。

無料ソフトで足りるかの分かれ目は、3つ考えられます。

  • Premiere の指定がないこと
  • 共同作業の相手と同じソフトを使う必要がないこと
  • Studio 限定の機能を使わないこと

DaVinci Resolve の公式ページでは、テキストベース編集や Magic Mask が Studio 専用の機能に挙げられています。これらがいらなければ、DaVinci Resolve無料版の使い方から始めれば0円で済みます。ただし画面の項目が多く、覚える手間はかかるでしょう。

Premiere Pro の単体プランとコンプリートプランはどちらを選ぶ?

向いている人・向いていない人

学生版 Creative Cloud Pro が向いているのは、授業や制作で Photoshop、After Effects、Illustrator なども使う人です。20以上のアプリと毎月4,000の生成クレジットが付きます。逆に、Premiere 以外を開かない人には、2年目以降の年10,800円の上乗せが割高です。

単体プランが向いているのは、編集だけを長く続けたい人、すでに卒業した人です。注意点として、After Effects が必要になった時点で、もう1本分の費用かプラン変更の手間が発生します。

なお、どちらもインストールできるのは合計2台までです。学校のパソコンで使う場合の扱いは別の話なので、学校の案内を確認してください。一般向けの全プランの比較は、Premiereの料金表と損益分岐が参考になります。

よくある質問

Premiere Pro の単体プランに学割はありますか?

公式のプラン比較ページの学生・教職員向けの欄に載っているのは、Creative Cloud Pro だけです。単体は月3,280円のプランとして案内されています。Premiere を安く使いたい学生は、1年目は学生版、2年目以降は単体という順で比べてみてください。

高校生や中学生でも学生料金で使えますか?

13歳以上で対象校に在籍していれば対象です。購入資格ページには中学校と高等学校が載っており、中学生は健康保険証も証明書類として認められています。契約や支払いが必要になるので、保護者の方と一緒に確認すると進めやすいでしょう。

学生版で作った動画を仕事に使えますか?

公式FAQには基本的に商用利用が可能とありますが、一部のマテリアルや機能には制限があるとされています。また、2020年のコミュニティ投稿に引用された Adobe スクールパートナーのFAQは、勤務先や取引先の業務には使えないとしています。案件を受ける予定なら、契約前に Adobe へ確認してください。

卒業の直前に申し込んでも学生価格で使えますか?

2026年3月の案内では、3月31日までの購入なら卒業する人も学割価格で契約できるとされていました。契約後1年間は卒業後も学割価格のままです。来年以降も同じ扱いとは限らないので、申し込む時点の案内を確認しましょう。

更新の通知メールが来ないときはどうしますか?

通知は更新の30日前に、登録したメールアドレスへ送られます。見つからなければ、Adobe アカウントから在籍確認の状況を確かめるか、カスタマーケアに連絡してください。迷惑メールフォルダと、学校のメールが今も使えるかも見直しましょう。
