#動画編集 #初心者 #DaVinci Resolve #CapCut

動画編集を初心者が独学で覚えるなら、カット・テロップ・BGM・書き出しまでは、無料のソフトと公式の教材で十分です。独学が止まりやすいのは、操作を覚えたあとの「構成」「音」「色」「作業時間」と、仕上げの「書き出し」の5工程です。同じ所で2〜3週間止まっているなら、添削のある講座を考える時期と見てよいでしょう。

この記事の要点

  • 基本のカット・テロップ・書き出しは無料の公式教材で独学できる
  • 挫折しやすいのは構成・音・色・書き出し・作業時間の5工程
  • 仕事にしたい・添削が欲しい段階で有料講座を検討する

動画編集は独学で習得できる?

動画編集の基本操作は独学で習得できます。時間がかかりやすいのは、見やすい構成やテンポのように「正解が画面に出ない」部分です。

独学しやすい理由の1つは、ソフトの会社が自分で無料の教材を出していることです。DaVinci Resolveを作るBlackmagic Designの公式トレーニングページには、編集・カラー・Fairlight(音声)・Fusion(合成)・書き出し(Delivering Content)の5分野のトレーニング動画があります(2026-10-22に確認)。日本語のPDFは『DaVinci Resolve 20 ビギナーズガイド』などがあり、練習用のファイルもあります。なお、今のソフトは21ですが、日本語のビギナーズガイドは20のままです。画面が少し違う所もあると思っておいてください。

「Blackmagic Design認定トレーニングは、新規ユーザーおよび既存のセミプロフェッショナルに向けたカリキュラムで、よりクリエイティブで効率的にジョブをこなすために必要なスキルを学べます！」(Blackmagic Design トレーニング)

無料のオンラインセミナーもあります。2026年秋は90分の回が6回あります(2026-10-22に公式のセミナーページで確認)。今日(10月22日)よりあとに残っているのは次の4回です。

独学で手に入らないのは、他人の目です。テロップの文字が小さすぎる、BGMが声にかぶって聞き取りにくい、といった問題は、自分で見返しても気づきにくいものです。教材は操作の正解を教えてくれますが、「あなたの動画のどこが見にくいか」までは教えてくれません。独学で伸び悩む人の多くは、操作ではなくここで止まります。

動画編集初心者はまず何から学べばいい?

最初の目標は「1分の動画を1本、最後まで書き出すこと」です。学ぶ順番は、読み込み → カット → テロップ → BGM → 書き出しの5段階にします。

エフェクトや色の調整は後回しで構いません。最後まで書き出せた経験が1回あると、次の動画で何を足せばいいかが自分で分かるようになります。

DaVinci Resolve無料版で1本作る手順

まず使うのは、画面の下に並ぶ7つのページのうち「カット」と「デリバー」の2つだけです。7つのページは「メディア」「カット」「エディット」「Fusion」「カラー」「Fairlight」「デリバー」です。

なお、以下のボタンやメニューの名前は、この記事では公式文書と1つずつ照らし合わせていません。バージョンや表示言語によって名前が少し違うことがあるので、見つからないときは近い名前や同じ位置のボタンを探してください。

  1. 起動すると「プロジェクトマネージャー」が開きます。右下の「新規プロジェクト」を押し、名前を入れて「作成」を押します。
  2. 画面下の「カット」ページを開き、左上の「メディアの読み込み」から、撮った動画のファイルを選びます。
  3. 読み込んだクリップを、下半分のタイムラインまでドラッグします。
  4. 要らない部分の頭で再生を止め、「ブレード」(はさみのアイコン)で切ります。切れ端を選んで Delete キーで消します。
  5. 左上の「タイトル」から「テキスト」をタイムラインのクリップの上へドラッグし、右側の「インスペクタ」で文字と大きさを変えます。
  6. BGMのファイルも「メディアの読み込み」で入れ、映像の下の音声トラックへ置きます。
  7. 画面下の「デリバー」ページを開き、左上の書き出し設定で「YouTube」などのプリセットを選び、「レンダーキューに追加」を押します。
  8. 右側の「すべてレンダー」を押すと書き出しが始まります。

インストールから最初の書き出しまでは、このサイトのDaVinci Resolve無料版の使い方、最初の一歩でもう少し細かく説明しています。

<a id="choose-software"></a>

動画編集ソフトは何を選べばいい?

ソフトは「作る動画の向き(縦か横か)」「予算」「パソコンのOS」の3つで決まります。お金をかけずに横長の動画を作るならDaVinci Resolve無料版、縦型のショート動画ならCapCutが始めやすいでしょう。

主なソフトを公式の情報で並べると次のようになります(2026年10月22日時点・最新は公式で確認)。

DaVinci Resolve Studioの40,980円は期間限定の値下げです。業界ニュースのFutureFiveによると、2026年10月21日に発表され、販売店で11月20日まで続きます。期限は公式ページで確かめていません。初心者は無料版で十分なので、値下げにつられて急いで買う必要はありません。

CapCutの料金ページにあるプランは、無料・Pro・Ultra・Teamsの4つです(2026-10-22に確認)。初心者が最初に考えるのは、無料とProの2つで足ります。細かい違いはCapCut無料と有料の違い、料金と制限まとめにまとめています。

透かし(ロゴ)の入り方はソフトごとにかなり違います。無料版で書き出した動画にロゴが入るかどうかは、動画編集ソフト無料ロゴなし比較【2026年】OSと画質の早見表で確かめてから選ぶと、作り直しを防げます。

「あとで乗り換える」前提でも大丈夫

独学の初心者が、最初のソフト選びで何週間も悩む必要はありません。カット・テロップ・BGM・書き出しという流れはどのソフトでも同じで、変わるのはボタンの場所と名前くらいです。たとえば、DaVinci Resolveの「ブレードで切る」は、Premiere Proでは「レーザーツール」という名前で同じことをします。

動画編集に必要なパソコンのスペックは?

フルHD(1920×1080)の編集なら、メモリ16GBが現実的な最低ラインです。4Kを扱う人や、テロップや音を何層も重ねる人は、メモリ32GBとGPUメモリ8GB以上を目安にしてください(この目安は、下の「確かめきれていない要件」の参考値がもとです)。

各ソフトの会社が出している要件のうち、2026-10-22に公式ページで確かめられたものは次の表です。

今のパソコンで足りるかの判断

メモリの量を見れば、どこまでできるかがだいたい分かります。Windowsは「設定」→「システム」→「バージョン情報」の「実装 RAM」、Macはアップルメニューの「このMacについて」で見られます。

  • 8GB:CapCut・Clipchamp・iMovieで短いフルHD動画を作るところまで。DaVinci ResolveのWindows版は、第三者のまとめでは最小16GBなので届かない
  • 16GB:フルHDなら、DaVinci ResolveでもPremiere Proでも練習できる
  • 32GB以上:4Kの素材や、長い動画・何層も重ねる編集まで

これから買う人のための目安は、動画編集パソコンのスペック、最低限の目安はで予算別にまとめています。

<a id="stuck-points"></a>

動画編集の独学でつまずきやすいポイントはどこ?

独学で止まりやすいのは「構成」「音」「色」「書き出し」「作業時間」の5工程です。どれも操作を覚えたあとに出てくる壁なので、教材を最後まで見ても解決しないことがあります。

動画編集の独学でつまずきやすいポイントはどこ?
工程起きること独学での直し方講座が役に立つ度合い
構成撮った順に並べただけで、何を伝える動画か分からない作る前に「最初の5秒で何を見せるか」を1行で書く。好きな動画の流れを秒数つきで書き出して真似る高い(第三者の感想が要る)
音BGMが声より大きい、場面ごとに音量がばらばらDaVinci Resolveなら「Fairlight」ページで音量を見ながら合わせる。公式のFairlightトレーニング動画で基礎を学ぶ中くらい
色カットごとに明るさや色味が違い、ちぐはぐに見える撮影の時点で明るさを固定する。DaVinci Resolveの公式Colorトレーニングで基本の補正を学ぶ中くらい
書き出しYouTubeに上げたら画質が落ちた、縦横の比率がずれた書き出し前に、解像度・フレームレート・縦横比を投稿先に合わせる。ソフトのプリセットを使う。公式トレーニングの「Delivering Content」も役に立つ低い(手順で解決できる)
作業時間1分の動画に何時間もかかり、続かなくなるショートカットキーを10個だけ覚える。テロップの型を保存して使い回す高い(人のやり方を見るのが早い)

構成とテンポは「数えて真似る」

構成やテンポは独学で一番伸びにくい所ですが、手を動かして練習できます。自分が最後まで見てしまったYouTube動画を1本選び、「何秒で場面が切り替わるか」「テロップが何秒出ているか」を紙に書き出してください。そのリズムを自分の素材で真似ると、何となく並べていたときより、どこが長すぎるかが見えてきます。

それでも「何が悪いのか分からない」状態が続くなら、独学の限界の1つです。次の見出しの判断表で、切り替えるかどうかを確かめてください。

作業時間は「同じ作業の2回目」で測る

1本目に時間がかかるのは当たり前です。見るべきなのは、同じ種類の動画の2本目・3本目で時間が縮んでいるかどうかです。縮んでいないなら、原因は操作の覚え方より作業の順番にあることが多いでしょう。カット → テロップ → 音 → 色 → 書き出しの順番を毎回守るだけでも、行ったり来たりが減ります。

<a id="switch-to-school"></a>

動画編集を独学からスクールに切り替えるタイミングはいつ?

切り替えの目安は「同じ壁で2〜3週間止まっている」「人に見せて直してほしい」「仕事として納品したい」のどれかに当てはまったときです。操作を知らないだけなら、まだ無料の教材で足ります。

切り替えの判断表

自分に当てはまる行を探してください。

切り替えの判断表
いまの状態足りないものおすすめの次の一手
ソフトのボタンの場所が分からない操作の知識独学のまま。公式トレーニングやビギナーズガイドを1章ずつ
1本は作れたが、2本目も同じくらい時間がかかる作業の型独学のまま。ショートカットとテンプレートを作る
自分の動画のどこが悪いか分からない他人の目(フィードバック)添削がある講座、または身近な人に見てもらう
2〜3週間、同じ所(構成・音・色)で止まっている体系的な学び方有料講座を考える
仕事で納品したい・案件に応募したい実務の手順と、Premiere Proなど指定ソフトの経験Premiere Proの体験版で確かめてから、講座を比べる
趣味で楽しく作れていて、困っていないなしお金を払う必要はない

判断のコツは、「分からないこと」の中身を言葉にしてみることです。「エフェクトの出し方が分からない」なら検索で解決します。「なぜかつまらない」は検索しにくい悩みで、ここまで来たら講座の添削が役に立ちます。

講座を選ぶときに確かめること

講座を比べるときは、次の4点を公式ページで確かめてください。

  1. 添削(作った動画を見てもらえるか)があるか。動画教材だけの講座では、独学と同じ所で止まることがある
  2. 受講期間と、教材を見られる期間が同じかどうか
  3. 付いてくるソフトのライセンスに、使い方の制限がないか
  4. 合計の費用(受講料+ソフト代+パソコン代)

例として、デジハリ・オンラインのAdobeマスター講座を見てみます。2026-10-20に公式ページで確かめた受講料は68,800円(税込)、受講期間は3ヶ月で、Adobe CCが1年分付きます。2026-10-22には公式サイトにつながらず、最新の受講料やキャンペーンは確かめられませんでした。公式サイトには「受講料改定のお知らせ」のページもあるので、申し込む前に今の金額を必ず確かめてください。

気をつけたいのは、付いてくるライセンスの種類です。公式ページによると、これは「学生・教職員個人向けライセンス」なので法人では使えず、使えるのは日本国内だけです。2024年12月の規約の変更で、このライセンスは1回しか買えなくなりました。教材は動画が中心です。

一方、1点目の「添削があるか」は、この講座の公式ページにはっきり書かれておらず、この記事では確かめられていません(未確認)。価格・期間・ライセンスの情報とは確かさが違うので注意してください。添削が欲しい人は、申し込む前に問い合わせて確かめてください。

動画編集の勉強にかかる期間はどれくらい?

期間の目安は、何を作れるようになりたいかで変わります。短い動画を1本作れるまでは数日〜数週間、人に見せられる形が安定するまでは数ヶ月と考えておけば無理がありません。

ソフトの会社が「何時間で習得」という数字を出しているわけではないので、ここでは目標ごとの段階で考えます。

動画編集の勉強にかかる期間はどれくらい?
目標目安その段階でやること
1分の動画を1本書き出す数日〜1週間上の8つの手順を最後まで
テロップとBGMの入った動画を毎週作れる1〜2ヶ月同じ形の動画を繰り返し作り、時間を記録する
色と音をそろえて、見やすい動画になる2〜3ヶ月公式トレーニングのColor・Fairlightの章
人から頼まれた動画を納品できる3ヶ月〜半年構成・修正への対応・納品形式まで

この表は公式の数字ではなく、この記事の学ぶ順番に合わせた目安です。参考として、Adobeマスター講座の受講期間は3ヶ月です。ただし、これはIllustrator・Photoshop・Premiere Pro・After Effectsなどの基礎をまとめて学ぶ期間で、動画編集だけの期間ではありません(デジハリ・オンライン)。

期間が延びる一番の原因は、間が空くことです。週末にまとめて5時間やるより、平日に30分ずつ触るほうが、ボタンの場所を忘れずにすみます。

動画編集を学ぶのに無料と有料の教材はどう違う?

無料の教材は「操作を覚える」ところまでなら十分です。有料の講座が上回るのは、学ぶ順番が決まっていることと、自分の作品を見てもらえることの2点です。

動画編集を学ぶのに無料と有料の教材はどう違う?
種類費用学べること向いている人弱いところ
ソフト公式のトレーニング(Blackmagic Designなど)無料正しい操作と用語。練習用ファイルつきソフトを1つに決めた人自分の動画への感想はもらえない。日本語のガイドは一部が古いバージョン
公式の無料セミナー(DaVinci Resolve Online Seminars)無料新機能やワークフローの全体像決まった時間に参加できる人英語。日本時間の夜遅く。初心者向けの回は2026年は終了
YouTubeの解説動画無料特定のテクニック知りたいことがはっきりしている人順番がばらばらで、古いバージョンの解説もまじる
オンデマンドの有料講座(例:Adobeマスター講座)数万円複数ソフトの基礎を順番にAdobeのソフトもまとめて揃えたい人添削がない講座もある。Adobeマスター講座の添削の有無は公式ページに明記がなく未確認
添削・面談つきのスクール講座によって大きく違う構成や見やすさへの指摘仕事にしたい人、独学で止まっている人費用が高い。受け身だと身につかない

無料と有料で迷ったら、まず無料の公式教材を1つ最後まで終えてみてください。終えられたなら、独学のまま続けられる人です。途中で止まっても、どこで止まったかが分かれば、講座を選ぶときの基準になります。

よくある質問

動画編集は完全に無料で独学できますか?

できます。DaVinci Resolve無料版・iMovie・Clipchampの無料プランは、透かしなしで書き出せます。教材も、Blackmagic Designの公式トレーニングやビギナーズガイドが無料です。お金がかかるのは、パソコンの買い替えが必要になったときくらいです。

スマホだけで動画編集を覚えても意味はありますか?

意味はあります。SNS向けの縦型動画なら、スマホのCapCutやiMovieで十分に作れます。カット・テロップ・BGMという考え方は、パソコンのソフトに移っても同じです。ただ、長い横長の動画や色の細かい調整は、パソコンのほうが作業しやすくなります。

メモリ8GBのパソコンでも動画編集はできますか?

短いフルHD動画なら、CapCut・Clipchamp・iMovieで作れます(iMovieは公式で最小4GB)。Premiere Proは最小8GB、HDでの推奨は16GBとされています(Adobeの公式ページを直接確かめられていない参考値)。DaVinci ResolveのWindows版は、第三者のまとめでは最小16GBなので、8GBでは動作が不安定になりやすいでしょう。どれもインストールの前に公式の要件を確かめてください。

DaVinci Resolve Studio(有料版)は値下げ中に買うべきですか?

初心者が急いで買う必要はありません。無料版でもUHD・60fpsまで書き出せるので、独学の段階で困ることはほとんどありません。2026年10月22日時点の公式ページの表示は40,980円(税込、通常51,980円)です。業界ニュースでは11月20日までの値下げと伝えられています。無料版で足りない機能がはっきりしてから考えれば十分です。

動画編集の仕事を目指すなら、最初からPremiere Proを使うべきですか?

最初は無料のソフトで基本を覚え、仕事を考える段階でPremiere Proの7日間体験を試す順番でも遅くありません。操作の考え方は共通しているので、乗り換えにかかる時間は長くないはずです。応募したい案件がソフトを指定していないかは、早めに確かめておきましょう。
