動画編集に使うパソコンは、フルHD(1080p)の動画ならメモリ16GB、グラフィック用のメモリ(VRAM)4GB以上、保存先はSSDが最低限の目安です。4K動画を編集するなら、メモリ32GB・VRAM 8GBあると安心です。Adobeは、Premiere Proの推奨メモリをHDで16GB、4Kで32GBとしています(Adobe Premiere Pro システム要件)。ただ、必要なスペックは使うソフトによって変わります。軽いソフトなら、メモリ8GBでも始められます。

この記事の要点

  • フルHDの編集はメモリ16GBが目安。Premiereは4Kで32GBを推奨
  • DaVinci Resolve 21のMac版はAppleシリコン搭載機だけで動く
  • CapCutのWindows版はメモリ4GBから動くが、AI機能は8GB以上を推奨

向いている人: 動画編集に使うパソコンを選びたい初心者

あなたに合うのはどれ?

答えは「何を作るか」と「今どのパソコンを持っているか」で決まります。まず自分に近い行を探してください。

理由をひとことずつ書きます。

  • CapCut: 求めるスペックがいちばん低く、今のパソコンのまま試せます。
  • iMovie: 無料で使えて、Macにすぐ入れられます。
  • DaVinci Resolve: 無料のままでも本格的な編集ができます。ただ、求めるスペックは高めです。
  • Premiere Pro: 仕事の現場で使われることが多く、データのやりとりで困りにくいソフトです。
  • Final Cut Pro: 買い切りを選べば、毎月の料金がかかりません。

解像度別に見る、必要なスペックの目安

撮る動画の解像度が上がるほど、必要なメモリとVRAMが増えます。下の表は、ソフト会社が公開している最低条件や推奨値から目安をまとめたものです。ソフトごとの細かい条件は、次の章で書きます。

解像度別に見る、必要なスペックの目安
編集する動画メモリGPU(VRAM)保存先考え方
SNSの短い縦動画・フルHDで数分8GB〜内蔵GPUでも可SSDCapCutやiMovieなら動く範囲
フルHDのYouTube動画(10〜30分)16GB4GB以上SSDPremiere Proが推奨するHD向けの値と同じ
4Kの動画・エフェクトを多く使う32GB8GB以上空き容量の多いSSDPremiere Proが推奨する4K向けの値と同じ

この表の数字は、次の公式の値をもとにしています。

  • Premiere Pro: 最低条件はメモリ8GB・VRAM 4GB。推奨はHDで16GB、4Kで32GB、VRAMは8GBです(Adobe)。
  • DaVinci Resolve 21: Windows版の最低条件がメモリ16GB・VRAM 4GBです(DaVinci Resolve 21 readmeの要約)。

CPUはどう選べばいい?

CPUの最低ラインは、たとえばCapCutのWindows版なら「Intel Core i3以上」です(CapCut)。ただ、エフェクトを重ねる編集や長い動画の書き出しでは、CPUが速いほど待ち時間が短くなります。

判断の基準は2つです。

  • これから買うなら、メモリとVRAMを先に決めます。CPUは「予算の中で新しい世代のもの」を選ぶと考えると、迷いにくくなります。
  • MacはCPUとGPUが1つのチップにまとまっています。そのため、メモリの量を基準に選びます。

保存先はSSD、容量は余裕をもって

動画のファイルは大きいため、編集用のファイルはSSDに置くのが基本です。HDDに置くと、読み込みが遅くなりやすいからです。

ソフト本体の容量は、CapCut(Windows)で2GB以上、Final Cut Proで7.2GBが必要です(CapCut、Apple)。実際には、ソフト本体よりも撮った素材や書き出したファイルのほうがずっと大きくなります。終わった案件の素材は、外付けのSSDやHDDに移すと決めておくと、空き容量が足りなくなるのを防げます。

CapCut: 今のパソコンでまず試したい人向け

CapCutは、表の中で求めるスペックがいちばん低いソフトです。AI機能を使う場合は、メモリ8GB以上、NVIDIA GeForce GTX 1060以上のGPUが推奨されています(CapCut)。

  • 向いている人: スマホの動画をSNS向けに手早く仕上げたい人
  • 向いていない人: 長い動画を細かく色調整したい人
  • 注意点: 一部の機能は有料プランでしか使えません。無料版との違いはCapCut無料と有料の違いにまとめています。

DaVinci Resolve: 無料で本格的に編集したい人向け

DaVinci Resolveの無料版は、Ultra HD(3840×2160)・60fps・8bitまで扱えます(Blackmagic Design)。

  • 向いている人: 費用をかけずにYouTube向けの動画を作り込みたい人
  • 向いていない人: Windowsのメモリ8GBのノートパソコンで作業する人(最低条件の16GBに届きません)
  • 注意点: Windows版の最低メモリは16GBで、合成機能のFusionを使うなら32GBが必要です。Mac版はAppleシリコン搭載機が条件なので、Intel製CPUのMacでは最新版を使えません(readmeの要約)。

始め方はDaVinci Resolve無料版の使い方で、手順を順番に説明しています。

Premiere Pro: 仕事で使う人向け

Premiere Proの料金は、年間プランの月々払いで月3,280円(税込)です。7日間の無料体験があります(Adobe)。

  • 向いている人: 仕事で動画を作る人や、Photoshopなど他のAdobe製品と一緒に使う人
  • 向いていない人: 月に1〜2本しか編集しない人(使わない月も料金がかかります)
  • 注意点: 最低条件の8GBでは、HD編集でも余裕がありません。メモリ16GB以上のパソコンで使うのが前提だと考えてください。

Final Cut Pro: Macで長く使いたい人向け

Final Cut Proは、50,000円(税込)の買い切りで購入できます。Apple Creator Studioのサブスクリプション(月1,780円・年17,800円)でも使えて、30日間の無料トライアルがあります(Apple)。

  • 向いている人: AppleシリコンのMacを持っていて、毎月の料金を払いたくない人
  • 向いていない人: Windowsを使う人(Mac版とiPad版しかありません)
  • 注意点: 一部の機能はAppleシリコン搭載のMacでしか使えません。

今のパソコンで編集できるか確かめる手順

買い替える前に、今のパソコンのメモリ・GPU・空き容量を確かめましょう。確かめた数字を前の章の表と比べると、使えるソフトが分かります。

Windows 11の場合

  1. 「スタート」→「設定」→「システム」→「バージョン情報」を開きます。
  2. 「プロセッサ」の欄でCPUの名前を、「実装 RAM」の欄でメモリの量を確かめます。
  3. キーボードで「Ctrl」+「Shift」+「Esc」を押して、タスクマネージャーを開きます。
  4. 「パフォーマンス」を選び、「GPU」をクリックします。「専用 GPU メモリ」がVRAMの量です。
  5. 「設定」→「システム」→「ストレージ」で、空き容量を確かめます。

Macの場合

  1. 画面左上のAppleメニュー →「このMacについて」を開きます。
  2. 「チップ」の欄が「Apple M1」などなら、Appleシリコン搭載機です。「プロセッサ」の欄に「Intel」とあれば、Intel製CPUのMacです。
  3. 「メモリ」の欄で、メモリの量を確かめます。
  4. 「システム設定」→「一般」→「ストレージ」で、空き容量を確かめます。

つまずきやすい所と、その直し方

  • 「専用 GPU メモリ」が0や小さい数字になっている: 内蔵GPUのパソコンでは、普通のメモリをGPU用に分けて使います。そのため、専用メモリが小さく表示されます。DaVinci Resolveは内蔵GPUでも使えますが、VRAM 4GBが条件です(readmeの要約)。まずはCapCutなど軽いソフトから始めましょう。
  • Intel製CPUのMacで、DaVinci Resolveの最新版が入らない: 最新版はAppleシリコン専用です。iMovieかCapCutを使うか、買い替えのときにAppleシリコンのMacを選びましょう。
  • メモリを後から増やせない: Macや薄型のノートパソコンの多くは、買った後にメモリを増設できません。買う前に「4Kを撮るかどうか」を決め、4Kを撮るなら32GBを選んでおくと、後悔しにくくなります。
  • スマホの4K動画を読み込むとカクカクする: スマホの撮影設定をフルHDに下げるのが、いちばん簡単な直し方です。編集ソフトのプロキシ機能(編集中だけ軽い代わりのファイルを使う機能)を使う方法もあります。

買うなら、予算別にどこまで選ぶか

買うときは、メモリ→保存先(SSD)→GPUの順に決めると、予算の配分で迷いにくくなります。下の表は、その順番で考えた判断の基準です。値段の数字ではなく、どこを優先するかを書いています。

買うなら、予算別にどこまで選ぶか
作りたいもの優先するもの妥協してよいもの
SNS用の短い動画メモリ16GB・SSD専用GPU(内蔵GPUで十分)
フルHDのYouTube動画メモリ16GB・VRAM 4GB以上CPUの最上位モデル
4K動画・仕事用メモリ32GB・VRAM 8GB・SSDの容量本体の軽さ

ノートパソコンかデスクトップかで迷ったら、持ち歩くかどうかで決めます。持ち歩かないなら、同じ予算でも性能を上げやすく、メモリも増設しやすいデスクトップが向いています。

よくある質問

メモリ8GBのパソコンで動画編集はできますか?

ソフトを選べばできます。CapCutのWindows版は4GB以上、iMovieは4GBで動きます(CapCut、iMovie)。ただ、Windows版のDaVinci Resolve 21は最低16GBが必要なので、8GBでは条件を満たしません。

グラフィックボード(GPU)は必要ですか?

フルHDの短い動画なら、内蔵GPUでも始められます。Premiere ProやDaVinci ResolveはVRAM 4GB以上が最低条件で、Premiere Proは8GBを推奨しています(Adobe)。4Kの動画やエフェクトの多い編集をするなら、専用GPUのあるパソコンを選ぶと処理が安定します。

MacとWindows、どちらが動画編集に向いていますか?

どちらでも編集できます。Final Cut ProとiMovieはMacでしか使えません。CapCut・DaVinci Resolve・Premiere Proは両方で使えます。DaVinci Resolve 21のMac版は最低メモリが8GBで、Windows版の16GBより低くなっています(readmeの要約)。

無料のソフトで、書き出した動画にロゴ(透かし)は入りますか?

ソフトや使う機能によって変わります。DaVinci Resolveの無料版は、Ultra HD・60fpsまで書き出せます。条件は動画編集ソフトの無料版、透かしが消える条件でソフトごとに整理しています。
