受講料のほかにかかるお金

申し込む前に計算に入れておきたいのは、次の2つです。

  • 編集ソフト代: 多くのスクールが教えるAdobe Premiereは、単体プランで月3,280円(年間プラン・月々払い)。Creative Cloud Proは通常月9,080円です(Adobe 公式・2026年10月時点)。たとえば6か月のコースをPremiere単体で受けると、ソフト代は3,280円×6=19,680円。
  • パソコン代: デジハクの公式ページには、WindowsならRTX 3060 Laptop以上のGPUとメモリ16〜32GB、MacならM1以上・メモリ16GB以上という推奨が載っています(デジハク)。STUDIO USも同じくらいの推奨です(STUDIO US)。

いまのパソコンでどこまで編集できるかは、動画編集パソコンのスペック、最低限の目安はで確認できます。スクールの推奨はAfter Effectsまで使う前提なので、カット編集とテロップだけならもっと下のスペックでも始められます。

つまずきやすい所: 分割払いの「月々◯円〜」

広告やトップページの「月々◯円〜」は、いちばん長い回数で分けたときの金額であることがほとんどです。手数料を足した総額と回数は、無料相談で紙かPDFにして出してもらいましょう。

オンラインのライブ授業と動画教材の違い

同じオンラインでも、中身は2種類あります。むびるスクールは「週1回2時間程度」のライブ授業で、欠席した回は録画が届く形です(むびるスクール)。STUDIO USは動画教材を好きな時間に見る形。決まった時間に人と顔を合わせないと続かないタイプなら、ライブ授業のあるほうが合います。

つまずきやすい所: 通学でも家での作業は残る

通学型でも、課題や卒業制作は家のパソコンで進めることが多くなりがちです。校舎のMacで習って家ではWindows、という組み合わせになると、ショートカットキーの違いで手が止まります。説明会では「家の課題はどのパソコンで、どのソフトで進める想定ですか」と聞いておきましょう。

動画編集スクールで補助金・給付金は使える?

使えるのは、厚生労働大臣が指定した講座を、雇用保険の要件を満たす人が受けた場合だけです。この2つがそろえば、受講料の20〜80%がハローワークから支給されます。

教育訓練給付には3つの種類があります(厚生労働省・2026-10-23に数えた)。

種類支給される割合上限

たとえば、一般教育訓練の対象になっている20万円の講座を修了すれば、4万円が戻る計算になります。デジタルハリウッドSTUDIOなんばの動画系コースは、公式ページに「第四次産業革命スキル習得講座の対象です」とあり、「最大80%キャッシュバック」と案内されています(STUDIOなんば)。いっぽう、オンラインだけのスクールには対象外のところも少なくありません。

対象講座の探し方

  1. 教育訓練講座検索システムを開き、「講座・スクールを探す」を押す
  2. 「フリーワードで検索する」に、スクール名か「動画」と入れる
  3. 出てきた講座の詳細で、給付の種類・指定期間・受講形態を確かめる
  4. 自分が受けられるか分からなければ、ハローワークで「支給要件照会」をする(本人が行くほか、代理人・郵送・電子申請もできます。ハローワーク)

つまずきやすい所

  • 雇用保険の期間が足りない: 一般教育訓練は、原則として雇用保険に3年以上入っていることが条件です。初めて受け取る人は1年以上で受けられます(ハローワーク)。
  • 手続きが間に合わない: 特定一般と専門実践は、訓練前キャリアコンサルティングを受けて「ジョブ・カード」をもらい、受講開始日の2週間前までにハローワークで受給資格確認をする必要があります(ハローワーク)。申し込んでから気づくと間に合いません。
  • 修了しないともらえない: 一般教育訓練は、修了日の翌日から1か月以内にハローワークへ申請します。途中でやめたら支給はありません。
  • 同じスクールでも全部が対象とは限らない: 対象なのはスクール単位ではなく講座単位。コース名と校舎まで同じかどうかを検索システムで照らし合わせてください。

無料の動画編集スクールやロゴなし無料ソフトはある?

受講料が完全に無料のスクールは、公式で確かめた範囲では見当たりませんでした。無料なのは個別相談・説明会と、ソフトの無料版・無料体験です。

各スクールの無料の入口は、それぞれ形が違います(2026年10月時点)。

ここで言う「無料体験」は、ほとんどが授業の体験ではなく相談や説明です。授業の雰囲気を見たいなら、予約するときに「体験授業や教材のサンプルは見られますか」と聞いてみてください。

ソフトのほうは、無料でもロゴ(透かし)が入らないものがあります。DaVinci Resolveの無料版は、公式の説明で「60fpsまでのほぼすべての8-bitフォーマットおよびUltra HD 3840x2160までの解像度」に対応しています(Blackmagic Design)。有料のDaVinci Resolve Studioは40,980円の買い切りです(2026年10月時点の公式表示)。Adobe Premiereにも7日間の無料体験があります(Adobe)。

Adobeの無料体験を使うなら、スクールの開講日に合わせて始めてください。無料相談の前に登録すると、授業が始まるころには体験期間が終わっています。

安いスクールと高いスクールの違いは何?

価格の差は、教材の量よりも「人が関わる時間」に出ます。たとえばサポートの期間、ライブ授業があるか、通学できるか、案件紹介の手厚さです。

安いスクールと高いスクールの違いは何?
価格を左右する所安めのスクールの例高めのスクールの例
サポート期間期間の区切りなし(STUDIO US:「期間無制限」)6か月・12か月など期間で料金が変わる(デジハク)
授業動画教材を自分で見る週1回のライブ授業(むびる)・個別トレーナー(LIG)
場所オンラインのみ通学校舎・機材あり
仕事との接点実績作り用の案件・コンペ転職支援・案件紹介制度

STUDIO USの公式ページには、サポートの期限について次の一文があります。

「サポートの期間制限はなく、永久的にサポートを受けることができます」(STUDIO US)

安いコースでも、サポートの期間が長ければ自分のペースで進められます。ただ、締め切りがない分だけ後回しにしやすいのが注意点。逆に高いコースは、期間内に課題を出し切る前提で組まれているので、仕事が繁忙期に入ると受講料の元を取りにくくなります。

判断の目安: 1週間に学習に使える時間を先に決めてから選ぶことです。たとえば週3時間しか取れないなら、3か月の短期集中コースより、期間の長いコースのほうが無理なく進められます。

動画編集スクール比較で見るべきポイントは?

比べる軸は、料金形態・受講形式・案件紹介・給付金・使うソフトの5つで足ります。公式サイトで埋められない欄が、そのまま無料相談で聞くことになります。

比較表を作る手順

  1. 紙かスプレッドシートに、横へ「一括料金/月あたり/期間/形式/案件紹介/給付金/使うソフト/推奨PC」の8列を作る
  2. 候補のスクールを2〜3校に絞り、公式サイトの料金欄を見て埋める
  3. 「月あたり」は一括料金÷期間で出す(期間無制限のスクールは「−」にしておく)
  4. 埋まらなかった欄に印をつけ、無料相談で聞く質問にする
  5. ソフト代(Premiereなら月3,280円×期間)を足した総額を最後に比べる

使うソフトで選ぶ

教わるソフトはスクールでかなり違います。デジハクはPremiere Pro・After Effects・Photoshop・Illustratorの4つ(デジハク)。STUDIO USはそれに加えてDaVinci Resolveやテラドーガも扱います(STUDIO US)。LIGの動画ディレクター専攻もDaVinci Resolveを含んでいます(LIG)。

月額のAdobeを払い続けたくない人は、DaVinci Resolveを教えてくれるかを比べる軸に入れると、受講後のソフト代を抑えられます。買い切りと月額のどちらが得かは動画編集ソフト買い切り比較【2026年】で計算しています。

スクールの案件紹介・就職サポートはどこまで信頼できる?

案件紹介は「仕事が必ずもらえる約束」ではなく、「仕事に触れる機会」と読むのが安全です。内容はスクールによって、在学中の練習用案件から卒業後の優先紹介まで差があります。

むびるスクールの公式ページには、次のように書かれています。

「卒業後はむびる/VideoWorksの認定パートナーとして案件の優先紹介を受けることができます」(むびるスクール)

ここで確かめたいのは「認定パートナーになる条件」と「優先紹介された案件の数」。紹介を受けるのに基準があるなら、卒業しただけでは紹介の対象にならないこともありえます。

公式サイトの割合の表示にも注意が要ります。デジハクのページには「92%の受講生が受講期間中に案件を獲得」とあります(デジハク)。分母が「全受講生」なのか「アンケートに答えた人」なのか、「案件」に無償や練習の仕事が入るのかで、数字の意味が変わります。どのスクールでも、割合や人数を見たら「何人中の何人で、いつの集計ですか」と聞いてみてください。

無料体験では何を聞けばいい?

聞くべきことは、料金の内訳・期間の延長・案件紹介の条件・ソフトとパソコン、それに解約のルールです。下の8つの質問をメモして、無料相談の画面の横に置いておけば十分。

相談の流れも書いておきます。

  1. 予約の前に、公式サイトの料金欄を見て比較表の空欄を確かめる
  2. 自分のパソコンの型番・メモリ・GPUをメモする(Windowsは「設定」→「システム」→「バージョン情報」で表示されます)
  3. 相談では最初に「今日は申し込まず持ち帰ります」と伝える
  4. 8つの質問を順番に聞き、答えをメモする
  5. 総額と解約の条件を書いた資料をメールかPDFでもらう
  6. 1日以上空けてから、ほかの候補と表で比べる

相談の当日に決めないこと。料金の割引や「本日限り」の特典を出されても、表で比べてからで遅くありません。

契約したあとに使える解約のルール

動画編集スクールのようなパソコン操作を教えるサービスは、期間が2か月を超えて金額が5万円を超えると、特定商取引法の「特定継続的役務提供」の「パソコン教室」に当たります(消費者庁)。オンラインの講座も含まれます。

「役務の内容がファックスや電話、インターネット、郵便等を用いて行われる場合も広く含まれます。」(消費者庁 特定商取引法ガイド)

これに当たる契約なら、法律で決められた書面を受け取った日から数えて8日以内は、書面か電磁的記録(メールなど)でクーリング・オフができます。8日を過ぎても中途解約はでき、スクールが請求できる金額には上限があります(消費者庁)。

  • 受講が始まる前の解約: 上限1万5,000円
  • 受講が始まった後の解約: すでに受けた分の料金+「5万円」と「契約残額の20%」の低いほう

たとえば、受講開始前に解約したなら、スクールが求められるのは最大1万5,000円です。ただし、契約が条件に当たるかどうか(たとえば期間の定めがない契約など)は個別に違います。契約書面の記載を確かめ、分からなければ消費者ホットライン188に相談してください。クーリング・オフを送るときは、送った画面のスクリーンショットを残しておくよう国民生活センターも勧めています。

スクール独自の返金保証もあります。デジハクは「30日間返金保証」を公式ページに載せています(デジハク)。法律の解約ルールとは別のものなので、条件(課題の提出が要るかなど)を質問8と一緒に聞いておきましょう。

よくある質問

動画編集スクールで、大阪で通える教室はありますか?

あります。デジタルハリウッドの校舎一覧には、近畿として大阪本校・大阪梅田・なんば・三宮・京都・姫路が載っています(デジタルハリウッド)。STUDIOなんばは南海線なんば駅から徒歩1分です(STUDIOなんば)。なお、LIGが運営する「by LIG」の校舎は関東だけです。

動画編集スクールのおすすめはどこですか?

人によって変わるので、1校には決められません。安さと期間の長さならSTUDIO US、ライブ授業ならむびるスクール、通学と給付金ならデジタルハリウッドSTUDIOが候補になります。まず「あなたに合うのはどれ?」の表で自分の行を選び、2〜3校の無料相談で比べてください。

動画編集ソフトは無料と有料、どちらを先に学ぶべきですか?

最初は無料ソフトで十分です。カット・テロップ・BGMといった基本の操作は、ソフトが変わってもほぼ共通。スクールでPremiere Proを使うと決まったら、開講日に合わせてAdobeの7日間無料体験か有料プランに切り替えれば、ソフト代の無駄が出ません。

主婦や学生でも給付金は使えますか?

教育訓練給付は雇用保険の制度なので、雇用保険に入っていない人は対象外です。離職した人でも、離職から1年以内で、以前に雇用保険へ一定期間入っていれば対象になる場合があります。自分が当てはまるかは、ハローワークの支給要件照会で確かめられます(ハローワーク)。
