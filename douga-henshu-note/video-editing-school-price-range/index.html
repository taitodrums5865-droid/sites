受講料のほかにかかる費用

いちばん大きいのはAdobeのソフト代です。そのほかに、分割の手数料と、場合によっては入学金がかかります。

今回見た2校は、どちらも受講料にAdobeのソフト代を含めていません。デジハクのよくある質問には、ソフトは自分で準備するよう書かれています。

「パソコンとAdobeソフトの準備が必要になります」(デジハク よくある質問)

studio USも、ソフトの料金は書かずにAdobeのプランページへのリンクを置いているだけです。動画編集コースではPremiere ProとAfter Effects、総合コースではさらにIllustratorとPhotoshopを使い、総合コースにはコンプリートプラン(現在のCreative Cloud Pro)を勧めています(studio US)。

給付金で総額はどれだけ下がるか

一般教育訓練給付の対象講座なら、修了後に受講料の20%(上限10万円)が戻ります。厚生労働省のページには、次のように書かれています。

「教育訓練経費の20%（上限10万円）が訓練修了後に支給されます。」(厚生労働省 教育訓練給付制度)

特定一般教育訓練という区分は40%(上限20万円)です。資格を取るなどして、修了から1年以内に雇用保険に入って働いた場合は、50%(上限25万円)まで追加で支給されます(同ページ)。どの講座がどの区分に入るかは講座ごとに違うので、厚生労働省の講座検索かスクールで確かめます。

対象になる人の条件

条件は、受講を始める日までに雇用保険に入っていた期間が3年以上あることです。初めて給付を受ける人は1年以上で受けられます(ハローワークインターネットサービス)。

「雇用保険に加入していた期間が1年以上あれば受給可能となります。」(ハローワークインターネットサービス)

退職した人は、離職日の翌日から受講開始日までが1年以内であることも必要です。受講開始日の前日から3年以内に給付を受けていた場合は、もらえません(同ページ)。自営業で雇用保険に入っていない人は、この給付は使えません。

たとえばstudio USの動画クリエイター総合コースは、一般教育訓練給付金と個人向けリスキリング補助金が使えると書かれています(studio US)。

デジハクのページには給付金についての記載が見当たりませんでした(デジハク よくある質問)。給付金を使いたい人は、申し込む前に「この講座は教育訓練給付の対象ですか」とはっきり聞きましょう。

サポート期間で何が変わるか

同じ受講料でも、質問できる期間が「無制限」か「6か月」かで、1か月あたりの値段は大きく変わります。

studio USは受講期間が無制限で、サポートにも期間の制限はないと案内しています(studio US)。デジハクは6ヶ月か12ヶ月で、サポート期間が終わったあとも教材は何度でも見返せると書いています(デジハク よくある質問)。

向き不向きをまとめるとこうなります。

  • 期間無制限が向いている人: 仕事や子育てで、週に何時間学べるか読めない人。注意点として、締め切りがないと後回しにしやすく、修了まで時間がかかることがあります
  • 6か月・12か月の期限つきが向いている人: 決まった期間で集中して終わらせたい人。注意点として、期限を過ぎると講師に質問できなくなり、延長の費用は説明会で聞かないと分かりません

たとえばデジハクの6ヶ月プラン248,000円を6か月で割ると、1か月あたり約41,300円です。この金額に見合うだけ添削や質問を使えるかどうかを考えると、判断しやすくなります。

申し込み前の無料相談で確かめる手順

申し込む前に、無料の説明会や個別相談で総額を出してもらいます。デジハクは「無料説明会」、studio USは「無料の個別相談」を案内しています。

  1. 公式ページの料金欄を見て、受講料と「(税込)」の表示をメモします
  2. 無料説明会か無料の個別相談を予約し、「支払総額」「分割の回数と手数料」「入学金の有無」を聞きます
  3. 「使うソフトは何か」「Premiere ProとAfter Effectsの両方が必要か」を聞いて、Adobeのプランと価格で12か月分を計算します
  4. 「この講座は一般教育訓練給付の対象ですか」と聞きます。対象なら、ハローワークで自分の雇用保険の加入期間を確かめます
  5. 「受講料+ソフト代−給付金」の総額を、ほかのスクールと同じ表に並べます

つまずきやすいのは手順4です。給付金の手続きは、受講を始める前にしなければならないことがあります。申し込んだあとでは間に合わない場合もあるので、先にハローワークで流れを聞いてください。

もう1つは、キャンペーンの期限です。「先着15名」のような表示があっても、総額を計算する前に申し込むのはやめておきましょう。

よくある質問

動画編集スクールの料金相場はいくらですか?

公式ページで確かめた受講料は、税込11万〜44.8万円でした(2026年11月時点)。Adobeのソフト代を1年分足すと、総額はおよそ19万〜49万円になります。

Adobeのソフト代はスクール代に含まれますか?

今回見たデジハクとstudio USは、どちらも含まれていません。どちらも受講生が自分で準備する形です。Premiere単体なら通常12か月で39,360円、Creative Cloud Proなら108,960円かかります。

給付金は誰でも使えますか?

いいえ、誰でもは使えません。雇用保険に入っていた期間が3年以上(初めての人は1年以上)あり、しかも講座が対象に指定されている必要があります。支給は修了したあとです。

スクールに通わずに独学でも学べますか?

学べます。DaVinci ResolveやCapCutなど無料のソフトで始める方法があります。どこでつまずきやすいかは独学の判断表にまとめました。独学で手が止まったところだけスクールで補う、という順番なら、払う額も減らせます。
