動画編集ソフトの無料版、透かしが消える条件とは

公開 2026-10-15 · 23分で読めます

#動画編集 #DaVinci Resolve #CapCut #初心者

無料の動画編集ソフトで透かし(ウォーターマーク)を出さない方法は2つあります。1つは、DaVinci Resolve・Clipchamp・iMovie・Shotcut のような、無料の範囲で使えば透かしが付かないソフトを選ぶことです。もう1つは、Filmora のように無料版だと透かしが入るソフトの有料版を買うことです。CapCut・Clipchamp・DaVinci Resolve は、有料の素材や機能を使ったかどうかで書き出せる内容が変わります。書き出す前に、有料の素材や機能が残っていないか確かめましょう。

この記事では、各社の公式ヘルプや料金ページに書かれている無料版の仕様を並べ、「透かしが付く条件」と「外す方法」をまとめました。料金と仕様は2026年10月15日時点の公式情報です。変わることがあるので、最新の内容は必ず公式ページで確認してください。

この記事の要点

  • DaVinci Resolve等は無料範囲なら透かし無しで書き出せる
  • Filmoraは無料版だと透かしが入り有料版で消える
  • CapCut等は有料素材・機能使用時のみ制限がかかる

あなたに合うのはどれ?

お金をかけずに透かしなしで公開したいなら、パソコンの人は DaVinci Resolve か Clipchamp、iPhone や Mac の人は iMovie、スマホでショート動画を作るなら CapCut(無料素材だけを使う)が選びやすいです。

あなたの状況おすすめ理由と注意点
パソコンで本格的に学びたい・YouTube用に4Kで書き出したいDaVinci Resolve無料版でも Ultra HD(3840×2160)・60fpsまで書き出せます。ある程度の性能のパソコンが必要です
Windows で学校や仕事の短い動画をすぐ作りたいClipchamp透かしは付きません。無料版の書き出しは1080pまでです
iPhone・iPad・Mac を持っているiMovie無料で4Kにも対応しています。Windows では使えません
Windows・Linux で、完全無料のソフトを使いたいShotcut無料のオープンソースソフトで、有料版はありません
スマホで TikTok・ショート動画を作りたいCapCutテンプレートが豊富です。Pro 素材を使うと透かしを外すのに Pro が必要です
有料でもいいから、日本語の案内が多い分かりやすいソフトがいいFilmora・PowerDirector無料版には制限があります。透かしなしで書き出すには有料版を前提に考えましょう

透かしが付くかどうかは何で決まるのですか?

透かしが付くかどうかは、「ソフトの無料版のルール」と「有料の素材や機能を使ったかどうか」の2つで決まります。ソフトごとに考え方が違うので、3つのタイプに分けると分かりやすくなります。

タイプ1:無料の範囲なら透かしが付かない

無料版で使える機能だけで編集すれば、書き出した動画に透かしが入らないタイプです。DaVinci Resolve の無料版は、8bitの動画形式で Ultra HD(3840×2160)・60fpsまで扱えます。有料版の DaVinci Resolve Studio は、高度な機能を足すための製品です(Blackmagic Design 公式)。iMovie は Apple が「無料」と案内しています(Apple 公式)。Shotcut は「無料・オープンソース・クロスプラットフォームの動画エディター」と公式サイトで説明されています(Shotcut 公式)。

タイプ2:無料版では透かしが入る

無料版で書き出すと、ソフトのロゴが入るタイプです。Filmora の公式ページには、無料版で出力した動画にはウォーターマークが入ると書かれています(Filmora 公式:無料版と有料版の違い)。

タイプ3:有料の素材・機能を使ったときだけ制限がかかる

ふだんは無料で書き出せますが、有料の素材やエフェクトを使うと、透かしを外せなくなったり書き出せなくなったりするタイプです。CapCut の公式ヘルプによると、次のものがプロジェクトに入っていると、書き出すときに CapCut Pro への加入を求められます(CapCut ヘルプ)。

  • バッジの付いたテンプレート・エフェクト・フォント・音楽・ステッカー
  • AI機能
  • 有料のトランジションやLUT
  • 4K・60fpsの設定
  • 無料版の長さの上限をこえる動画

Clipchamp は透かしを付けません。そのかわり、プランに含まれないプレミアム素材を使うと、アップグレードするまで書き出せません(Microsoft サポート)。

主な無料動画編集ソフトの透かし条件を比較すると?

透かしなしで書き出しやすいのは DaVinci Resolve・Clipchamp・iMovie・Shotcut です。Filmora は有料版にしないと透かしが消えません。下の表は各社の公式ページの内容をまとめたものです(2026年10月時点。最新の内容は公式で確認してください)。

DaVinci Resolve:無料版でも4Kまで書き出せる

DaVinci Resolve の無料版は、8bitの動画形式で最大60fps・Ultra HD(3840×2160)まで扱えます。公式サイトでは、写真を編集する「Photo ページ」などを加えた最新版 DaVinci Resolve 21 が紹介されています。有料版の DaVinci Resolve Studio 21 は、米国の公式ページで295ドルです(2026年10月時点。最新の価格は公式で確認してください)(Blackmagic Design 公式)。

注意点:公式フォーラムでは、無料版で Studio だけの機能を使うと、その部分に透かしが表示されたというユーザーの投稿があります(Blackmagic Forum)。知らないうちに Studio 用のエフェクトを使っていることもあるので、書き出す前に確認しましょう。

Clipchamp:透かしは付かないが、プレミアム素材は書き出せない

Microsoft の公式サポートには、Clipchamp は映像・音声などの透かしを付けないと書かれています。ただし個人アカウントでは、プランに含まれないプレミアム素材を使うと、アップグレードするまで書き出しも保存もできません(Microsoft サポート)。無料版の書き出しは1080pまでです。Microsoft 365 Personal・Family に含まれるプレミアム機能を使うと、4Kまで書き出せます(Clipchamp 料金ページ)。

CapCut:エンディング動画と Pro 素材に注意

CapCut の公式ヘルプによると、透かしは多くの場合「書き出し」そのものではなく、最初から付いているエンディング動画やテンプレートの部品から入ります。手順は次のとおりです(CapCut ヘルプ)。

  1. タイムラインの最後まで移動する
  2. CapCut のロゴが入ったエンディング動画やロゴの重ね表示を消す
  3. ほかのトラックに透かしが隠れていないか確認する
  4. 書き出す

いっぽうで、Pro 素材を使った動画は、1080pを選んでも透かしを外すには Pro が必要です。スマホ版は Pro に入らなくても透かし付きで書き出せますが、透かしを外すには加入が必要になります。無料版にはスマホで15分という長さの上限もあります(地域によって違います)(CapCut ヘルプ)。CapCut Pro の料金は国やプランで変わるので、アプリや公式サイトで確認してください。

Filmora:有料プランを買うと透かしが消える

Filmora の無料版で書き出した動画には透かしが入ります。ただし公式ページには、新しく登録した人は透かしなしで書き出せる特典をもらえるとも書かれています(Filmora 公式:無料版と有料版の違い)。Windows版の個人向けプランは次の3つで、どれも透かしなしで書き出せます(Filmora 公式ストア)。

PowerDirector:無料版は「一部の書き出しが制限」

CyberLink の公式ページによると、無料版の PowerDirector Essential では基本的な編集ができますが、「高度なAIツールや一部の書き出しオプション」は制限されています(CyberLink 公式)。有料版には、サブスクリプションの PowerDirector 365 と、買い切りの PowerDirector 2027 があります。米国の料金ページでは、PowerDirector 2027 は139.99ドルです(2026年10月時点。最新の価格は公式で確認してください)(CyberLink 料金ページ)。

今回見た公式ページには、透かしがあるかどうか、どこにどの大きさで入るかは書かれていませんでした。透かしなしで書き出したいなら、ダウンロードする前に公式の最新の比較表を確認してください。

iMovie と Shotcut:無料で使えるシンプルなソフト

Apple は iMovie を「無料」と案内しています。iPhone・iPad・Mac で使えて、4Kの動画も扱えます。必要なのは iOS/iPadOS 16.0以降、Mac なら macOS 11.5.1以降・メモリ4GB・空き容量3.5GBです(Apple 公式)。Shotcut は Windows・Mac・Linux で使える無料のオープンソースソフトで、2026年10月時点の最新版は26.9です(Shotcut 公式)。どちらも有料版がないので、透かしを気にせず練習できます。

透かしを消す正しい方法はどれですか?

正しい方法は「有料版を買う」「有料の素材・機能を外す」「最初から透かしのないソフトを使う」の3つです。透かし除去ツールや画面録画で消す方法はおすすめしません。

方法1:有料版・有料プランにする

Filmora のように無料版では透かしが入るソフトは、有料版にするのがいちばん確実です。Filmora の公式ページでも、有料版を買うのがほかの方法より良いと案内されています(Filmora 公式:ロゴを消す方法)。買う前に無料版で操作をひととおり試し、自分に合うか確かめましょう。

方法2:有料の素材・機能をプロジェクトから外す

CapCut・Clipchamp・DaVinci Resolve は、有料の素材や機能を外せば、無料のまま書き出せる場合があります(CapCut ヘルプ、Microsoft サポート)。

  1. 有料のマーク(王冠・ダイヤ・「Pro」など。ソフトによって違います)が付いた素材を探す
  2. フォント・BGM・エフェクト・トランジションを、マークのない無料のものに取り替える
  3. 解像度とフレームレートを無料版の範囲(例:Clipchamp は1080p、CapCut は4K・60fpsを使わない)に戻す

方法3:CapCut のエンディング動画を消す

CapCut では、タイムラインの最後にあるロゴ入りのエンディング動画を消す方法が公式に案内されています(CapCut ヘルプ)。消しても透かしが残るときは、CapCut のサポートに問い合わせるよう案内されています。

避けたい方法:透かし除去ツールや画面録画

Filmora の公式ページは、プレビューを画面録画して書き出す方法は利用規約に違反するおそれがあり、最悪の場合ソフトが使えなくなると注意しています(Filmora 公式:ロゴを消す方法)。除去ツールを使っても、ロゴの大きさや場所によってはきれいに消えません。出どころの分からない「透かしを消せる」ソフトには、ウイルスなどの危険もあります。正しい方法で対応しましょう。

初心者はどのソフトを選べばいいですか?

初心者は、まず「透かしなしで書き出せるか」と「自分のパソコンやスマホで動くか」を確かめてから選ぶと失敗しにくくなります。どのソフトにも良い点と注意点があるので、向いている人・向いていない人をまとめました。

DaVinci Resolve

  • 向いている人:無料で本格的な編集や色の調整を学びたい人、将来はプロのような作業もしたい人
  • 向いていない人:とにかく早く1本仕上げたい人、性能が低めのパソコンを使っている人
  • 注意点:機能が多いので、最初は画面の多さに戸惑いやすいです。Studio だけの機能を使うと透かしが入るという報告もあります(Blackmagic Forum)。

Clipchamp

  • 向いている人:Windows で手軽に始めたい人、学校や仕事の短い動画を作りたい人
  • 向いていない人:無料で4Kで書き出したい人(無料版は1080pまで)
  • 注意点:プレミアム素材を使うと、アップグレードするまで書き出せません(Clipchamp 料金ページ、Microsoft サポート)。

CapCut

  • 向いている人:スマホでショート動画を作りたい人、テンプレートで手早く仕上げたい人
  • 向いていない人:有料素材を使わないように気をつけるのが面倒な人、長い動画を作りたい人
  • 注意点:Pro 素材や4K・60fpsを使ったまま書き出すと、加入を求められます(CapCut ヘルプ)。

Filmora・PowerDirector

  • 向いている人:日本語の案内が多い有料ソフトで、迷わず編集したい人
  • 向いていない人:お金をかけずに、完成した動画を公開したい人
  • 注意点:Filmora の無料版では透かしが入ります(Filmora 公式)。年間プランは自動で更新されるので、解約する時期も決めておきましょう(Filmora 公式ストア)。

iMovie・Shotcut

  • 向いている人:iMovie は iPhone や Mac を持っている人、Shotcut は Windows や Linux で無料のまま使いたい人
  • 向いていない人:iMovie は Windows の人(使えません)、Shotcut は凝ったテンプレートを使いたい人
  • 注意点:iMovie には iOS 16.0以降・macOS 11.5.1以降が必要です(Apple 公式)。古い端末では使えないことがあります。

書き出す前に何を確認すればいいですか?

書き出す前に、「有料の素材や機能を使っていないか」「エンディングやロゴが入っていないか」「解像度の設定が無料版の範囲か」の3つを確認しましょう。次のチェックリストを使うと見落としが減ります。

書き出し前チェックリスト

  1. タイムラインの最後に、ソフトのロゴやエンディング動画が入っていないか(CapCut など)
  2. 王冠マークや「Pro」マークなど、有料を示すマークの付いた素材を使っていないか
  3. 解像度とフレームレートが無料版の範囲か(Clipchamp の無料版は1080pまで、DaVinci Resolve の無料版は Ultra HD・60fpsまで)(Clipchamp 料金ページ、Blackmagic Design 公式)
  4. 書き出しの設定画面に「透かしあり」などの表示や鍵マークがないか
  5. 書き出した動画を最初から最後まで再生して、透かしが入っていないか

学び始める順番の例

最初の1本は、「カット・テロップ・BGM」だけを使って1〜3分の短い動画を作るのがおすすめです。慣れてきたら、トランジションや色の調整を少しずつ足していきましょう。最初から有料のエフェクトに頼らなければ、透かしで悩むことも減ります。

よくある質問

無料で透かしなしの動画編集ソフトはありますか?

あります。DaVinci Resolve・Clipchamp・iMovie・Shotcut は、無料の範囲で編集すれば透かしなしで書き出せるか、公式に無料と案内されています(Blackmagic Design 公式、Microsoft サポート、Apple 公式、Shotcut 公式)。ただし、有料の素材や機能を使うと制限がかかるソフトもあります。

Filmora の無料版で透かしを消す方法はありますか?

公式ページでは、有料版を買うのがいちばん確実な方法と案内されています。画面録画で消す方法は、利用規約に違反するおそれがあると注意されています(Filmora 公式)。新しく登録した人は、透かしなしで書き出せる特典をもらえる場合があります(Filmora 公式)。内容は変わることがあるので、公式で確認してください。

CapCut の最後に出るロゴは消せますか?

消せます。公式ヘルプでは、タイムラインの最後にあるロゴ入りのエンディング動画を消す方法が案内されています(CapCut ヘルプ)。ただし、Pro 素材を使った動画は、1080pで書き出しても透かしを外すには Pro が必要です(CapCut ヘルプ)。

透かし除去ツールで消しても大丈夫ですか?

おすすめしません。画質が落ちたりきれいに消えなかったりすることがあり、方法によっては利用規約に違反するおそれもあります(Filmora 公式)。有料版にするか、透かしのないソフトを使うのが安全です。

Clipchamp で書き出せないのはなぜですか?

プランに含まれないプレミアム素材や機能を使っている可能性があります。Clipchamp は透かしを付けないかわりに、アップグレードするまで書き出しを止める仕組みです(Microsoft サポート)。プレミアム素材を外し、解像度を1080p以下にすれば、無料のまま書き出せます。

次にやること
