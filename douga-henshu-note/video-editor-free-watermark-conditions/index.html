動画編集ソフトの無料版、透かしが消える条件とは

無料の動画編集ソフトで透かし(ウォーターマーク)を消すには、2つの方法があります。1つは、DaVinci Resolve・Clipchamp・iMovie・Shotcut のように、もともと無料版でも透かしが付かないソフトを選ぶ方法です。もう1つは、Filmora のように無料版では必ず透かしが付くソフトの有料版を買う方法です。CapCut と Clipchamp では、透かしやエンディングを外せるかどうかが「有料の素材や機能を使ったかどうか」で変わるため、書き出す前の確認が大切です。

この記事では、各社の公式ヘルプや料金ページに書かれている無料版の仕様を並べて、「透かしが付く条件」と「外せる条件」を整理します。料金や仕様は2026年10月時点の公式情報をもとにしています。変わることがあるので、最新の内容は必ず公式で確認してください。

透かしが付くかどうかは何で決まるのですか?

透かしが付くかどうかは、「ソフトの無料版そのものの決まり」と「有料の素材や機能を使ったか」の2つで決まります。ソフトによってルールの考え方が違うので、大きく3つのタイプに分けると分かりやすくなります。

タイプ1:無料版でも透かしが付かない

無料版で使える機能だけで編集すれば、書き出した動画に透かしが入らないタイプです。DaVinci Resolve は、無料版で Ultra HD(3840×2160)・60fpsまでの書き出しに対応していて、有料版の DaVinci Resolve Studio は高度な機能を足すための製品という位置づけです(Blackmagic Design 公式)。Shotcut は「無料・オープンソース・クロスプラットフォームの動画エディター」と公式サイトで説明されています(Shotcut 公式)。

タイプ2:無料版では必ず透かしが付く

無料版で書き出すと、ソフトのロゴが自動で入るタイプです。Filmora は公式ページで、無料版のロゴは「無料版の仕様、つまり機能制限」であり、無料版のユーザーには必ず表示されると説明しています(Filmora 公式:ロゴを消す方法)。

タイプ3:有料の素材・機能を使ったときだけ制限がかかる

基本は無料で書き出せるものの、有料の素材やエフェクトを使うと、透かしを外せなくなったり書き出しそのものができなくなったりするタイプです。CapCut の公式ヘルプには、プロジェクトに Pro 会員向けの要素(テンプレート、エフェクト、フォント、音楽、ステッカー、AI生成の内容、4K・60fpsの設定など)が含まれていると、書き出し時に CapCut Pro への加入を求められると書かれています(CapCut ヘルプ)。Clipchamp は透かしを付けない代わりに、プランに含まれないプレミアム素材を使ったプロジェクトはアップグレードするまで書き出せない仕組みです(Microsoft サポート)。

主な無料動画編集ソフトの透かし条件を比較すると?

透かしなしで書き出しやすいのは DaVinci Resolve・Clipchamp・iMovie・Shotcut で、Filmora は有料版にしないと透かしが消えません。下の表は、各社の公式ページに書かれている内容をまとめたものです(2026年10月時点・最新は公式で確認)。

ソフト無料版の透かし透かしや制限が出る条件外す方法対応環境
DaVinci Resolve無料の機能だけなら付かないStudio(有料版)だけの機能を使ったときStudio を買う/Studio だけの機能を外すWindows・Mac・Linux
Clipchamp付かないプレミアム素材・機能を使うと書き出せないMicrosoft 365 の対象プランにする/プレミアム素材を外すブラウザ・Windows アプリ
CapCut主にエンディングやテンプレート由来Pro 素材・機能、4K・60fps などを使ったときエンディング動画を削除/Pro に加入/Pro 素材を外すスマホ・PC・Web
Filmora必ず付く無料版で書き出すとき有料プランを買うWindows・Mac など
PowerDirector公式では「一部の書き出しオプションが制限」無料版(Essential)で書き出すとき有料版(365・買い切り版)を買うWindows・Mac など

各ソフトの根拠は、このあとの小見出しで出典と一緒に説明します。

DaVinci Resolve:無料版でも4Kまで書き出せる

DaVinci Resolve の無料版は、8bitの動画形式で最大60fps・Ultra HD(3840×2160)まで扱えます(Blackmagic Design 公式)。有料版の DaVinci Resolve Studio は、AI機能(DaVinci Neural Engine)、ノイズ除去、追加の Resolve FX、10bit・120fps、4Kを超える解像度などに対応していて、価格は米国の公式ページで295ドルです(2026年10月時点・最新は公式で確認)(Blackmagic Design 公式)。

注意点として、無料版で Studio だけの機能を使うと、その部分に透かしが表示されるという報告が公式フォーラムに投稿されています(Blackmagic Forum)。気づかずにエフェクトを使ってしまうことがあるので、書き出し前に見直しておくと安心です。

Clipchamp:透かしは付かないが、プレミアム素材は書き出せない

Microsoft の公式サポートには、Clipchamp は動画に映像・音声などの透かしを付けないと書かれています(Microsoft サポート)。無料版の書き出しは1080pまで、Microsoft 365 Personal・Family で使えるプレミアム機能では4Kまで書き出せます(Clipchamp 料金ページ)。

ただし個人アカウントでは、プランに含まれないプレミアム素材を使うと、透かしは付かない代わりにアップグレードするまで書き出しと保存ができません(Microsoft サポート)。

CapCut:エンディング動画と Pro 素材に注意

CapCut の公式ヘルプでは、透かしは多くの場合「書き出しそのもの」ではなく、自動で付くエンディング動画やテンプレートの要素から来ると説明されています。タイムラインの最後にある CapCut のエンディング動画を削除すれば外せるほか、設定(デスクトップ版は環境設定)で「デフォルトのエンディングを追加」をオフにすると、新しいプロジェクトにエンディングが付かなくなります(CapCut ヘルプ)。

一方、Pro 素材を使った動画は、1080pを選んでも透かしを外すには Pro が必要だと書かれています。デスクトップ版では、Pro 会員でないと「4K」「60fps」「透かしなし」などの項目がロックされることがあります(CapCut ヘルプ)。CapCut Pro の料金は国やプランで変わるため、アプリや公式サイトで確認してください。

Filmora:有料プランを買うと透かしが消える

Filmora の無料体験版で書き出した動画には透かしが入ります。ただし公式ページには、新しいユーザー向けに透かしなしで書き出せる無料体験があるとも書かれています(Filmora 公式:無料版と有料版の違い)。Windows版の個人向けプランは次のとおりで、どのプランでも透かしなしで書き出せます(Filmora 公式ストア)。

プラン価格(税込)特徴

年間プランは自動で更新されるので、続けて使わないときは更新を止める手続きが必要です。永続ライセンスは、そのバージョン(Filmora 16)だけが対象であることも覚えておきましょう(Filmora 公式ストア)。

PowerDirector:無料版は「一部の書き出しが制限」

CyberLink の公式ページでは、無料版の PowerDirector Essential でも基本的な編集ツールと一部のAI機能をずっと無料で使える一方、「一部の書き出しオプションは無料版では制限されています」と説明されています(CyberLink 公式)。有料版には、サブスクリプションの PowerDirector 365 と、買い切りの PowerDirector 2027 があります。米国の料金ページでは、買い切り版が139.99ドルと表示されています(2026年10月時点・最新は公式で確認)(CyberLink 料金ページ)。

今回確認した公式ページには、透かしの位置や大きさまでは書かれていませんでした。透かしなしで書き出したいときは、ダウンロードする前に最新の比較表を公式で確認してください。

iMovie と Shotcut:無料で使えるシンプルな選択肢

Apple は iMovie を「無料」と紹介していて、iPhone・iPad・Mac に対応し、4Kビデオも扱えます(Apple 公式)。Shotcut は Windows・Mac・Linux で使える無料のオープンソースソフトです(Shotcut 公式)。どちらも有料版に誘導する仕組みがないので、透かしの心配をせずに練習しやすいソフトです。

透かしを消す正しい方法はどれですか?

透かしを消す正しい方法は、「有料版を買う」「有料の素材・機能を外す」「初めから透かしのないソフトを使う」の3つです。透かし除去ツールで消したり、画面を録画して撮り直したりする方法はおすすめしません。

方法1:有料版・有料プランにする

Filmora のように無料版では必ず透かしが付くソフトは、有料版にするのが確実です。Filmora の公式ページでも、有料版の購入が透かしを完全に消す唯一の方法だと案内されています(Filmora 公式:ロゴを消す方法)。買う前に、無料版で操作に慣れておくと失敗しにくくなります。

方法2:有料の素材・機能をプロジェクトから外す

CapCut・Clipchamp・DaVinci Resolve では、有料の素材や機能を外せば、無料のまま書き出せる場合があります(CapCut ヘルプ、Microsoft サポート)。たとえば、王冠マークやダイヤマークの付いたフォント・BGM・エフェクトを、無料のものに置き換えるといったやり方です(マークの形はソフトによって違います)。

方法3:CapCut のエンディング動画を削除する

CapCut では、タイムラインの最後にあるエンディング動画を削除し、設定で自動追加をオフにする方法が公式に案内されています(CapCut ヘルプ)。

避けたい方法:透かし除去ツールや画面録画

Filmora の公式ページは、他社の透かし除去ツールや画面録画で消す方法について、画質が落ちるおそれや利用規約に反するおそれがあるとして勧めていません(Filmora 公式:ロゴを消す方法)。出どころの分からない「透かしを消せる」ソフトには、ウイルスなどの危険もあります。正規の方法で対応しましょう。

初心者はどのソフトを選べばいいですか?

初心者は、「透かしなしで書き出せること」と「自分のパソコンやスマホで動くこと」を先に確かめてから選ぶと失敗しにくくなります。どのソフトにも良い点と注意点があるので、向き不向きを整理しておきます。

DaVinci Resolve

  • 向いている人:無料で本格的な編集や色の調整を学びたい人、将来はプロのような作業もしたい人
  • 向いていない人:とにかく早く1本仕上げたい人、性能が低めのパソコンを使っている人
  • 注意点:機能が多いので、最初は画面の多さに戸惑いやすいです。Studio だけの機能を使うと透かしが表示されることがあります(Blackmagic Forum)。

Clipchamp

  • 向いている人:Windows でソフトのインストールを最小限にしたい人、学校や仕事の短い動画を作りたい人
  • 向いていない人:4Kで書き出したい人(無料版は1080pまで)
  • 注意点:プレミアム素材を使うと、アップグレードするまで書き出せません(Clipchamp 料金ページ、Microsoft サポート)。

CapCut

  • 向いている人:スマホでショート動画を作りたい人、テンプレートで手早く仕上げたい人
  • 向いていない人:有料素材を使わないよう気をつけるのが面倒な人
  • 注意点:編集中は Pro の機能も試せますが、使ったまま書き出すと加入を求められます(CapCut ヘルプ)。

Filmora・PowerDirector

  • 向いている人:日本語の案内が多い有料ソフトで、操作に迷わず編集したい人
  • 向いていない人:お金をかけずに完成した動画を公開したい人
  • 注意点:Filmora は無料版では透かしが付きます(Filmora 公式)。年間プランは自動更新なので、解約するタイミングも決めておきましょう(Filmora 公式ストア)。

iMovie・Shotcut

  • 向いている人:iMovie は iPhone や Mac を持っている人、Shotcut は Windows や Linux で無料のまま使いたい人
  • 向いていない人:iMovie は Windows の人(対応していません)、Shotcut は凝ったテンプレートを使いたい人
  • 注意点:iMovie は iOS 16.0以降・macOS 11.5.1以降などが必要です(Apple 公式)。古い端末では使えないことがあります。

書き出す前に何を確認すればいいですか?

書き出す前には、「有料の素材や機能を使っていないか」「エンディングやロゴが入っていないか」「解像度の設定が無料版の範囲内か」の3つを確認しましょう。次のチェックリストを使うと、見落としを減らせます。

書き出し前チェックリスト

  1. タイムラインの最後に、ソフトのロゴやエンディング動画が入っていないか(CapCut など)
  2. 王冠マークなど、有料を示すマークの付いた素材を使っていないか
  3. 解像度・フレームレートが無料版の範囲か(Clipchamp の無料版は1080pまで、DaVinci Resolve の無料版は Ultra HD・60fpsまで)(Clipchamp 料金ページ、Blackmagic Design 公式)
  4. 書き出しの設定画面に「透かしあり」などの表示がないか
  5. 書き出した動画を最初から最後まで再生して、透かしが入っていないか

学び始めの順番の例

たとえば、最初の1本は「カット・テロップ・BGM」だけで1〜3分の短い動画を作ってみる、という順番がおすすめです。慣れてきたら、トランジションや色の調整を少しずつ足していきます。最初から有料の効果に頼らなければ、透かしで悩むことも減らせます。

よくある質問

無料で透かしなしの動画編集ソフトはありますか?

あります。DaVinci Resolve・Clipchamp・iMovie・Shotcut は、無料で使える範囲で編集すれば透かしなしで書き出せる、または公式に無料と案内されています(Blackmagic Design 公式、Microsoft サポート、Apple 公式、Shotcut 公式)。ただし、有料の素材や機能を使うと制限がかかるソフトもあります。

Filmora の無料版で透かしを消す方法はありますか?

公式には、有料版の購入が透かしを完全に消す唯一の方法だと案内されています(Filmora 公式)。新しいユーザーには、透かしなしで書き出せる無料体験が用意されている場合もあります(Filmora 公式)。内容は変わることがあるので、公式で確認してください。

CapCut の最後に出るロゴは消せますか?

公式ヘルプでは、タイムラインの最後にあるエンディング動画を削除すれば外せると案内されています。設定で「デフォルトのエンディングを追加」をオフにすれば、次からは自動で付きません(CapCut ヘルプ)。ただし、Pro 素材を使った動画は、透かしを外すのに Pro が必要です(CapCut ヘルプ)。

透かし除去ツールで消しても大丈夫ですか?

おすすめしません。画質が落ちるおそれや、利用規約に反するおそれがあると、ソフトの公式ページでも注意されています(Filmora 公式)。有料版にするか、透かしのないソフトを使うのが安全です。

Clipchamp で書き出せないのはなぜですか?

プランに含まれないプレミアム素材や機能を使っている可能性があります。Clipchamp は透かしを付ける代わりに、アップグレードするまで書き出しを止める仕組みです(Microsoft サポート)。プレミアム素材を外すと、無料のまま書き出せます。
