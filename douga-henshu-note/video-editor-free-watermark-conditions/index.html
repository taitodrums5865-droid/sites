#動画編集 #透かし #DaVinci Resolve #Clipchamp

無料の動画編集ソフトで透かし(ウォーターマーク)を付けずに書き出す方法は2つです。1つは、DaVinci Resolve・Clipchamp・iMovie・Shotcut・Adobe Premiere のモバイル版のように、無料の範囲なら透かしが付かないソフトを選ぶことです。もう1つは、Filmora のように無料版だと透かしが入るソフトの有料版を買うことです。CapCut・Clipchamp・Adobe Express は、有料の素材や機能を使うと透かしが付いたり書き出せなかったりするので、書き出す前に有料素材が残っていないか確かめましょう。

各社の公式ヘルプと料金ページに書かれている無料版の仕様を並べ、「透かしが付く条件」と「外す方法」をまとめました。料金は2026年11月19日に確認しました。一部のヘルプページは2026年10月15日に確認した内容です。どのページをいつ確認したかは、末尾の出典欄に書いています。料金や仕様は変わることがあるので、最新の内容は必ず公式ページで確認してください。

あなたに合うのはどれ?

お金をかけずに透かしなしで公開したい場合のおすすめです。パソコンなら DaVinci Resolve か Clipchamp、iPhone・Mac なら iMovie、スマホでショート動画を作るなら Adobe の Premiere モバイル版か CapCut(無料素材だけを使う)が選びやすいです。

透かしが付くかどうかは何で決まるのですか?

透かしが付くかどうかは、「ソフトの無料版のルール」と「有料の素材や機能を使ったかどうか」の2つで決まります。ソフトごとに考え方が違うので、3つのタイプに分けると分かりやすくなります。

タイプ1:無料の範囲なら透かしが付かない

無料で使える機能だけで編集すれば、書き出した動画に透かしが入らないタイプです。

  • DaVinci Resolve:無料版は、8bitの動画形式で Ultra HD(3840×2160)・60fpsまで扱えます(Blackmagic Design 公式)
  • iMovie:Apple が「無料」と案内しています(Apple 公式)
  • Shotcut:公式サイトで、無料・オープンソースのソフトと説明されています(Shotcut 公式)
  • Adobe Premiere(モバイル版):Adobe の公式ページに「透かしなし」と書かれています(Adobe 公式)

タイプ2:無料版では透かしが入る

無料版で書き出すと、ソフトのロゴが入るタイプです。

  • Filmora:公式ページに、無料版で書き出した動画には透かしが入ると書かれています(Filmora 公式:無料版と有料版の違い)
  • Adobe Premiere Elements:体験版で書き出すと透かしが入り、製品を買うと消せると公式ヘルプで案内されています(Adobe ヘルプ)

タイプ3:有料の素材・機能を使ったときだけ制限がかかる

ふだんは無料で書き出せますが、有料の素材やエフェクトを使うと、透かしが付いたり書き出せなくなったりするタイプです。

  • CapCut:公式ヘルプによると、バッジの付いたテンプレート・エフェクト・フォント・音楽・ステッカー、AI機能、有料のトランジションやLUT、4K・60fps(PC版)、スマホ版の15分をこえる動画(地域によって違います)を使うと、書き出すときに Pro への加入を求められます(CapCut ヘルプ)
  • Clipchamp:透かしは付きません。そのかわり、プランに含まれないプレミアム素材を使うと、アップグレードするまで書き出せません(Microsoft サポート)
  • Adobe Express:無料プランは「プレミアムコンテンツを使ったときに透かしが入る」と、公式の比較表に書かれています(Adobe Express 比較表)

主な無料動画編集ソフトの透かし条件を比較すると?

DaVinci Resolve:無料版でも4Kまで書き出せる

DaVinci Resolve は、無料版でも8bitの動画形式で最大60fps・Ultra HD(3840×2160)まで扱えます。有料版の DaVinci Resolve Studio は買い切りで、米国の公式ページでは通常価格295ドルです(2026年11月19日確認)。セールで値下がりすることがあるので、買う前に公式で今の価格を確認してください(Blackmagic Design 公式)。

注意点:公式フォーラムには、無料版で Studio だけの機能を使ったらその部分に透かしが入った、というユーザーの投稿があります(Blackmagic Forum)。知らないうちに Studio 用のエフェクトを使っていることもあるので、書き出す前に確認しましょう。

Clipchamp:透かしは付かないが、プレミアム素材を使うと書き出せない

Clipchamp は透かしを付けません。そのかわり、個人アカウントでプランに含まれないプレミアム素材を使うと、アップグレードするまで書き出しも保存もできません(Microsoft サポート)。無料版の書き出しは1080pまでです。Microsoft 365 Personal・Family に入ると、4Kの書き出しとプレミアム素材が使えます(Clipchamp 料金ページ)。料金ページには価格が書かれていないので、Microsoft 365 の価格は Microsoft の公式ページで確認してください。

CapCut:エンディング動画・Pro 素材・PC版の設定に注意

CapCut の透かしは、多くの場合、テンプレートに最初から入っているエンディング動画やロゴの部品から入ります。公式ヘルプで案内されている消し方は次のとおりです(CapCut ヘルプ)。

  1. タイムラインの最後まで移動する
  2. CapCut のロゴが入ったエンディング動画や、ロゴの重ね表示を消す
  3. ほかのトラックに透かしが隠れていないか確認する
  4. 書き出す

ただし、次のときは Pro が必要です(CapCut ヘルプ)。

  • Web版:Pro 素材を使った動画は、1080pで書き出しても、透かしを外すには Pro が必要です
  • PC版:Pro でない人は、書き出し画面の「透かしなし」の項目がロックされています
  • スマホ版:無料の長さや解像度の上限をこえると、「透かしなし」を選ぶのに Pro が必要です。加入しなくても、透かし付きなら書き出せます

CapCut Pro の料金は国やプランで変わるので、アプリや公式サイトで確認してください。

Filmora の無料版で書き出した動画には透かしが入ります。ただし公式ページには、新しく登録した人向けに、透かしなしで書き出せる特典があるとも書かれています。条件や期間は書かれていないので、使う前に確認してください(Filmora 公式:無料版と有料版の違い)。Windows版の個人向けプランは次の3つで、どれも透かしなしで書き出せます(Filmora 公式ストア)。

PowerDirector:透かしなしで書き出すなら有料版が前提

PowerDirector の無料版(Essential)は、透かしなしで書き出せるソフトとしては選ばないでください。CyberLink の公式ページには、無料版では基本的な編集ができる一方で「高度なAIツールや一部の書き出しオプション」が制限されるとだけ書かれています。無料版で透かしなしに書き出せるとは書かれていません(CyberLink 公式)。透かしなしで確実に書き出す方法は、有料版にすることです。米国の料金ページでは、2026年11月19日時点で次の価格です(CyberLink 料金ページ)。

  • PowerDirector 2027(買い切り):139.99ドル
  • PowerDirector 365(サブスクリプション):年54.99ドル(表示上の通常価格は79.99ドル)
  • Director Suite 365(PhotoDirector・AudioDirector も入ったセット):年99.99ドル(表示上の通常価格は149.99ドル)

お金をかけずに透かしなしで公開したいなら、PowerDirector の無料版ではなく、DaVinci Resolve・Clipchamp・iMovie・Shotcut を選びましょう。

Adobe Express の透かしを外す方法:Express の無料プランで透かしが入るのは、プレミアムコンテンツを使ったときだけです(Adobe Express 比較表)。無料のまま透かしをなくすには、次の手順で進めます。

  1. 編集画面で、王冠マークの付いたテンプレート・写真・動画・フォント・音楽などを探す
  2. 見つけたものを、マークのない無料の素材に取り替えるか、削除する
  3. プレビューで透かしが消えたことを確かめてから書き出す

プレミアム素材をどうしても使いたい場合や、4Kで書き出したい場合は、Premium プランにします。Premium の料金は国や支払い方法で変わるため、申し込む前に Adobe Express の料金ページで今の価格を確認してください。

iMovie と Shotcut:無料で使えるシンプルなソフト

Apple は iMovie を「無料」と案内していて、4Kの動画も扱えます。必要なのは iOS・iPadOS 16.0以降、Mac なら macOS 11.5.1以降・メモリ4GB・空き容量3.5GBです(Apple 公式)。Shotcut は Windows・Mac・Linux で使える無料のオープンソースソフトです(Shotcut 公式)。どちらも有料版がないので、透かしを気にせず練習できます。

透かしを消す正しい方法はどれですか?

正しい方法は「有料版を買う」「有料の素材・機能を外す」「最初から透かしのないソフトを使う」の3つです。透かし除去ツールや画面録画で消す方法はおすすめしません。

方法1:有料版・有料プランにする

Filmora や Premiere Elements のように無料版・体験版では透かしが入るソフトは、有料版にするのがいちばん確実です。Filmora の公式ページでも、有料版を買うのがほかの方法より良いと案内されています(Filmora 公式:ロゴを消す方法)。Premiere Elements は、製品を買ったあと、プロジェクトのレンダリングファイルを消してから書き出し直す手順が公式ヘルプで案内されています(Adobe ヘルプ)。買う前に無料版で操作をひととおり試し、自分に合うか確かめましょう。

方法2:有料の素材・機能をプロジェクトから外す

CapCut・Clipchamp・Adobe Express・DaVinci Resolve は、有料の素材や機能を外せば、無料のまま書き出せる場合があります(CapCut の PC版は、「透かしなし」の項目が Pro 限定なので注意してください)。

  1. 有料のマーク(王冠・ダイヤ・「Pro」など。ソフトによって違います)が付いた素材を探す
  2. フォント・BGM・エフェクト・トランジションを、マークのない無料のものに取り替える
  3. 解像度とフレームレートを無料版の範囲に戻す(例:Clipchamp は1080pまで。CapCut は4K・60fpsを使わない)

方法3:CapCut のエンディング動画を消す

CapCut では、タイムラインの最後にあるロゴ入りのエンディング動画を消す方法が公式に案内されています(CapCut ヘルプ)。消しても透かしが残るときは、CapCut のサポートに問い合わせるよう案内されています。

避けたい方法:透かし除去ツールや画面録画

Filmora の公式ページは、プレビューを画面録画して書き出す方法は利用規約に違反するおそれがあり、最悪の場合ソフトが使えなくなると注意しています(Filmora 公式:ロゴを消す方法)。除去ツールを使っても、ロゴの大きさや場所によってはきれいに消えません。出どころの分からない「透かしを消せる」ソフトには、ウイルスなどの危険もあります。

初心者はどのソフトを選べばいいですか?

初心者は、まず「透かしなしで書き出せるか」と「自分のパソコンやスマホで動くか」を確かめてから選ぶと失敗しにくくなります。向いている人・向いていない人をまとめました。

DaVinci Resolve

  • 向いている人:無料で本格的な編集や色の調整を学びたい人
  • 向いていない人:とにかく早く1本仕上げたい人、性能が低めのパソコンを使っている人
  • 注意点:機能が多いので、最初は画面の多さに戸惑いやすいです。Studio だけの機能を使うと透かしが入るというユーザーの報告もあります(Blackmagic Forum)

Clipchamp

  • 向いている人:Windows で手軽に始めたい人、学校や仕事の短い動画を作りたい人
  • 向いていない人:無料で4Kで書き出したい人(無料版は1080pまで)
  • 注意点:プレミアム素材を使うと、アップグレードするまで書き出せません(Microsoft サポート)

CapCut

  • 向いている人:スマホでショート動画を作りたい人、テンプレートで手早く仕上げたい人
  • 向いていない人:有料素材を避けるのが面倒な人、PC版を無料のまま透かしなしで使いたい人
  • 注意点:Pro 素材や4K・60fpsを使ったまま書き出すと、加入を求められます(CapCut ヘルプ)

Adobe Premiere(モバイル版)・Premiere Pro

  • 向いている人:モバイル版は、スマホで透かしなしの動画を無料で作りたい人。Premiere Pro は、仕事や学校で Adobe 製品を使う人
  • 向いていない人:Premiere Pro は、月額の費用をかけたくない人
  • 注意点:モバイル版でお金がかかるのは生成AIのクレジットなどです(Adobe 公式)。Premiere Pro の無料体験は7日間なので、続けないなら期限までに解約しましょう(Adobe 公式)

Filmora・PowerDirector

  • 向いている人:日本語の案内が多い有料ソフトで、迷わず編集したい人
  • 向いていない人:お金をかけずに、完成した動画を公開したい人
  • 注意点:Filmora の無料版では透かしが入ります。PowerDirector の無料版も、透かしなしで書き出せるとは公式に書かれていないので、有料版を前提にしましょう。年間プランや365は自動で更新されるので、解約する時期も決めておきましょう(Filmora 公式ストア)

iMovie・Shotcut

  • 向いている人:iMovie は iPhone や Mac を持っている人、Shotcut は Windows や Linux で無料のまま使いたい人
  • 向いていない人:iMovie は Windows の人(使えません)、Shotcut は凝ったテンプレートを使いたい人
  • 注意点:iMovie には iOS 16.0以降・macOS 11.5.1以降が必要です(Apple 公式)。古い端末では使えないことがあります

書き出す前に何を確認すればいいですか?

書き出す前に、「有料の素材や機能を使っていないか」「エンディングやロゴが入っていないか」「解像度の設定が無料版の範囲か」の3つを確認しましょう。次のチェックリストを使うと見落としが減ります。

書き出し前チェックリスト

  1. タイムラインの最後に、ソフトのロゴやエンディング動画が入っていないか(CapCut など)
  2. 王冠マークや「Pro」マークなど、有料を示すマークの付いた素材を使っていないか(CapCut・Clipchamp・Adobe Express など)
  3. 解像度とフレームレートが無料版の範囲か(Clipchamp の無料版は1080pまで、DaVinci Resolve の無料版は Ultra HD・60fpsまで)(Clipchamp 料金ページ、Blackmagic Design 公式)
  4. 書き出しの設定画面で、「透かしなし」の項目に鍵マークが付いていないか
  5. 書き出した動画を最初から最後まで再生して、透かしが入っていないか

よくある質問

無料で透かしなしの動画編集ソフトはありますか?

あります。DaVinci Resolve・Clipchamp・iMovie・Shotcut・Adobe Premiere のモバイル版は、無料の範囲で編集すれば透かしなしで書き出せるか、公式に無料・透かしなしと案内されています(Blackmagic Design 公式、Microsoft サポート、Apple 公式、Shotcut 公式、Adobe 公式)。ただし、有料の素材や機能を使うと制限がかかるソフトもあります。

Adobe の動画編集ソフトは無料だと透かしが入りますか?

製品によって違います。モバイル版 Premiere は公式に「透かしなし」と案内されています。Adobe Express の無料プランは、プレミアムコンテンツを使ったときだけ透かしが入ります。Premiere Elements の体験版は透かしが入り、製品を買うと消せます(Adobe 公式、Adobe Express 比較表、Adobe ヘルプ)。Premiere Pro の体験版の透かしについては、公式ページに書かれていません。

Filmora の無料版で透かしを消す方法はありますか?

公式ページでは、有料版を買うのがいちばん確実な方法と案内されています。画面録画で消す方法は、利用規約に違反するおそれがあると注意されています(Filmora 公式)。新しく登録した人には、透かしなしで書き出せる特典がある場合があります(Filmora 公式)。

CapCut の最後に出るロゴは消せますか?

消せます。公式ヘルプでは、タイムラインの最後にあるロゴ入りのエンディング動画を消す方法が案内されています(CapCut ヘルプ)。ただし、Pro 素材を使った動画や、PC版の「透かしなし」の書き出しには Pro が必要です(CapCut ヘルプ)。

Clipchamp で書き出せないのはなぜですか?

プランに含まれないプレミアム素材や機能を使っている可能性があります。Clipchamp は透かしを付けないかわりに、アップグレードするまで書き出しを止める仕組みです(Microsoft サポート)。プレミアム素材を外し、解像度を1080p以下にすれば、無料のまま書き出せます。
