#補助金 #個人事業主

補助金を受けた個人事業主は、事業に関係する補助金なら原則として確定申告で事業所得の収入に含めます。青色申告決算書では「雑収入」、白色の収支内訳書では「その他の収入」の欄に書くものです。国や地方公共団体の補助金などをパソコンや車といった固定資産の購入に充てた場合は、明細書を添付して収入に入れない特例(国税庁 No.2202)を選べます。

この記事は2026年11月時点で確認できた国税庁の情報をもとにしています。様式の説明は最新の公開分である令和7年分を参照しました。令和8年分の申告では、公開された新しい様式と書き方も確かめてください。

この記事の要点

  • 決算書は雑収入欄、収支内訳書はその他の収入欄に書く
  • 年分は入金日でなく収入すべき権利の確定で考える
  • 固定資産向けは明細書の添付で収入に入れない特例がある

個人事業主が受け取った補助金は確定申告が必要?収入になるもの・ならないもの

事業に関係する補助金は原則として収入になり、確定申告に含めます。

名古屋国税局の文書回答では、個人事業者が事業用の機械装置の購入に受けた補助金を、一時所得ではなく事業所得の総収入金額に算入するとしています。2016年の個別事例ですが、「事業に付随する収入」という考え方を確かめられる公式の資料です。

一方で、国税庁は助成金や給付金について個別の事実関係によって課税関係が異なるとも案内しています。特別定額給付金のように非課税のものもあり、名前だけでは決められません。

補助金の性格所得税での扱い申告での動き
広告費・外注費など事業の経費の補助事業所得の収入雑収入またはその他の収入に記入
事業用の固定資産の購入に充てる補助事業所得の収入。特例で不算入も可記入するか、明細書を添付

収入に入れたからといって、税金が必ず発生するとは限りません。所得は収入から経費を引いた額で、所得控除の合計を超えて税額が出る人に確定申告の必要があります。期間は原則として翌年2月16日から3月15日までです。

会社員の副業なら、給与が1か所で年末調整を受けていて、給与・退職所得以外の所得が合計20万円以下のとき、所得税の確定申告は原則不要です。補助金の額そのものではなく、経費を引いた後の所得で比べます。

補助金は資産の譲渡等の対価に当たらず消費税の対象外とされますが、これは消費税だけの話です。所得税では別に判断します。

補助金はどの年分の収入になる?交付決定と入金の年がずれたとき

収入にする年は、入金日ではなく収入すべき権利が確定した年で考えます。

「その年において収入すべき金額は、年末までに現実に金銭等を受領していなくとも、「収入すべき権利の確定した金額」になります。」(国税庁 No.2200)

では、補助金の「権利の確定」はどの日か。国税庁の情報を確認した範囲では、すべての補助金に共通する日付の基準は見つかりませんでした。公式の例として、厚生労働省の発熱外来補助金のQ&Aは交付決定がされた日の属する年分の収入としています。ただ、これは特定の制度の案内です。実績報告の後に金額が決まる精算払いの補助金へ、そのまま当てはめられるとは言えません。

次の順に確かめます。

  1. 交付決定通知書、額の確定通知書、入金が分かる通帳を手元に並べます。
  2. 3つの日付を書き出します。入金の流れは小規模事業者持続化補助金の支払い方法や補助金申請の流れで確認できます。
  3. 交付要綱や公募要領で、実績報告の後に金額が変わる仕組みかを確かめます。
  4. 3つの日付がすべて同じ年なら、その年分で計上します。
  5. 年をまたぐなら、通知書を持って所轄の税務署に年分を確認します。確認した日と回答の内容はメモしておきましょう。

補助金は収支内訳書・青色申告決算書のどこに書く?

青色申告決算書は「雑収入」、収支内訳書は「その他の収入」の欄に書きます。

収支内訳書の説明書には次の一文があります。

「国や地方公共団体などから支給された助成金等で事業所得や業務に係る雑所得として課税の対象となるものがある場合には、当該助成金等の金額も含めて、この欄に記入します。」(令和7年分 収支内訳書(一般用)の書き方)

国税庁の作成コーナーも、雑収入の説明で課税対象の助成金等を雑収入に含めるよう案内しています。

記入の順番は次のとおりです。

  1. 帳簿で、その年分に入れる補助金の合計を出します。
  2. 青色なら決算書2ページの「雑収入」、白色なら「その他の収入」に金額を入れます。
  3. 青色は「売上(収入)金額」の計が損益計算書の①に転記されているかを見ます。
  4. 固定資産を買ったなら、減価償却の欄も入力します。国税庁の確定申告書等作成コーナーでは「経費の合計」から減価償却費の入力に進みます。
  5. 不算入の特例を使う補助金は、雑収入に入れず、明細書を添付します。

特例を使う補助金を雑収入に入れたまま明細書も出すと、収入と取得価額の調整が食い違います。提出前に、補助金1件ごとに「雑収入に入れた」「明細書に書いた」のどちらか一方だけになっているかを見直しましょう。

事業用のEV補助金は原則として事業所得の収入です。国庫補助金等に当たるなら不算入の特例も選べますが、CEV補助金が当たるかどうかは国税庁の資料で確認できていません。

全期間の合計はほぼ同じで、特例は税金をなくす制度ではなく、課税のタイミングをならす制度です。向いているのは、その年の所得が大きく、補助金で税金が増えるのを避けたい人。赤字に近い年なら、収入にしても税金が増えにくいため、将来の償却費が多く残る収入方式のほうが合う場合もあります。

手順は次のとおりです。

  1. 車検証で車の区分を確かめ、耐用年数表を見ます。
  2. 補助金の交付元と根拠を、交付決定の書類で確認します。
  3. 事業に使う割合を、走行記録などで説明できるようにします。
  4. 上の未確認の3点のうち、自分に関係するものを税務署に確認します。
  5. 特例の対象なら、収入にするか特例を使うかをその年の所得の見込みで決めます。
  6. 特例を使うなら、明細書を添付して申告します。

CEV補助金には処分を制限する期間があり、令和6年度補正の応募要領では4年または3年とされています。令和7年度補正の応募要領でも財産処分の手続きが案内されているので、自分の年度の期間を確かめましょう。期間内の売却では補助金の返納が必要になることがあります。

圧縮記帳(国庫補助金等の総収入金額不算入)の条件と手順

個人事業主が使うのは圧縮記帳ではなく、総収入金額不算入の特例です。

国税庁の案内で使われる名前は「国庫補助金等の総収入金額不算入」です。使える条件はNo.2202と明細書の書き方から次のように整理できます。

圧縮記帳(国庫補助金等の総収入金額不算入)の条件と手順。出典: jGrants(デジタル庁)
条件確認すること
国または地方公共団体の補助金や給付金などであること交付決定通知書の交付元と補助金名
固定資産の取得や改良に充てるものであること補助対象の経費の内訳
交付の目的に合った資産を取得・改良したこと実績報告の内容と請求書
確定申告書に一定の事項を記載すること明細書の添付

経費と固定資産が混ざった補助金は、固定資産に充てた部分だけが対象です。たとえば補助金50万円でチラシとホームページの両方を作ったケースが該当します。通知書に内訳がないときの分け方は国税庁の資料で確認できず、経費の比率で分ける計算を示す税理士の相談回答があるにとどまります。これは非公式の個別回答なので、まず交付元に内訳を確認し、それでも分からなければ税務署に確かめてください。ホームページの費用の扱いは、持続化補助金のホームページの上限と対象外の記事も参考にしてください。

申告までの流れです。

  1. 国税庁の明細書の様式と書き方を開きます。
  2. 補助金の名称と金額、資産の取得価額を、通知書と請求書から写します。
  3. 年末までに返還不要が確定したかを確認します。確定していないと「確定しない場合」の欄以下の記入が必要です。
  4. 取得価額から不算入額を引いた残額を、減価償却の計算に使います。
  5. 明細書を確定申告書に添付して、所轄の税務署長へ提出します。

取得費は実際の金額から不算入額を引いた残額で、減価償却費もその額を基礎に計算します。翌年以降も同じ額を引き継ぐので、資産の台帳に補助金名を書き残しておくと年をまたいでも追えます。

補助金で買ったパソコンは経費にできる?少額資産と減価償却の違い

パソコンの処理は、取得価額が10万円未満かどうかで最初に分かれます。

たとえば50万円のパソコンを2026年7月に使い始めると、定額法の年の途中の月割りで、2026年の償却費は50万円×0.250×6/12で6.25万円です。個人は届出をしなければ定額法で計算します。

補助金を収入にする場合は取得価額を減らさないので、購入額で区分を判定します。たとえば青色申告者が30万円のパソコンに20万円の補助を受け、要件を満たして少額の特例を使うなら、雑収入20万円と経費30万円で所得は10万円の減少です。

不算入の特例を使う場合に、少額資産の区分を減額前と減額後のどちらの金額で判定するかは、国税庁の明文を確認できませんでした。この記事では判定の結論を示しません。特例の併用を考えているなら、取得価額と補助金額を示して、申告前に所轄の税務署で確認してください。

補助金を受けた年の経費と収入の整理|採択されても支給が翌年のとき

購入と入金が別の年でも、経費は購入や使用の年に、収入は確定の年に分けて考えます。

採択された時点では、まだ収入にしません。補助金は後払いが多いため、経費や減価償却が先の年、補助金の収入が後の年に来るのは珍しくないことです。たとえば2026年に広告費60万円を払い、2027年に補助金40万円が確定した場合、2026年は赤字が膨らみ、2027年は所得が増える形になります。

固定資産を特例で処理減価償却費を計上算式で出した額を不算入にし、残りを収入

固定資産の特例には、この場面のための計算があります。明細書の書き方には、補助金で取得した資産が前年以前に取得した減価償却資産である場合の算式があり、返還不要が確定した日までの償却累計額を使います。おおまかな形は次のとおりです。

補助金の額 ×(取得価額 − 償却累計額)÷ 取得価額

たとえば取得価額100万円、確定までの償却累計額20万円、補助金50万円なら、不算入額は50万円×80万円÷100万円で40万円です。残りの10万円は収入に入れます。すでに経費にした部分に対応する補助金は収入に戻す、という見方です。式の細部は申告の年の書き方で確かめてください。

前の年に少額の特例で全額を経費にしていると、償却累計額が取得価額と同じなので、算式の答えは0円になります。翌年に補助金が確定すると分かっているなら、購入した年の処理を決める前に計算しておきましょう。

また、固定資産を取得した後で補助金を受ける個人事業者の取扱いについては、東京国税局の文書回答が公表されています。ただし個別の事例への回答なので、そのまま当てはまるとは限りません。

よくある質問

エコカー補助金は個人事業主の経費になりますか?

補助金そのものは経費ではなく、原則として収入です。不算入の特例の対象なら、取得価額から引く金額として扱うこともできます。経費になるのは車の減価償却費で、事業に使う分に限られます。特例を使うと償却の基礎が補助金の分だけ小さくなるため、毎年の経費も減ります。

EV補助金で買った車を事業と私用で使うとき、補助金はどう分けますか?

確認できたのは、減価償却費のうち業務に必要な部分を明らかに区分できる金額だけが経費になるという点までです。補助金を事業分と私用分にどう分けるかを示した国税庁の説明は確認できませんでした。分ける必要の有無と計算方法は、走行記録などをそろえて税務署で確認してください。

補助金で買ったパソコンは減価償却が必要ですか?

取得価額が10万円未満なら不要で、全額をその年の経費にできます。10万円以上なら原則は減価償却ですが、20万円未満の一括償却や、要件を満たす青色申告者の40万円未満の特例を選べる場合もあります。

補助金を受け取った年に赤字でも申告は必要ですか?

所得控除の後に税額が出ないなら、確定申告が必須ではない場合があります。ただ、赤字を翌年以後に繰り越したい青色申告者などは、提出したほうがよい場面です。迷うときは税務署に確認してください。

青色申告特別控除の金額に補助金は影響しますか?

控除額の65万円、55万円、10万円の区分は、記帳の方法や提出の方法などの要件で決まります。補助金を受けたこと自体は要件に挙げられていません。ただし雑収入の計上漏れがあると帳簿の正確さに関わるので、仕訳は必ず残しましょう。
