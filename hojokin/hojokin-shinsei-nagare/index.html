補助金申請の流れ|相談から入金まで6段階と対象別5つの手順表

#補助金 #持続化補助金 #IT導入補助金 #個人事業主

補助金申請の流れは、「①情報収集・相談 → ②申請準備 → ③申請 → ④審査・採択(交付決定) → ⑤事業実施・実績報告 → ⑥補助金の受取」の6段階です。補助金は原則として後払いです。先に自分のお金で払い、報告と検査が終わってからお金が振り込まれます。もう1つ大事なのが、制度ごとに「申請するのは自分か業者か」「契約や着工の前に申請するのか後なのか」が違うこと。ここを先に確かめると失敗が減ります。

この記事の要点

  • 補助金はほぼ後払いで、入金は実績報告と検査が終わってから
  • 交付決定の前に契約・着工すると対象外になる制度がある
  • 窓・給湯器・蓄電池は登録された業者が申請する

向いている人: 補助金を初めて使う個人事業主・小さな会社の経営者

補助金申請の流れは全体で何段階あるのか

多くの補助金は6段階で進みます。細かい所は対象によって違いますが、骨組みは同じです。中小企業庁の「ミラサポplus」も、探す・計画書を作る・審査と交付・事業実施・交付という順で説明しています。

「原則、補助金は後払い（精算払い）なので、事業の実施後に必要書類を提出して検査を受けた後、受け取ることができます」(ミラサポplus 補助金とは)

6段階を1つの表にしました。「あなたがやること」の欄は、自分で申請するタイプ(持続化補助金など)を前提にしています。

公式の流れの細かさは制度ごとに違います。小規模事業者持続化補助金の公式サイトでは、「GビズIDプライム取得」から「補助金交付」まで10の項目が並んでいます(持続化補助金とは・2026-10-25に数えた)。6段階の表と比べると、②に「事業支援計画書の申請」、④に「見積書提出」、⑥に「補助金額確定」と「補助金請求」が入ります。

6段階の前と後にもやることがある

表の外側にも手続きがあります。①より前に必要なのが、GビズIDのような電子申請用のアカウントです。⑥のあとも終わりではありません。デジタル化・AI導入補助金には、何年かにわたって出す「事業実施効果報告」があります(デジタル化・AI導入補助金 公式サイト)。EVのCEV補助金には「原則として４年または３年の保有」の決まりがあります(CEV補助金のご案内)。ミラサポplusによると、書類は補助事業が終わってからも5年間保管します。

申請額がそのままもらえるとは限らない

もらえる額が決まるのは⑥の「額の確定」です。採択の時点では決まりません。たとえば、50万円で申請したのに、実際に払った対象の経費が見積もりより安かったとします。この場合は、実際に払った額をもとに計算し直されます。領収書がない経費や、交付決定の前に払った経費は外されます。

補助金の相談はどこにすればいいのか

事業の補助金なら、商工会・商工会議所とよろず支援拠点に相談します。家庭向けの設備なら、各事業の事務局(コールセンター)と市町村の窓口です。相談先は「どの補助金か」で決まります。

「経営上のあらゆるご相談に何度でも無料で対応します」(よろず支援拠点全国本部)

持続化補助金では、商工会・商工会議所に「事業支援計画書(様式4)」を出してもらう必要があります。申請する人が自分で作る書類ではありません。第20回は、様式4の発行受付が2026年12月4日(金)に締め切られます。申請そのものの締切12月15日(火)17:00より11日早い日です(持続化補助金とは・2026年10月時点)。12月に入ってから相談に行くと間に合わないかもしれません。11月の早いうちに予約しておくと安心です。

「事務局の者です」という電話に気をつける

事務局を名のる勧誘があります。持続化補助金の公式サイトは2026年8月28日に、事務局の関係者を名のる不正な働きかけが起きたと注意を出しました(持続化補助金 公式サイト)。公式の事務局から、頼んでもいないのに制度を勧める連絡が来ることはありません。迷ったら、公式サイトにある電話番号に自分からかけて確かめてください。

どの補助金があるか分からないとき

先に地域と締切で候補をしぼってから相談すると、話が早く進みます。探し方の3つの手順は補助金・助成金の探し方|地域と締切で探す3手順にまとめました。

事業者向けの補助金は、申請準備で何をそろえるのか

最初に取るのはGビズIDプライムです。次に見積書、そして事業計画書をそろえます。持続化補助金も、デジタル化・AI導入補助金も、電子申請にGビズIDプライムを使います。

GビズIDプライムの手順は次のとおりです。

  1. GビズIDのサイトで、プライムの申請方法を選ぶ。マイナンバーカードを使うオンライン申請か、書類を郵送する申請かのどちらかです。
  2. オンライン申請なら、スマートフォンでマイナンバーカードを読み取る。
  3. 登録したメールアドレスに届く案内に沿って、パスワードを決める。

公式ページによると、マイナンバーカードを使えば最短で即日に発行されます。書類を郵送する申請は「申請から審査、アカウント発行まで最大1か月の時間がかかります」と書かれています(GビズID・2026年10月時点)。マイナンバーカードを持っていない人は、締切の1か月以上前に郵送で申し込むのが安全です。

見積書と事業計画書のつまずき

よくあるのは次の2つです。

  • 見積書の日付・品名・金額が計画書の経費の表と合っていない。直し方は、書き上げたあとに見積書と計画書を並べ、1行ずつ照らし合わせることです。
  • 補助の対象にならない経費を入れている。たとえば、持続化補助金のウェブサイト関連費は「補助金総額の1/4(最大50万円)」までという上限があります(第19回FAQ)。公募要領の「補助対象経費」の章を見て、経費の区分ごとに確かめてください。

個人事業主がデジタル化・AI導入補助金を使う場合、そろえる書類が法人と違います。くわしくはIT導入補助金 個人事業主の申請条件|書類4種と申請手順を見てください。

ev補助金の申請の流れはどうなっているか

国のCEV補助金は、車を買って登録(軽自動車は届出)したあとに申請します。順番は「契約 → 登録・代金の支払い → 申請 → 審査 → 交付」。期限は原則として登録日から1か月以内です。事前に申請して交付決定を待つ設備の補助金とは、順番が逆になります。

  1. 次世代自動車振興センターの補助対象車両一覧で、買いたい車と補助額を確かめる。
  2. 販売店と契約し、登録(届出)と代金の支払いを済ませる。
  3. 様式集から書類をダウンロードし、車検証などの写しを用意する。
  4. 「CEV補助金Web申請」からログインし、申請情報を入力して書類をアップロードする。
  5. 申請ボタンを押す。画面に「WEB申請済」と出たら完了です(Web申請について)。
  6. 審査が終わると交付が決まり、補助金が振り込まれる。

公式のWeb申請の案内には「審査期間は3～4ヶ月程度」とあります。申請日は「オンライン申請ボタン押下時点」です。受付の締めは17:15と書かれています(Web申請について・2026年10月時点)。ネットで申請できない人は郵送でも出せます。

いま気をつけたいこと

令和7年度補正のCEV補助金は、予算の残りによって受付が早めに終わる可能性があります。次世代自動車振興センターは受付終了の見込み時期をお知らせとして出しているので、契約の前に読んでおいてください(CEV補助金のご案内)。2026年10月時点では、12月上旬から下旬に終わる見込みと伝えられています。12月に登録する予定の人は特に注意が必要です。

国と自治体の補助金を両方使うとき

自治体の補助金は国とは別の制度です。窓口も期限も対象の条件も違います。国の補助金を受けることを条件にしている自治体もあるので、国→自治体の順で申請するのが一般的です。ただし決まりは自治体ごとに違います。住んでいる都道府県と市区町村の公式ページで「申請期限」と「国の補助金との関係」の2点を確かめてください。

エコキュートの補助金申請の流れはどうなっているか

国の給湯省エネ2026事業は、工事が終わったあとに、登録された業者が申請します。依頼する人は、申請の手続きをしません。

「補助対象者である一般消費者が直接申請をすることはできません」(給湯省エネ2026事業)

  1. 給湯省エネ事業者として登録されている業者を探し、補助の対象になる機種を選ぶ。
  2. 工事請負契約を結ぶ。工事の契約より前に着工すると、補助の対象になりません。
  3. 工事をして、引渡しを受ける。
  4. 業者が事務局に交付申請をする。
  5. 審査を通ると交付が決まり、業者を通して補助金が戻ってくる。

補助額は、エコキュートが基本額「7万円／台」です。性能の条件を満たすと「3万円／台」が加わります。対象は戸建住宅なら2台まで、共同住宅などは1台までです(対象要件の詳細・2026年10月時点)。対象になる工事は2025年11月28日以降に着手したもので、期限は予算の上限に達するまで(遅くとも2026年12月31日)。公式トップには、2026年10月24日時点の予算の使われ具合が「53％」と出ていました(給湯省エネ2026事業)。

つまずきやすい所

自分で買った機器を取り付けてもらうだけの「施主支給」は対象外です。もう1つ見落としやすいのが、個人の場合にJ-クレジット制度への参加の表明が求められること(対象要件の詳細)。業者から書類への署名を頼まれたら、内容を確かめてから署名しましょう。

自治体の上乗せ補助金はまた別の手続きです。着工前の申請を求める自治体もあります。国は工事が終わってからの申請で、自治体は工事の前の申請。こうした組み合わせもあるので、契約の前に市区町村のページを見てください。

蓄電池の補助金申請の流れはどうなっているか

国のDR家庭用蓄電池事業は、交付決定のあとで発注・設置する流れでした。ただし令和7年度補正分はすでに受付が終わっています。2026年10月にこれから蓄電池を入れるなら、相談先は自治体の補助金が中心になります。

「2026年5月29日（金）に交付申請額の合計額が予算に達したことを確認したため、公募は終了しました。」(DR家庭用蓄電池事業 申請の詳細手続き)

公式の手続きページに載っている流れは10段でした(DR家庭用蓄電池事業・2026-10-25に数えた)。

  1. 本人確認情報の登録
  2. 見積取得・販売事業者選定
  3. 補助事業の理解
  4. 共同実施事業規約への同意
  5. 交付申請
  6. 審査・交付決定
  7. 発注
  8. 設置
  9. 検収・支払い
  10. 実績報告

申請ポータルのアカウントは、登録された販売事業者に発行されます。そのため、依頼する人が1人で申請することはできません。次の年度に同じような事業が出た場合も、「交付決定を確かめてから発注」という順番は守ってください。

内窓の補助金申請の流れはどうなっているか

先進的窓リノベ2026事業も、登録された「窓リノベ事業者」が申請と補助金の受け渡しをします。依頼する人は申請できません。代わりに、契約と規約への同意、それから工事前の写真撮影に協力します。

公式の申請手続きページに載っている手順は12段です(申請手続きの詳細(住宅)・2026-10-25に数えた)。そのうち依頼する人がかかわるのは、次の所です。

  1. 工事請負契約を結ぶ(業者と依頼する人)
  2. 共同事業実施規約を結ぶ(業者と依頼する人)。ここで、補助金を契約代金にあてるか、現金で受け取るかを決めます。
  3. 工事着手(2025年11月28日以降)
  4. 交付申請の予約(任意・業者がする)
  5. 工事完了・引渡し
  6. 補助金交付申請(業者がする)
  7. 交付決定 → 実績報告・補助金の振込(事務局から業者へ)
  8. 補助金の還元(業者から依頼する人へ)

補助額の上限は、住宅で1戸あたり100万円です。延床面積240㎡以下の非住宅(店舗など)は1棟あたり100万円、240㎡を超える非住宅は1棟あたり1,000万円(事業概要・2026年10月時点)。期限は、交付申請の予約が遅くとも2026年11月16日、交付申請が遅くとも2026年12月31日です。どちらも、予算の上限に達したらその時点で終わります。予約の有効期間は提出から3か月か12月31日の早いほう、と公式のお知らせにあります。

工事前の写真がないと出ない

公式ページは、工事前の写真がないと補助金が出ないとしています。写真の提出を免除してもらう書類も使えません。たとえば、急ぎで内窓を付けてもらい、そのあとで補助金を思い出した場合、元の窓の写真が残っていなければ申請できません。契約するときに「工事前の写真はいつ撮りますか」と業者に聞いておくと防げます。

浄化槽の補助金申請の流れはどうなっているか

浄化槽の補助金は市町村が窓口です。多くの所で「着工の前に申請し、交付決定を受けてから工事」という順番になります。国(環境省)が市町村の事業を交付金で支えている仕組みなので、申請書も期限も市町村ごとに違います。

例として、大阪府柏原市の個人設置型の流れは7段階です(柏原市 浄化槽設置整備事業の補助金制度・2026-10-25確認)。

  1. 交付申請書の提出
  2. 交付決定通知
  3. 着工届の提出 → 工事
  4. 浄化槽の検査
  5. 実績報告書の提出
  6. 交付額確定通知
  7. 補助金交付請求書の提出

「交付決定通知より前に工事に着手した場合は対象外となります。」(柏原市)

柏原市では、交付決定から60日以内に着工しないと決定が取り消されます。期限はほかにもあります。工事が終わってから7日以内に完了届、検査に合格してから30日以内に実績報告書です。上限額は5人槽332,000円、6〜7人槽414,000円、8〜10人槽548,000円です(同ページ)。これは柏原市の数字です。ほかの市町村では金額も期限も違います。

自分の市町村の調べ方

「市町村名 浄化槽 補助金」で検索し、役所のドメイン(lg.jpなど)のページを開きます。確かめるのは次の4点です。

  • 申請の受付期間(年度の最初に受付が始まり、予算に達したら終わる所が多い)
  • 着工前の申請が必要か
  • 指定の工事業者がいるか
  • 単独処理浄化槽やくみ取り便槽から替えるとき、撤去費や配管費に加算があるか

下水道を整備する予定の区域は、補助の対象外になることがあります。区域に入っているかどうかは窓口で聞いてください。

採択と交付決定は別もの

持続化補助金では、採択されたあとに見積書を出し、それから交付決定を受けます。採択の通知を見てすぐに発注すると、その経費は補助の対象になりません。直し方は1つだけ。交付決定通知書の日付を確かめ、その日より後の日付で発注・契約することです。第19回の結果の見方と、不採択だったときの動き方は小規模事業者持続化補助金19回採択結果|確認6手順と不採択後の対応にまとめています。

補助金が実際に支払われるのはいつで、何が必要か

補助金が振り込まれるのは、事業が終わって実績報告を出し、検査を受けて額が決まり、請求をしたあとです。採択から入金までには半年以上かかることもあります。その間の支払いは自分のお金でまかないます。

持続化補助金の場合は次の順番です(持続化補助金とは)。

  1. 交付決定のあとに、計画どおり発注して支払う(銀行振込などで記録を残す)
  2. 事業が終わったら「実績報告書提出」
  3. 事務局の確認を受けて「補助金額確定」
  4. 確定した額で「補助金請求」
  5. 指定の口座に「補助金交付」

第20回の補助事業の期間は、交付決定日から2028年3月31日(金)までです(2026年10月時点)。公式サイトにも、補助事業を進めるときは自己負担が必要で、事業が終わってから精算払いになると書かれています。

立替えの資金をどう用意するか

たとえば、補助率2/3で75万円のホームページ制作をする場合を考えます。まず75万円を全額自分で払います。50万円が戻るのは、検査と請求が終わってからです。手元の資金が足りない人は、申請する前に金融機関に相談しておきましょう。入金までの手順と立替えの目安は小規模事業者持続化補助金の支払い方法|入金までの5手順と立替の目安でくわしく書いています。

入金のあとも続く報告

デジタル化・AI導入補助金には、補助金を受け取ったあとに出す「事業実施効果報告」があります。出さないと返還を求められることがあります。期限と書類はIT導入補助金 効果報告の期限と書類|年度別スケジュール表つきを見てください。

よくある質問

電気自動車の補助金はいつ申請すればいいのか

国のCEV補助金は、車を登録(軽自動車は届出)したあとに申請します。期限は原則として登録日から1か月以内です。令和7年度補正分は2026年12月上旬〜下旬に受付が終わる見込みなので、年末に納車される人は早めに販売店と日程を確かめてください。自治体の補助金は期限が別なので、それぞれの公式ページで確認が必要です。

蓄電池の補助金とエコキュートの補助金は併用できるのか

対象の機器が違うので、別々の制度に申請すること自体はできます。ただ、同じ機器に国の補助金を2つ重ねることは、多くの公募要領で認められていません。また、国のDR家庭用蓄電池事業は2026年5月29日に受付を終えています。いまは自治体の蓄電池補助金と、国の給湯省エネ事業の組み合わせを、それぞれの要綱で確かめることになります。

内窓の補助金申請は業者がやってくれるのか

はい。先進的窓リノベ2026事業では、登録された窓リノベ事業者が申請し、補助金も業者から受け取ります。依頼する人が自分で申請することはできません。自分の役目は、工事請負契約と共同事業実施規約を結ぶことと、工事前の写真撮影への協力です。

浄化槽の補助金はどの自治体でも同じ手続きなのか

同じではありません。窓口は市町村で、金額や期限、指定の業者がいるかどうかが違います。それでも、着工の前に申請して交付決定を待つ順番はよく見られます。柏原市の場合は、交付決定から60日以内の着工と、検査に合格してから30日以内の実績報告が決まっています。

採択されたらすぐに発注していいのか

持続化補助金などでは、採択のあとに交付決定があります。交付決定通知書を受け取る前に発注・契約・支払いをした経費は、補助の対象になりません。通知書の日付を確かめてから発注してください。
