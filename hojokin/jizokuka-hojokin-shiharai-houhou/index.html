#小規模事業者持続化補助金 #個人事業主

小規模事業者持続化補助金は後払いです。経費をいったん全額自分で払い、事業が終わったら実績報告を出します。補助金額が確定したあと「精算払請求書」を出すと、自分名義の口座に振り込まれます。経費の払い方にも決まりがあり、1取引10万円超(税抜)の現金払いや、ポイント・商品券での支払いは補助の対象外です。

「補助金は『後払い』であることに注意してください」(ミラサポplus 中小企業庁担当者に聞く)

この記事の要点

  • 補助金は後払いで、経費はいったん全額を自分で立て替える
  • 1取引10万円超(税抜)の現金払いやポイント払いは対象外
  • 入金は実績報告と確定通知のあと、精算払請求を出してから

向いている人: 持続化補助金に申請する個人事業主・小さな会社の経営者

補助金はいつ、どうやって振り込まれる?

振り込まれるのは補助事業が終わったあとです。事業の途中で前払いされることはありません。

中小企業庁の解説では、採択後の流れを「見積書提出 → 交付決定 → 事業開始 → 実績報告書提出 → 補助金交付 → 事業効果報告書提出」と示しています(ミラサポplus)。商工会地区の事務局の採択者向けページでも、手続きは「見積書等提出 → 実績報告書提出 → 補助金請求 → 事業効果報告書提出」の4つのSTEPで載っています(採択者向け情報・2026-10-19に数えた)。お金が入るのは3つ目のSTEP、補助金請求のあと。

実績報告の締切には、もう1つ条件があります。補助事業が終わった日から30日を過ぎた日と、上の表の期限のうち「早いほう」が締切です(採択者向け情報)。たとえば第19回で2026年12月に事業を終えたなら、2027年7月まで待たずに約30日以内に出す必要があります。

請求から入金までの日数は、事務局の精算払い請求のページに書かれていません(2026-10-19に確認)。確定通知を待つ期間も含め、資金計画には余裕を持たせてください。

立て替えるお金はいくら必要?

必要なのは、補助対象経費の全額です。補助される分も含め、先に自分で払います。

一般型 通常枠の補助率は2/3、補助上限は基本50万円です。インボイス特例で50万円、賃金引上げ特例で150万円が上乗せされ、上限は最高250万円になります(ミラサポplus・2026年10月時点・最新は公式で確認)。創業型の補助上限は200万円です(同)。

経費は何で払えばいい?対象外になる払い方

いちばん確実なのは、自分名義の口座からの銀行振込です。現金・カード・ポイントには、補助の対象外になる条件があります。

日付の決まりも大事です。

「交付決定日より前に発注、購入、契約等を実施したものは補助対象外となります」(採択後手続き(商工会議所地区))

採択通知が届いただけでは、まだ発注できません。「交付決定通知書」に書かれた交付決定日を確認してから注文します。

つまずきやすい所と直し方

  • カードの締め日をまたいだ → 実施期限が近い時期の購入は、振込に切り替えるか、引き落としが期限内に収まる日に買う
  • 10万円を超える物を現金で買ってしまった → あとから振込扱いにはできません。次の取引から振込に統一する
  • 見積書を出す前に注文した → 交付決定前の発注は対象外。発注書・契約書の日付は交付決定日より後にする

入金までの5手順(採択後〜振込)

画面や書類の名前は、事務局のページの言葉に合わせています。申請や報告は電子申請システムのマイページで行い、GビズIDプライムかGビズIDメンバーのアカウントが必要です(応募する)。

  1. 交付決定を受ける:採択後、マイページで「採択通知書」を見て、見積書等を出します。事務局の確認が終わると「交付決定通知書」が届きます(採択後手続き)。発注はここから。
  2. 発注して、決まった方法で払う:上の表のルールで支払い、発注書・請求書・領収書・振込控えをそろえます。
  3. 実績報告書を出す:事業終了から30日以内、または回ごとの期限のどちらか早い日までに提出します(実績報告)。事務局は「実績報告用チェックリスト」や「立替払請求書兼領収書」などの様式を用意しています(同)。
  4. 「確定通知書」を受け取る:事務局が実績報告書を確認し、補助金の額を確定して通知します(精算払い請求)。
  5. 「精算払請求書」を出し、入金を確かめる:必要事項を入力し、振込先口座が分かる資料を付けて出します(同)。

手順5の口座資料は、差し戻しが起きやすい所です。精算払い請求のページによると、口座情報の①〜⑧がすべて読める資料が必要です(精算払い請求)。

  • 紙の通帳:表紙と、中面の見開き(1・2ページ目)の両方
  • 当座預金:当座勘定照合表か残高証明書
  • WEB通帳・ネットバンキング:公式サイトやアプリの画面のスクリーンショット

口座名義は、交付決定を受けた事業者本人の名義でなければいけません。カタカナの名義は、スペースも含めて資料のとおりに入力します(同)。個人事業主が家族名義の口座を書いてしまうと、受け付けてもらえません。

入金後も手続きは残ります。事業効果報告書は、事業実施期間が終わった翌月から1年間の報告期間が過ぎてから、30日以内に出します(採択者向け情報)。

手元のお金が足りないときは?

立て替える資金が足りなければ、申請する前に地元の商工会・商工会議所へ資金のことも相談してください。持続化補助金の申請には商工会・商工会議所が出す「事業支援計画書(様式4)」が必要なので、どのみち窓口に行くことになります。

公的な選択肢として、日本政策金融公庫のマル経融資(小規模事業者経営改善資金)があります。日本商工会議所の案内によると、内容は次のとおりです(マル経融資|日本商工会議所・2026年10月時点・最新は公式で確認)。

  • 対象:常時使用する従業員が20人以下(商業・サービス業は5人以下)の法人・個人事業主
  • 融資限度額:2,000万円
  • 返済期間:運転資金・設備資金とも10年以内(据置2年以内)
  • 担保・保証人:不要(保証協会の保証も不要)

向いているのは、商工会議所や商工会の経営指導をすでに受けていて、補助金が入るまでの数か月をつなぎたい人。逆に、開業したばかりの人や、窓口とまだ付き合いがない人には向かない場合があります。経営指導を受けていることが前提の制度で、事業を続けている期間などにも条件があるためです。借入なので、補助金が予定より少なく確定しても返済は減りません。この点がデメリットです。

よくある質問

持続化補助金を先にもらってから経費を払えますか?

できません。補助金は後払いで、交付決定のあとに自分で全額を払い、実績報告と確定通知を経てから振り込まれます。前払いを前提に計画すると、事業の途中で資金が尽きるおそれがあります。

クレジットカードで払った経費は対象になりますか?

条件つきで対象になります。口座からの引き落とし日が補助事業の実施期限を過ぎると対象外で、リボ払い・分割払いで期間中に完済していない分も対象外です(補助事業の進め方)。期限が近い時期は振込か一括払いにしておくと安全です。

振込先を家族の口座や別名義の口座にできますか?

できません。振込先は、交付決定を受けた補助事業者(会社か個人事業主本人)の名義でなければいけません(精算払い請求)。法人なら法人名義の口座を用意してください。

請求してから入金まで何日かかりますか?

事務局の精算払い請求のページには、日数が書かれていません(2026-10-19確認)。確定通知を待つ期間もあるので、数か月の余裕を見ておくと安心です。

補助金が申請した額より少なくなることはありますか?

あります。実績報告で、交付決定前の発注や1取引10万円超(税抜)の現金払いなど、対象外の経費が見つかるとその分は補助されません。確定するのは「確定通知書」の額です。
