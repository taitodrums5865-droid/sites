#入札参加資格 #全省庁統一資格 #自治体入札

入札参加資格の申請時期は、申請先の機関が「定期受付」と「随時受付」のどちらを開いているかで決まります。多くの自治体は2年に1度の定期受付で4月1日からの資格をまとめて審査します。その期間を過ぎても随時受付で申請できますが、資格が始まるのは審査が終わってからです。2026年10月時点では、国の全省庁統一資格(物品・役務)は随時審査を令和10年3月10日まで受け付けています。一方、東京都・神奈川県・横浜市・浜松市などは2026年秋から冬にかけて、令和9・10年度分の定期受付をしています。

この記事の要点

  • 国の物品・役務は令和10年3月10日まで随時審査を受付
  • 東京都・神奈川県などは2026年秋に定期受付
  • 締切を逃すと4月1日から資格の空白が出る

向いている人: 国や自治体の入札に参加したい個人事業主・中小企業

入札参加資格はいつ申請すればいい?

答えは「参加したい入札の公告が出る前に、資格が有効になっている時期」です。逆算すると、定期受付がある機関なら受付期間中に出し、それを逃したら随時受付に出す、の2択になります。

決め方は次の4段です。

  1. 参加したい機関を1つ書き出す(例: 〇〇県、△△市、国の□□省)
  2. その機関のサイトで「入札参加資格」「競争入札参加資格審査」と書かれたページを開く
  3. 「定期受付(定期申請・定期審査)」の期間が今後あるかを見る。あればその期間に出す
  4. 定期受付が終わっていれば「随時受付(随時申請・追加審査)」の期間と、資格が始まる日を確かめる

2026年10月21日時点で受付中・受付予定の主な定期受付

2026年の秋から冬は、令和9・10年度分(2027年4月から2年間)の定期受付が重なる時期にあたります。公式ページで確かめた日付を並べました(2026年10月時点・最新は各公式で確認)。

つまずきやすい所

いちばん多いのは「県の資格を取れば市の入札にも出られる」という思い込みです。資格は機関ごとに別々で、県と市はたいてい別の申請になります。かながわ電子入札共同システムや東京電子自治体共同運営のように、1回の申請で複数の自治体にまとめて出せる仕組みもあります。それでも「どの自治体を選んで申請したか」で資格の範囲が決まるので、申請画面で希望する自治体の選び漏れがないか確かめてください。

定期受付と随時受付の違いは?

定期受付は「資格が始まる日(多くは4月1日)に間に合わせるための一斉受付」です。随時受付は「その後の途中参加用の受付」にあたります。どちらで出しても資格が切れる日は同じなので、随時受付で後から取るほど使える期間は短くなります。

具体例で見てみます。神奈川県の共同システムでは、令和7・8年度の随時申請は令和7年4月1日から令和9年2月1日まで受け付け、資格は認定された日から令和9年3月31日までです。たとえば2026年12月に随時申請で認定されると、使えるのは約3か月だけ。そのうえ2027年4月からの資格は、別に定期申請(2026年10月1日〜11月30日)を出さないともらえません。

随時受付の形も機関ごとにばらつきがあります。浜松市の追加審査は「いつでも」ではありません。令和7・8年度は年4回、各回2週間ほどの申請期間でした(浜松市。公式ページに載っている回数を2026-10-21に数えた)。大阪府(物品・委託役務)は逆に毎週の締切で、火曜日までに電子申請と書類添付をすると、翌週月曜日に登録という流れです。

つまずきやすい所

「随時受付で取ったから、次の更新も勝手に続く」と考えるのは誤りです。随時で取った資格も、名簿の終わりの日にほかの人と一緒に切れます。次の名簿に載るには、次の定期受付で申請し直す必要があります。直し方は単純で、資格を取った日に「この名簿の終わりの日」と「次の定期受付が出そうな月」を手帳に書いておくことです。

全省庁統一資格の次回申請時期はいつ?

全省庁統一資格(物品の製造・販売、役務の提供など)は、今は随時審査の期間中です。2026年10月時点では、次の定期審査の日付は発表されていません。今の資格は3年間有効で、調達ポータルでは次のように案内されています(2026年10月時点)。

  • 令和7・8・9年度の定期審査: 令和7年1月31日で受付終了
  • 随時審査の受付: 令和7年2月1日〜令和10年3月10日
  • 随時審査の資格の有効期間: 審査後、資格を付与した時点から令和10年3月31日まで

出典は調達ポータル「各年度に有効な資格の審査申請について」。随時審査の混み具合について、同じページにこう書かれています。

「申請混雑の影響で資格の付与に時間がかかる場合もあり、希望する調達案件の入札に間に合わないことがあります」(調達ポータル)

次の名簿(令和10年4月から)の定期審査はいつか。前回の定期審査は令和7年1月末に締め切られました。同じ流れなら2027年度の冬ごろになりそうですが、これはこのサイトの見立てで、公式の発表ではありません。正式な日付は調達ポータルの告知で確かめてください。

今から申請するときの手順

  1. 調達ポータルを開き、「各年度に有効な資格の審査申請について」で、今受付中なのが随時審査であることを確かめる
  2. 申請方法を選ぶ。「インターネットによる申請」と「郵送・持参による申請」がある。調達ポータルは、なるべくインターネット申請を使うよう呼びかけている
  3. 郵送・持参なら、公式の申請書記入要項(令和7年11月版)を読みながら申請書を作る
  4. 添付書類をそろえる。令和7年1月6日から「納税証明書その2」の添付が必須になった(調達ポータル)
  5. 申請後は資格審査結果通知書を待つ。届いた日から入札に参加できる

つまずきやすいのは手順4の納税証明書です。「その1」と「その2」は中身が違い、取り違えると出し直しになります。税務署で請求するときに「その2」と指定してください。

もう1つ、防衛省大臣官房会計課管理班契約係はインターネット申請だけの受付です(調達ポータル)。郵送で準備を進めていた人は、提出先を確かめ直しましょう。等級の決まり方(点数表)は入札は個人事業主でもできる|等級の点数表と申請手順で説明しています。

国の工事・測量は時期が別

国土交通省の建設工事や測量・建設コンサルタント等は、全省庁統一資格とは別の資格です。受付の周期も違います。関東地方整備局の令和9・10年度分は、パスワード発行申請が2026年11月2日〜12月28日、申請書データの受付が12月1日〜2027年1月15日(関東地方整備局・2026年10月時点)。

「上記受付期間に申請いただけない場合は令和9年4月1日に競争参加資格が認定されません」(関東地方整備局)

パスワードを先に取っておかないと、インターネット一元受付で申請データを送れません。手順の最初の締切は12月28日のほうだと覚えておくと安全です。

自治体(都道府県・市区町村)の入札参加資格の申請時期はいつ?

自治体の申請時期は「何年ごとか」「何月に始まるか」の2点で分かれます。多くは2年ごとの4月始まりで、受付は前の年の秋から冬。ただ、3年ごとや10月始まり、さらに毎月締めの自治体もあります。

大分県の物品・役務は、年度の途中に切り替わる珍しい例です。定期更新は令和8年6月1日〜7月31日に終わり、有効期間は令和8年10月1日から令和10年9月30日まで。随時申請の資格は「申請受理月の翌々月」から始まります。たとえば2026年11月に受理されれば、2027年1月からです。

東京都内の区市町村は「決算月」で決まる

都内の区市町村の多くは、東京電子自治体共同運営という共同の仕組みで資格を受け付けています。52団体の参画で平成16年2月に設置された仕組みです(東京電子自治体共同運営サービスとは)。ここは「〇年度分の定期受付」という形をとりません。世田谷区の案内では、次のとおりです。

「毎月25日（25日が土曜日・日曜日・祝日等の閉庁日にあたる場合は、直前の開庁日）までに申請が承認された方は、翌月1日から資格が有効になります。」(世田谷区)

有効期限は、登録申請した月の直前の決算月の翌月から数えて1年8か月の末日まで。続けたい人は、前回の申請直後の決算月の翌月から、有効期限までに継続申請をします(世田谷区)。たとえば3月決算の会社が2026年10月に申請すると、直前の決算月は2026年3月です。数え始めは翌月の4月で、そこから1年8か月の末日、つまり2027年11月末が期限になる計算です。人によって期限が違うので、自分の受付票で確かめてください。

東京都の局の資格(東京都電子調達システム)と区市町村の資格(東京電子自治体共同運営)は、別々の申請です。2026年10月30日の東京都の締切は、区市町村の資格とは関係ありません。

入札参加資格の更新時期を逃すとどうなる?

更新の締切を逃すと、今の資格が切れた日の翌日から入札に参加できない期間が生まれます。随時受付で取り直せても、資格が始まるのは審査の後です。空白は早くても数週間、長ければ数か月になります。

空白の長さは機関の決まりで計算できます。2027年3月31日で今の資格が切れる場合の例です。

「1か月くらいなら困らない」と思うかもしれません。ですが4月から5月は、年度初めの単価契約や年間委託の入札が集まる時期です。たとえば毎年4月に公告される清掃委託に出ていた会社なら、その年の入札は見送りになります。

もう1つの落とし穴は名簿の切り替えです。神奈川県の共同システムでは、令和7・8年度の競争入札参加資格は、すべて令和9年3月31日までで失効します。「去年取ったばかりだから大丈夫」は通じず、去年の随時申請組も今回の定期申請が必要です。

逃したときの直し方は次のとおりです。

  1. 定期受付の締切を過ぎたと分かったら、その日のうちに機関の「随時申請」の案内ページを確かめる
  2. 随時申請の始まる日と、最初の認定日をメモする
  3. 書類(登記事項証明書、納税証明書、財務諸表など)を随時申請の始まる日までにそろえ直す。証明書には「発行から3か月以内」などの期限があることが多いので、手引きで確かめる
  4. 空白期間に公告が出る入札は、参加資格の条件を読んで、出られないものを外しておく

審査の日数は、機関と時期によって数日から2か月ほどまで開きがあります。公式に書かれている数字は次のとおりです(2026年10月時点)。

審査を長引かせる一番の原因は、書類の不備です。大分県は、指定した期日までに訂正しないと資格審査が行えず申請を却下する場合があるとしています。電話やメールで訂正の連絡が来たら、その週のうちに返すのが目安。担当者の連絡先(電話・メール)を、申請書にすぐつながる番号で書いておくことも大切な対策です。

逆算の目安をまとめると、参加したい入札の公告日から見て次のように考えます。

  • 毎月締め・毎週締めの機関: 公告の1か月前までに申請を終える
  • 回数の決まった追加審査がある機関: 公告の2〜3か月前の回に出す
  • 全省庁統一資格の随時審査: 日数が示されていないので、2か月以上の余裕を見る

複数の自治体・省庁に申請する場合、申請時期をどう管理すべき?

複数の機関に出すなら、機関ごとに「資格が切れる日」と「次の受付の時期」を1枚の表にまとめるのが確実です。周期(2年・3年・決算月)も始まりの月(4月・10月・毎月)もばらばらなので、頭で覚えるのは無理があります。

表を作るときの手順です。

  1. 今持っている資格の通知書(資格審査結果通知書・受付票など)を全部集める
  2. 通知書に書かれた「有効期間」の終わりの日を表に写す
  3. 各機関の入札参加資格ページで、次の定期受付の予定が出ているかを確かめる。出ていなければ「前回の受付月」を書いておく
  4. 「準備を始める日」は、受付開始の1か月前に置く。納税証明書や登記事項証明書の取り寄せに時間がかかるため
  5. 毎年9月と2月に表を見直す。秋の定期受付と、年度末の切り替えに合わせるため

つまずきやすいのは、決算期の変わり目です。新しい決算が確定すると財務の数字が変わり、等級が変わることもあります。定期受付の時期が決算の確定直後に重なる会社は、どちらの決算で出すのかを手引きで確かめてから入力してください。

共同受付をうまく使うと、管理する行が減ります。神奈川県内の参加団体や都内の区市町村は、1回の申請で複数の自治体に出せます。1行に「共同システム(〇市・△町)」とまとめて書けば十分です。

よくある質問

入札参加資格の申請はいつでもできますか?

多くの機関では、定期受付の後に随時受付があるので、ほぼ一年じゅう申請できます。ただし浜松市の追加審査のように年数回だけの所もあり、横浜市の定期申請のように期間外を一切受け付けない受付もあります。申請先のページで「随時」の期間を確かめてください。

定期受付を逃したら、次の2年間は入札に出られませんか?

いいえ、随時受付で途中から取れます。ただ、資格が始まるのは審査が終わってからで、関東地方整備局の工事・測量なら認定は令和9年4月15日以降です。4月1日から出たいなら定期受付に間に合わせるしかありません。

全省庁統一資格の更新はいつですか?

今の名簿は令和10年3月31日までで、次の定期審査の日付は2026年10月時点で発表されていません。前回の定期審査は令和7年1月31日に締め切られました。調達ポータルの告知を、2027年の秋ごろから見ておくと安心です。

随時受付で取った資格はいつまで使えますか?

定期受付で取った資格と同じ日に切れます。たとえば神奈川県の共同システムで令和7・8年度の随時申請をした場合、認定日がいつでも令和9年3月31日で失効します。続けて使うには次の定期申請が必要です。

個人事業主でも申請時期は同じですか?

同じです。受付期間は法人と個人で分かれていないことが多く、東京都の物品買入れ等も「一般(法人・個人)」として2026年10月30日までの受付です。事業協同組合などは別の期間になる場合があります。
