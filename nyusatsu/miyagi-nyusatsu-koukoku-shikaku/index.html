#入札 #入札参加資格 #自治体入札

※この記事にはアフィリエイト広告(PR)が含まれます。紹介したサービスへの申し込みなどで、運営者に報酬が入ることがあります。

宮城県が出す入札の公告は、県の出納局契約課のページと「宮城県入札・調達ポータル」の入札情報サービスで見られます。参加資格は県の入札参加登録システムに電子申請しますが、この資格で参加できるのは県の入札だけです。仙台市や町村の入札に出るには、それぞれの発注者に別に登録する必要があります。物品・役務の登録は年4回で、2027年1月1日に登録を受けたい場合の受付は2026年11月20日(必着)で締め切られます(宮城県 物品調達等入札参加登録の申請)。

この記事の要点

  • 県の公告は契約課ページと入札・調達ポータルの2か所
  • 県の資格では仙台市や町村の入札に参加できない
  • 県の物品・役務の登録は年4回で有効期間は3年

向いている人: 宮城県で官公庁の仕事を取りたい初めての事業者

宮城県の入札公告はどこで見られる?

県の公告は、契約課の案件一覧ページと「宮城県入札・調達ポータル」の入札情報サービスの2か所で見られます。物品・役務と工事では入口が違います。

県の契約課のページ(宮城県 契約課・2026年10月16日掲載)には、入札情報への入口が区分ごとに並んでいます。

ポータルの位置づけは、トップページの説明文がいちばん短く伝えています。

「本サイトは宮城県の入札参加資格の申請・電子入札・電子調達に関するポータルサイトです。」(宮城県入札・調達ポータル)

ポータルからは「入札参加登録システム」「建設工事等電子入札システム」「物品等電子調達システム」に入れます。入札情報サービスは工事と物品の両方にあります(宮城県入札・調達ポータル)。

物品・役務の公告を開く手順

  1. 県の契約課のページを開き、「物品・役務(委託)関連業務情報」の欄へ進む
  2. 「物品・役務(委託)等入札情報」を開く
  3. 「物品等入札情報サービス」(外部サイト)を開く
  4. 発注する所属や公告日などで案件を探す。くわしい探し方は同じページの「入札情報サービスでの案件検索方法」に載っています

「物品・役務(委託)等入札情報」のページには、入札情報サービスのほかに「電力の一般競争入札の一覧」「賃貸借の一般競争入札の一覧」「物品の売払い一般競争入札の一覧」への入口が別にあります(物品・役務(委託)等入札情報)。電力やリースを扱う事業者は、入札情報サービスだけ見ていると取りこぼします。

つまずきやすい所

  • ブラウザで動かない: 物品等電子調達システムが動くのはMicrosoft EdgeとGoogle Chromeだけです。Windows 10は動作環境から外れました(物品等電子調達システムの案内)。別のブラウザで開けないときは、まずこの2つに切り替えてください。
  • 見られる時間の違い: 入札情報サービスは24時間だれでも使えます。入札見積システムで札を入れられるのは平日9時〜20時だけです(同上)。締切日に夜遅くまで作業する予定は立てないほうが安全です。
  • 停止日: システムは保守で止まることがあります。2026年6月19日20時〜22日9時には入札情報サービスが止まりました(同上)。締切の直前には案内ページで停止の予定を確認してください。

県の過去の落札結果を調べたいときは、県庁地下1階の県政情報センターで閲覧できます。公表の対象は、物品・役務と建設関連業務が予定価格200万円超、建設工事が400万円超の案件です(宮城県 入札関係情報の公表・2025年7月1日掲載)。国や他の自治体も含めて無料で見られる範囲は、入札情報 無料|国と自治体の公告・落札結果を4区分の表で比較にまとめています。

宮城県と市町村の入札の違い

県と市町村は別々の発注者です。公告を出す場所も、資格を登録する先も分かれています。県の資格で仙台市や町村の入札には参加できません。

宮城県には35の市町村(14市20町1村)があります(宮城県 子ども向け資料)。それぞれが自前の契約担当を持っていて、公告や受付の日程もばらばらです。代表として県・仙台市・美里町を並べます。

仙台市は「市の本体+4つの企業局」をまとめて1つの名簿で受ける

仙台市の名簿に載っていないと、売払いを除く仙台市の競争入札に参加できません。この「仙台市」には水道局・交通局・ガス局・市立病院も含まれます(仙台市 競争入札参加資格・2026年11月16日更新)。名簿は工事業者名簿、コンサルタント業者名簿、物品業者名簿の3種類。

市外の事業者も登録できます。

「仙台市内に本店や支店・営業所等がない事業者でも、競争入札参加資格者名簿への登録はできます。」(仙台市 よくある質問と回答(契約一般))

注意したいのは受付の時期です。仙台市の登録は定期登録と補充登録に分かれていて、定期登録の間に名簿に入るには補充登録を使います。仙台市 登録申請の受付のページ(2026年8月18日更新)では、2026年10月登録分の補充登録は受付を終えていて、次回は2026年12月初旬ごろにホームページで案内する予定とされています。名簿の有効期限と次の定期登録の時期は、申請の前に同じページで確かめてください。

町村は1つずつ別の申請になる

美里町の令和9・10年度分の受付は、2026年10月1日〜11月30日(土日祝を除く)。郵送か信書便で出します(美里町)。

市町村の共同受付はあるのか

結論は「一部の市町村には2年度ごとの共同受付があるが、県は含まれず、県内全市町村を1回で済ませる窓口でもない」です。

  • 富谷市の随時受付の募集要項には、2年度ごとの「共同受付」や「中間受付」とは別の受付だという注意書きがあります。共同受付という仕組みが市町村の間にあることは、この要項から分かります(富谷市 募集要項)
  • 共同受付の時期以外に出す随時受付では、申請先は富谷市だけで、ほかの団体への申請はできないとされています(同上)
  • 美里町のように、自前の受付ページで期間と提出方法を案内している町もあります(美里町)
  • 県の資格は県の入札にしか使えないので、共同受付で市町村に登録しても、県には別に申請が要ります

どの市町村が共同受付に加わっているかは、この記事で調べた資料からは特定できません。狙う市町村の「入札・契約」ページで、共同受付の対象かどうかと次の受付時期を確かめてください。共同受付の対象外の町村は、1つずつ申請します。

つまずきやすい所

町村の公告の参加条件には、その町村の名簿に載っていることが書かれている場合があります。公告の「参加資格」の欄を読むとき、どの発注者の名簿のことかを最初に確かめてください。受付の時期は発注者ごとに違います。定期と随時の違いは入札参加資格 申請時期|定期・随時の違いと2026年秋の受付表で整理しています。

宮城県の入札参加資格の登録先と申請手順

県の資格は、入札・調達ポータルの「入札参加登録システム」に電子申請します。工事・建設関連・物品・役務の区分ごとに受付の時期が違います。

2026年7月から申請の方法が変わりました。

「宮城県では、これまで紙でのみ受付を行っていた入札参加資格申請が、令和8年7月1日より電子申請での受付になりました。」(宮城県の入札参加資格登録の電子申請について)

ネットで見つかる古い解説の中には「書類を郵送する」と書いたものがあります。2026年7月より前の情報なので注意が必要です。システムを使うのが難しい場合だけ、紙での申請を事前受付フォームで申し込めます(同上)。

物品・役務の申請手順

  1. 物品調達等入札参加登録の申請を開き、本店の所在地に合った申請要領と申請様式を手元に置く
  2. 上の必要書類を申請要領に沿ってそろえる
  3. 宮城県入札・調達ポータルから「入札参加登録システム」に入る。メニューには「予備登録」と「入札参加資格申請」がある
  4. 説明動画のテキスト版とシステム操作マニュアル(電子申請の案内にリンク)を見ながら入力し、送信する
  5. システム上で処理の状況を確かめ、登録月の前月末ごろの通知を待つ

入力の画面は、必須項目を埋めないと次に進めません。前回の申請情報は残るので、更新のときは変わった所だけ直せば済みます(電子申請の案内)。

  • 登録日は年4回(1月1日・4月1日・7月1日・10月1日)。WTO案件のための新規登録だけは随時受け付けます
  • 有効期間は登録日から3年
  • 承認者名簿はExcelをZIPにまとめた形(約850KB)で公開され、次回の更新は2027年1月5日の予定(物品調達等入札参加資格承認者名簿・2026年10月28日掲載)

いずれも物品調達等入札参加登録の申請と名簿のページに載っている数字です(2026年11月時点)。

つまずきやすい所と直し方

  • 締切の当日に出す: 県は、書類の不備で間に合わなくなるおそれがあるとして、受付終了日の1か月前までに出すよう呼びかけています。2027年4月1日登録を狙うなら、2027年1月中の提出が目安です。
  • 更新の時期が分からない: 自分の登録の有効期限と更新の受付時期は、承認者名簿のページの案内で確かめてください。期限が近い場合は、更新の締切に間に合うよう早めに準備します。
  • 住所などが変わったまま更新する: 登録内容が変わった場合は、更新の前に別に変更の届出が要ります(物品調達等入札参加登録の申請)。
  • 納税証明書が古い: 書類の発行日には期限があります。取り寄せる前に申請要領で有効期間を確認してください。

宮城県入札 物品の参加資格と公告の見方

物品の入札には、工事とは別の「物品・役務」の資格が要ります。案件は物品等電子調達システムの入札情報サービスで探します。資格を取ったら、入札見積システムのID・パスワードも別に用意します。

県の物品の仕組みは2段に分かれています。公告を見るだけなら資格はいりません。入札見積システムで札を入れるには、県の登録とID・パスワードが必要です(物品等電子調達システムの案内)。

入札・見積に参加する入札見積システム県の物品・役務の登録、ID・パスワード(平日9時〜20時)

「ICカードは、必須ではありません。」(物品等電子調達システムの案内)

ID・パスワードで入札見積システムを使えるので、初めての事業者が最初からICカードを用意する必要はありません。

地元の事業者が有利になる仕組み

県は、地元で調達できるものは地元企業に発注することを基本方針としています。地方公所を中心に「地域限定型」の入札や見積合わせを行っています。所管区域に本店を置く登録業者が5者以上いれば地域限定型、5者未満なら隣りの地域と合わせて5者以上になる場合に「隣接地域ブロック限定型」になります(地元企業からの物品調達等について)。

県外の事業者から見ると、登録はできても参加条件で外れる案件があるということです。反対に、たとえば石巻や大崎に本店がある小さな事業者なら、その地域に絞った案件で相手が少なくなります。登録のときは本店の所在地を正しく入れてください。

公告を読むときに確かめる3か所

  1. 参加資格の欄: 「宮城県の物品調達等の入札参加登録」と、登録している営業種目が求められているか
  2. 地域の条件: 本店の所在地が限られていないか
  3. 納入期限: システムの案内でもわざわざ「案件に設定されている『納入期限』にご注意願います」と書かれています。納期に遅れると、参加資格を制限されることがあります(物品等電子調達システムの案内)

案件の中身で分からない点は、システムに表示された発注所属の担当者に聞きます。契約課物品班(022-211-3333)は制度の窓口です。システムの操作はヘルプデスク(050-3820-9928・平日9時〜17時30分、12時〜13時を除く)に聞きます(同上)。

つまずきやすい所

  • 金額の打ち間違い: 入力ミスで辞退すると、参加資格の制限につながるおそれがあります。県は複数人で金額を確かめるよう案内しています(同上)。
  • IDの通知書をなくした: 「ユーザーID・仮パスワード通知書」は再交付を申請すれば出してもらえますが、ふつう1〜2日かかります(同上)。締切の前日に気づいても間に合わないことがあります。

物品を納める小さな会社が「中小企業」として扱われるかは、官公需の中小企業定義|業種別の基準表と令和8年度の発注目標で業種別の基準を確認できます。

初めての事業者が最初にやることの順番

ここまでの内容を、登録から初めての入札までの順に並べます。

  1. 狙う発注者を1つ決め、登録なしで案件を見る: 仙台市なら入札情報公開システム(平日6時〜23時)と仙台市公報 号外(調達)で見られます(仙台市 電子入札システムポータルサイト(物品・役務))
  2. 自分が出せる案件の条件(営業種目・地域・納期・数量)を書き出し、その発注者の受付日程に合わせて申請する
  3. 登録の通知が届いたら、入札見積システムのID・パスワードを用意する: 名簿のC列にある業者コードを使って申請します(承認者名簿のページ)
  4. 見積合わせなど、条件の分かりやすい小さな案件から参加する

たとえば仙台市内に本店がある事務用品の販売店なら、県の物品・役務を2026年12月に申請し、同じ時期に仙台市の補充登録の案内(2026年12月初旬ごろの予定)を待つ、という並べ方ができます。どちらも登録されれば、県庁の案件と仙台市役所の案件を見比べられます。

個人事業主でも申請の流れは同じです。等級や点数の考え方は入札は個人事業主でもできる|等級の点数表と申請手順を整理で説明しています。

自分でやる人の今日の一歩

  1. 物品等入札情報サービスで、自分の商品に近い案件を3件ほど開き、参加資格の欄を読む
  2. 県税と消費税の納税証明書の取り寄せ方を、税務署と県税事務所の窓口で確かめる

早く確実にしたい人の選択肢

  • 県の窓口に聞く(無料): 申請の中身は契約課管理班(022-211-3335)へ、システムの操作はヘルプデスクへ。向いているのは、自分で入力できるが判断に迷う所がある人です。
  • 行政書士に代行を頼む(有料): 申請書類の作成と提出を行政書士に頼む方法があります。費用は事務所ごとに違うので、申請する発注者の数と区分を伝えて見積もりをもらってください(最新は各事務所で確認)。向いているのは、県と複数の市町村に一度に出したい人や、事務に時間を割けない人です。発注者が1つだけで、必要書類を自分でそろえられるなら、まず自分で出してみる選択もあります。

よくある質問

宮城県の資格があれば仙台市の入札にも参加できますか?

できません。仙台市の競争入札に参加するには、仙台市財政局契約課の名簿に載っている必要があります。この名簿は水道局・交通局・ガス局・市立病院の入札にも共通です。

宮城県の物品の登録はいつでも申請できますか?

いつでもではありません。登録日は年4回で、それぞれ受付期間があります。2027年4月1日登録の受付は2026年12月1日〜2027年2月19日必着で、県は締切の1か月前までに出すよう呼びかけています。

県外の会社でも宮城県の入札に登録できますか?

登録できます。申請要領と様式は、県内に本店がある事業者と県外に本店がある事業者で別になっています。ただし、物品には地域限定型の入札もあるので、参加できない案件もあります。

県内の市町村にまとめて申請できる共同受付はありますか?

一部の市町村には2年度ごとの共同受付があります(富谷市の募集要項に記載)。ただし県の資格は含まれず、どの市町村が対象かは各市町村のページで確かめる必要があります。対象外の町村には1つずつ申請します。

電子入札のICカードは買わないといけませんか?

県の物品等電子調達システムでは、ICカードは必須ではありません。ID・パスワードで入札見積システムを使えます。ブラウザはMicrosoft EdgeかGoogle Chromeを使います。

紙で申請することはできますか?

2026年7月1日から、県の入札参加資格の申請は原則として電子申請だけになりました。システムを使うのが難しい場合は、県の事前受付フォームで紙での申請を申し込めます。
