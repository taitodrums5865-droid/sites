How the estimate works

Monthly cost = requests × (input tokens × input price + output tokens × output price) ÷ 1,000,000. Cached input uses the model's cached-input price when one is listed. Taxes, minimum fees, rate-limit tiers and batch discounts are not included. See how LLM API pricing works.
