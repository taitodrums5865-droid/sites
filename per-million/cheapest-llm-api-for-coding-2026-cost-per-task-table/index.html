If you count what a full coding task costs, the cheapest LLM API for coding in October 2026 is Claude Haiku 5.5 when your prompts stay under 100K tokens. DeepSeek's deepseek-flash is cheapest once your repo context goes past that, and in off-peak hours it is close to Haiku on small tasks too. Both rankings assume prompt caching is turned on. Without caching, the per-token tables most sites publish overstate what agent loops cost by roughly 3-4x and can put the models in the wrong order. For better code quality at moderate cost, Gemini 3.8 Flash and GPT-5.4 mini come out at about $0.25 per example task. Claude Sonnet 5.5 costs about $0.60 for the same task.

How cost per coding task is calculated here

A coding task is costed as a whole agent session: a large repeated context, a little new input on each turn, and some output. A single prompt is the wrong unit. That's why caching rates and long-context surcharges matter more than list price.

Coding agents send the same system prompt, tool definitions and file contents on every turn. Tool use also adds hidden tokens. For example, Claude adds 286 system-prompt tokens per request on Haiku 5.5 and Sonnet 5.5 when tools are enabled with tool_choice: auto. On top of that you pay for your tool schemas and every tool_use and tool_result block (Claude tool use docs). On a 20-turn session, all of that is re-sent 20 times.

These are the two example workloads used below. They are illustrations, not measurements:

  • Task A (typical feature fix): 20 turns. A 40K-token prefix (system prompt, tools, relevant files) is cached after turn 1. Each turn adds 3K new input tokens and 1.5K output tokens. Totals: 40K cache write, 760K cache reads, 60K uncached input, 30K output.
  • Task B (large-repo work): Same 20 turns, but with a 150K-token prefix. Totals: 150K cache write, 2.85M cache reads, 60K uncached input, 30K output.

Formula: cost = write_tokens × write_price + read_tokens × read_price + fresh_input × input_price + output × output_price. If you want to run this on your own logs, see how to build an LLM cost calculator in Python. The general caching math is in Prompt Caching Cost 2026: Discount Table + Savings Formula.

Two simplifications apply. Real conversations grow every turn, which favors caching even more. And a cheaper model that needs more turns to finish can end up costing more per task, which no price table can capture.

What the table hides

Haiku 5.5 is the cheapest for short prompts, but the 100K-token threshold works like a cliff. In Task B, every price goes up 5x, and Haiku drops behind deepseek-flash. Not for: whole-repo agents that routinely send 100K+ tokens. Anthropic also positions Haiku for "classification, extraction, and routing" rather than long agentic coding (Claude models overview).

deepseek-flash has the flattest cost curve as context grows, plus a 1M context window. Not for: teams that need EU or US data residency, or predictable latency during peak hours. Limitation: the same request costs twice as much depending on the time of day, which makes forecasting harder.

Gemini 3.8 Flash prices are promotional. If you model your budget on October 2026 rates, your January 2027 invoice will roughly double (Gemini pricing).

GPT-5.4 mini is priced close to Gemini 3.8 Flash. Its 2x surcharge applies only above 272K input tokens, so most coding prompts never reach it (OpenAI pricing).

Devstral 2 ranks low here only because no caching discount was modeled. Its value is EU hosting (see the EU sections below). For autocomplete, Mistral's Codestral costs $0.30/$0.90 with a 128K context and a dedicated /v1/fim/completions endpoint (Codestral model card).

How to get the cached price in practice

You only get the cached prices if your prompt prefix stays byte-identical between turns and you check the usage fields to confirm cache hits.

  1. Put stable content first. Order the prompt as system prompt → tool definitions → repo files → conversation. Anything that changes (timestamps, random IDs, the user's new message) goes last.
  2. Turn caching on where it's explicit. On Claude, add "cache_control": {"type": "ephemeral"} to the last stable block. A 5-minute cache write costs 1.25x input and a 1-hour write costs 2x for most models (Claude pricing). OpenAI, DeepSeek and Gemini's implicit caching apply automatically.
  3. Check hits in the response. Read usage.cache_read_input_tokens (Claude), usage.prompt_tokens_details.cached_tokens (OpenAI), prompt_cache_hit_tokens (DeepSeek) or usage_metadata.cached_content_token_count (Gemini). If the number is 0 after turn 2, your prefix is changing.
  4. Set a spend cap per key. OpenRouter supports per-key credit limits and budgets that reset daily, weekly or monthly (OpenRouter limits). On Mistral, check Admin Console → Limits.
  5. Send non-urgent jobs through Batch. Claude, OpenAI and Gemini all take 50% off batch requests (sources above). See Batch API Discount 2026: OpenAI vs Claude vs Gemini Table.

Common mistakes and fixes

  • Mistake: Putting the current date or git status at the top of the system prompt. Fix: Move it to the latest user message so the cached prefix stays the same.
  • Mistake: Reordering tools between requests. Fix: Serialize tool definitions in a fixed order.
  • Mistake: Paying 1-hour cache-write prices for sessions that end in two minutes. Fix: Use the 5-minute TTL unless the gaps between turns are longer.
  • Mistake: Budgeting with Haiku's ≤100K price while your agent sends 120K. Fix: Log prompt sizes and trim retrieved files, or route big prompts to deepseek-flash.
  • Mistake: Building a budget on Gemini 3.8 Flash's 2026 promotional price. Fix: Use the 2027 price in your forecast.

What Is the Cheapest Translation API for a Coding Project?

For plain UI strings, Google's 500K free characters cost nothing, but past the free tier a cheap LLM usually costs less per 1M characters. LLMs are clearly better when the text contains placeholders, markup or code.

DeepL's older "API Pro" plan can no longer be bought. New sign-ups get a one-time 1M-character Developer allowance, then move to Growth (DeepL support). Check the DeepL pricing page for current rates.

Worked example: Anthropic estimates 1M tokens at about 2.5M Unicode characters on its tokenizer (Claude models overview). Using that ratio, 1M characters is roughly 400K tokens in and 400K out. On Gemini 3.1 Flash-Lite that comes to about $0.10 + $0.60 = $0.70, compared with $20 on Google NMT after the free tier. Tokenizers differ by provider and language, so treat this as a rough estimate.

Pitfalls: LLMs sometimes translate {count} placeholders, ICU plural keys or variable names. Fix this by asking for JSON output with keys unchanged and checking placeholders in CI. Dedicated APIs handle markup more predictably and offer glossaries.

Is a Coding Bootcamp Cheaper Than Learning to Code with an LLM API?

Yes, by a wide margin on cash cost. A $5–$50 monthly API budget compares with average bootcamp tuition of $14,142, but bootcamps also sell structure, feedback and career services.

Next steps

Start with today's prices and your own prompt sizes. A single afternoon is enough to see what your coding agent will cost per month.

Do it yourself today:

  1. Log prompt token counts from 20 real coding sessions. Find your median and see whether it is over or under 100K. That tells you whether Haiku 5.5 or deepseek-flash should be your default.
  2. Turn on caching and confirm cache hits using the usage fields listed in "How to get the cached price in practice."
  3. Put a monthly spend cap on every API key before sharing it with teammates or an agent.

If you'd rather not run it yourself: Anthropic's Max plan bundles Claude usage for a flat monthly fee. It suits heavy individual users who want a predictable bill. It doesn't suit teams that need per-key spend caps or backend automation. Compare it with API usage in Claude API Pricing vs Max Plan: Break-Even Table for 2026. Check claude.com/pricing for the current price (as of October 2026). For EU teams, OpenRouter's Business plan handles routing and residency without a contract, but it does not support the Batch API in the EU region.

FAQ

What is the cheapest translation API?

For small volumes, DeepL API Free and Google Cloud Translation both give you 500K free characters a month. Above that, a cheap LLM such as Gemini 3.1 Flash-Lite costs roughly $0.70 per 1M characters in the example above, compared with $20 on Google NMT. Dedicated APIs are still easier for glossaries and markup.

What is the cheapest LLM for international students?

Free tiers come first: the Gemini API free tier, OpenRouter :free models (50 requests a day, or 1,000 after a one-time $10 purchase) and Groq's free plan. Don't put personal data into Gemini's free tier, because Google may use it to improve its products.

What is the cheapest coding bootcamp?

Course Report lists tuition from $3,500 to $30,000, with an average of $14,142, and some programs are free. A capped LLM API budget of $5–$50 a month costs far less, but it doesn't give you mentors or career services.

What is the cheapest LLM in Europe?

For EU-hosted inference, OVHcloud's gpt-oss-20b at €0.04/€0.15 per 1M tokens is among the lowest list prices. Mistral's API offers a free mode with EU hosting by default. Azure's EU Data Zone costs more than Global deployments, not less.
